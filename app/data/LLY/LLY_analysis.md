# LLY — Eli Lilly and Company
> 글로벌 빅파마. Incretin(GLP-1/GIP) 듀오(Mounjaro·Zepbound) 중심의 Metabolic 플랫폼 + Oncology(Verzenio) + Immunology(Taltz/Omvoh) + Neuroscience(Kisunla). FY25 매출 $65.18B(+45%), Mounjaro $22.97B(+99%) + Zepbound $13.54B(+175%)로 Incretin 비중 62%. 2026-04 Orforglipron(oral GLP-1, "Foundayo") FDA 승인으로 경구 GLP-1 선점.

## 투자 thesis

- **Tirzepatide(Mounjaro·Zepbound)의 head-to-head 우월성 + 2036~2041 특허 보호** → 무형 자산(특허·임상 데이터) + 전환비용(만성 대사 치료 관성): FY25 합산 $36.5B(+127%). SURMOUNT-5 trial에서 Wegovy(semaglutide) 대비 체중 감량 47% 우월(-20.2% vs -13.7%). US 제조 특허 2036(US 9,474,780) + 조성물/제형/디바이스 패밀리 2039~2041 연장.
- **Orforglipron(oral GLP-1) 2026-04 FDA 승인으로 경구 비만 시장 선점** → 무형 자산(First-to-file) + 효율적 규모(Small molecule 제조 비용 < 10% of peptide injection): Novo Nordisk oral Wegovy(2026H2 승인 예정) 대비 3~6개월 앞선 상업화. Morgan Stanley 2026E $1.2B, BofA $2B 추정, 2030E peak $18~25B 전망.
- **LLY의 재투자 엔진 — R&D $13.34B(매출 20.5%) + CapEx $7.84B + M&A**: Loxo@Lilly(Pirtobrutinib), DICE(Immunology oral), Versanis(Bimagrumab), Morphic(IBD α4β7) 인수. 파이프라인: Retatrutide(Triple agonist) Phase 3 체중 -24~28%, Kisunla(Alzheimer) 2024 승인, Verzenio adjuvant peak $10B+.

### 3-3. 경쟁 우위 원천 분석

**1. Tirzepatide 분자적 우월성 (head-to-head 승리)**
- **우위**: GLP-1 + GIP 이중작용 → semaglutide(GLP-1만) 대비 통계적 우월
- **정량**: SURMOUNT-5 72주 -20.2% vs -13.7% (47% 상대), SURPASS-6 HbA1c -2.08% vs -1.86%
- **복제 난이도**: 높음 — GIP receptor agonism 발견은 LLY 독자 R&D(15년+). NVO는 amylin+sema 다른 기전 접근
- **격차 지속**: 7~10년 (2033 Retatrutide 본격 ramp 시 재확장 가능)

**2. 경구 GLP-1 first-mover (Orforglipron)**
- **우위**: Small molecule 저분자 경구 GLP-1 최초 FDA 승인 (2026-04)
- **정량**: PDUFA 2027-01 대비 9개월 early approval. NVO oral Wegovy 선점 3~6개월
- **차별성**: NVO oral Wegovy는 semaglutide 25mg 대용량 peptide — 경구 흡수 제한, 식전 공복 30분 필수. Orforglipron은 food/water restriction 없음
- **복제 난이도**: 중간 — Chugai 원천 물질, LLY 라이선스(2018). Structure·Viking·AZN 추격 Phase 2~3
- **격차 지속**: 3~4년 (2029 Phase 3 자산 3~4개 승인 예상)

**3. 제조 CAPEX 선행투자**
- **우위**: 2021~2026 $50B+ 투자로 4개 신규 시설 건설
- **정량**: 2025 기준 tirzepatide 연간 생산능력 20M+ 환산, 2028 50M+ 목표. NVO 15M→25M
- **복제 난이도**: 매우 높음 — 단일 시설 $5~10B + 5~7년 소요, FDA GMP 승인 2~3년 추가
- **격차 지속**: 10년+ (투자 사이클 자체가 해자)

**4. Metabolic+Obesity 통합 임상 플랫폼**
- **우위**: SURPASS(T2D) + SURMOUNT(비만) + SURMOUNT-CV + SUMMIT(HFpEF) + SURMOUNT-CKD 등 10+ Phase 3 동시 가동
- **정량**: SURMOUNT-1(-22%), 2~5 positive. OSA(2024), HFpEF(2025), MASH·CKD(2026E) 확장
- **복제 난이도**: 높음 — 임상 인프라 + 환자 인구집단 + 데이터 자산
- **격차 지속**: 지속 (경쟁자 follow-on 구조)

### 3-4. 투자 차별화 근거

**해설**: Forward PE 프리미엄 +136%는 2026E 40%+ 성장 vs 경쟁사 5~10% 성장 감안 시 **일부 정당**. PEG 0.8은 성장 대비 저평가 시사. 그러나 FCF Yield 1.1%는 CAPEX 부담 반영 — LLY는 고성장을 가격에 반영한 상태로, 성장 궤적 미달 시 멀티플 디레이팅 리스크 큼. LOE 2036 근접에 따라 2030~2033년 사이 멀티플 15~18x 회귀 예상.

- 2 ↔ 5: **중상관** (관세와 지정학 동일 정치 사이클 동조)

**보정 후 Bear 기여 합계**: -4.5%(금리) + -2.5%(tariff+decoupling 동조) + -4.0%(safety/경쟁 중 선택) = **약 -11%**

### 7-3. Bear → Stress 반영 시 비교

| 구분 | 값 | 대비 |
|------|------|------|
| Base 파일 Bear 1-year target | $620 | 기준선 |
| Base 파일 Extreme Bear 1-year target | $320 | -48% vs Bear |
| 단순 합산 적용 시 Bear → $523 | $620 × (1-0.156) | -15.6% |
| 동조성 보정 적용 시 Bear → $552 | $620 × (1-0.11) | -11% |

**시사점**:

1. **동조성 보정 $552는 Extreme Bear $320보다 $232 높다** — Base 파일의 Extreme Bear는 본 Stress 시나리오 절반 이상을 이미 반영한 구조(MFN 확산 + Retatrutide 실패 + Orforglipron 실패 + 경기 침체 **동시 발생**). Extreme Bear는 Stress 시뮬레이션 전부 반영한 수준보다 보수적

2. **가장 큰 기여**: 경쟁 구도 파괴(S4, -5.6%) > 금리 상승(S1, -4.5%) > Class recall(S3, -2.5%) > Tariff(S2, -2.2%) > Decoupling(S5, -0.8%)
   - S3(Class recall)은 확률 5%로 낮지만 실현 시 충격 -50%로 가장 큼. 꼬리 위험 관리 대상
   - S4(경쟁 파괴)는 확률 15% × 충격 -37%로 Bear 기여 최대 — **실질적 최대 위험**

3. **주의**: 본 Stress 시뮬레이션은 Revaluation 가중평균에 **반영하지 않는다**. Extreme Bear 15% 확률 설정이 본 합계보다 우선. 본 시뮬레이션은 "모두 발생했을 때 Bear가 얼마나 더 깊어질 수 있는가" 참고용

4. **Extreme Bear $320이 보수적인 이유**: 멀티플 압축(Exit EV/EBITDA 10x + Forward PE 12x)까지 반영한 결과. 단일 macro/class 충격보다 **복합 충격(pipeline 실패 + 가격 인하 + 경쟁 + 경기)** 반영 설계

5. **모니터링 우선순위 (꼬리 위험)**:
   - **1순위**: GLP-1 class 안전성 signal (FDA MedWatch, EMA PRAC, MDL 소송)
   - **2순위**: Amgen MariTide Phase 3 readout (2026~27)
   - **3순위**: 10Y UST 5%+ 지속 여부
   - **4순위**: Pharmaceutical Section 232 EO 서명
