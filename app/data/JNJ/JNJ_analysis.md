# JNJ — Johnson & Johnson
> 글로벌 헬스케어 복합기업. Innovative Medicine(처방약, FY25 $60.4B/64%) + MedTech(의료기기, $33.8B/36%). FY25 매출 $94.2B(+6.0%), Q1'26 $24.1B(+10%). Tremfya(+64%)·Darzalex(+18%)가 Stelara LOE(-60%) 상쇄. 2025-10 Orthopaedics(DePuy Synthes) 분사 발표 — 18~24개월 내 분리. AAA 신용 + 60+년 연속 배당 증액(Dividend King).

## 투자 thesis

- **이중 Platform 다각화 (IM + MedTech)** → 무형 자산(특허·브랜드) + 전환비용 + 효율적 규모: pharma LOE 사이클과 device 시장 사이클 비상관(0.3 미만), 단일 segment 충격 시 다른 segment buffer
- **Tremfya·Darzalex·Carvykti 트리오의 Stelara LOE 상쇄** → 무형 자산(특허·임상): Q1'26 Tremfya $1.6B(+64%) + Darzalex $4B(+18%) + Carvykti ~$600M(+80%+). 회사 가이던스 oncology $50B 2030E (현재 $25.4B)
- **DePuy Synthes 분사로 SOTP discount unlock** → 자본 배분 우위: 2025-10 발표, 18~24개월 완료. Ortho ($9.2B/MedTech 29%) 분리 후 잔여 MedTech는 cardiovascular(Abiomed/Shockwave/Biosense) + robotic 중심 재편 → 멀티플 리레이팅 잠재력

**작성일**: 2026-04-19
**목표가 (가중평균 내재가치)**: **$201** ($107 ~ $271)

### Innovative Medicine

**사업 구조**: Oncology가 가장 빠른 성장 동력 ($25.4B → $50B 2030E 가이던스). Darzalex(anti-CD38, multiple myeloma) Q1'26 $4B(+18%, 연환산 $16~17B). Carvykti(BCMA-CAR-T, Legend Biotech 50:50) Q1'26 $600M, peak $5B+ 가이던스. Tremfya(IL-23p19, 건선+IBD) Q1'26 $1.6B(+64%) → 연환산 $7B, peak $10~12B 추정. Stelara(IL-12/23) 미국 LOE 2025로 Q1'26 $656M(-60% YoY) — biosimilar(Amgen Wezlana, Teva/Alvotech, Sandoz) 침식. Caplyta(Intra-Cellular $14.6B 인수, schizophrenia/bipolar) 신규 동력. Xarelto는 IRA 2026 협상가 $197(list $517 -62%) 적용.

| 해자 유형 | 검증 |
|---------|------|
| 무형 자산 (특허 thicket) | ✅ |
| 무형 자산 (임상 데이터) | ✅ |
| 전환비용 (만성 치료) | ✅ |
| 규제 진입장벽 (CAR-T 제조) | ✅ |

**상세**:
- **특허 thicket**: Darzalex 조성물 ~2029(US), SC formulation(Faspro) 2032+. Tremfya 핵심 ~2031(US), 적응증 확장 IP 추가. Carvykti BCMA 항원 결합 도메인 + Legend Biotech 공동. Caplyta 2030년대 중반까지 보호.
- **임상 데이터**: Darzalex 1L NDMM PERSEUS phase 3 PFS HR 0.42 (NEJM 2024) → standard of care. Tremfya IBD GALAXI phase 3 (2024-09, ustekinumab 대비 우월). Carvykti CARTITUDE-4 1L PFS HR 0.27 (Lancet 2024-07).
- **전환비용 (만성 치료)**: Darzalex 평생 유지요법 일반화. Tremfya 12주 1회 SC, 환자 변경 회피. Stelara → Tremfya 자가 cannibalization으로 J&J 내 환자 retain.
- **규제 진입장벽**: Carvykti 자가 CAR-T 제조 시설 ($2B+ Raritan NJ + Ghent BE), 인증 hospital만 처방. CAR-T 시장 진입자는 BMS Abecma 2개사 과점.

**해자 리스크 (해자 훼손 관점)**:
- **Stelara 후속 LOE 누적 (Simponi 2026, Opsumit 2026)**: Stelara $11B → $3B(2027) + Simponi $2.5B → $1.5B + Opsumit $1.8B → $1.0B = 누적 -$9B+ 영향. **현실화 시점: 2025~28 진행 중 / 해자 훼손 정도: 중**
- **IRA 2027 cycle 추가 약물**: Stelara/Xarelto/Imbruvica 첫 cycle. 2027 cycle (2026-02 CMS 발표) Tremfya/Opsumit/Erleada 후보. **현실화 시점: 2026-02 / 해자 훼손 정도: 중~고 (Tremfya 지정 시)**
- **Trump MFN TrumpRx 직판 가격 압박**: 2025-11 합의로 tariff 면제 + OECD 가격 매칭. **현실화 시점: 진행 중 / 해자 훼손 정도: 저 (-1~3%)**

### MedTech — Cardiovascular

**사업 구조**: Biosense Webster(EP 매핑 시장 50%+ 점유) + Abiomed Impella($16.6B 인수 2022, percutaneous heart pump) + Shockwave Medical($13.1B 인수 2024, IVL 칼슘 병변 파쇄) + Varipulse(PFA, 2024 FDA + 2026 Pro CE Mark). Q1'26 +14.4% 가속.

| 해자 유형 | 검증 |
|---------|------|
| 무형 자산 (브랜드·임상) | ✅ |
| 전환비용 (시술자 트레이닝) | ✅ |
| 효율적 규모 (GPO 계약) | ✅ |
| PFA 매핑 통합 (Varipulse + CARTO) | ⚠️ |

**상세**:
- Biosense CARTO 시스템은 EP 시술자 5,000+ 인증, 평균 200 케이스/시술자. Abbott Ensite 35% / BSX Rhythmia 15% 경쟁 (시장점유율은 industry 추정).
- Impella PROTECT III/IV trial 데이터 (NEJM 2024) → high-risk PCI 가이드라인 등재.
- Shockwave DISRUPT C IV trial (NEJM 2023) → calcified coronary 표준화.
- Varipulse Pro 2026 EU 출시, 시술 시간 5배 단축 (J&J 자체 측정 — 독립 검증 진행 중).

**해자 리스크**:
- **PFA 3-way 경쟁 (BSX Farapulse + MDT PulseSelect)**: J&J Varipulse 후발 진입, 향후 2~3년 점유율 결정. **현실화 시점: 2026~28 / 해자 훼손 정도: 중**
- **Impella 가이드라인 약화 위험**: 2025-08 PROTECT IV subgroup 논쟁 — AHA/ACC 가이드라인 등재 지연 시 매출 캡

### 해자 강도 판정

**JNJ = Wide Moat ✅** (단, 다중 LOE 동시 진행으로 "Narrow 압박 구간" 진입 — 신약 가속 + MedTech 다각화로 유지)

핵심 근거:
1. **시간 지평**: 5년 투자 기간 내 핵심 신약(Tremfya·Darzalex·Carvykti·Caplyta·TAR-200·Imaavy) 모두 특허 보호 유지 (2030~2032+). MedTech cardiovascular는 Abiomed·Shockwave 인수로 Wide moat 신규 확보.
2. **전략적 헤지**: IM + MedTech 이중 구조 = pharma·device 사이클 헷지. 단일 segment LOE/규제 충격 시 다른 한 축이 buffer.
3. **계약/구조 보호**: AAA 신용등급(전세계 2개사 중 하나) — IG 발행 비용 우위, 차환 리스크 최저. 60+년 연속 배당 증액(Dividend King). FY25 R&D $15.1B + CAPEX $4.5B + M&A $14.6B 동시 집행.

**주의 구간**: **Tremfya 분기 매출 $1.5B 유지 + Carvykti $700M 분기 돌파 + DePuy 분사 일정**이 가장 먼저 균열을 알려줄 선행 지표. Tremfya 성장률 50% 이하 둔화 또는 Carvykti capacity 병목 지속 시 Stelara LOE 상쇄 실패 → Narrow Moat 재분류.

### 경쟁 우위 원천

**1. 이중 Platform 다각화 (IM + MedTech)**

- 경쟁사 격차: MRK·BMY pharma 100%, MDT·SYK device 100% — 단일 segment 사이클 노출
- 복제 난이도: **매우 높음** — 100+년 결합 운영, 신규 결합은 인수·통합 10년 단위
- 격차 지속: 영구

**2. AAA 신용등급 + 자본배분 규율**

- 정량 근거: WACC 약 7.5% (peer 8.5~9.5% 대비 저렴). 차환 비용 IG spread 50bp (peer 80~120bp 대비)

- 복제 난이도: **불가능** (50년+ 신용 트랙레코드)
- 격차 지속: 10년+

**3. Carvykti CAR-T 시설 (Legend Biotech 50:50)**

- 복제 난이도: **높음** (CAR-T 제조 + GMP 인증 + COGS 학습곡선)
