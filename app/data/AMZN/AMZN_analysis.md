# AMZN — Amazon.com, Inc.
> 세계 최대 E-commerce + 1위 클라우드 인프라(AWS ~32% MS) + Top-3 디지털 광고 플랫폼 (3 이질 세그먼트 복합기업)

## 투자 thesis

- **AWS: 구조적 네트워크 효과 + 전환비용 해자의 AI 재가속** — 네트워크 효과 + 전환비용: FY25 매출 $128.7B(+20% YoY), Q4 $35.6B(+24% YoY, 13개 분기 중 최고 가속), 운영이익률 35.4%, backlog $244B(+40% YoY), 시장점유율 32% (Azure 23%, GCP 11%)
- **광고: 리테일 트래픽 기반 폐쇄형 고마진 성장엔진** — 네트워크 효과 + 효율적 규모: FY25 광고 매출 $68B+(+22% YoY), Q2 전체 매출의 9.36%(사상 최고), 리테일미디어 $60.6B(1위 과점)
- **Prime 폐쇄형 소비자 네트워크 + 전환비용** — 글로벌 Prime 260M (US 185M, 미국 가구 77%), 연 평균 소비 $1,400/인, 미국 E-commerce 점유율 37.6%

**분석 작성일**: 2026-04-19
**목표가 (가중평균 내재가치)**: $202 (범위 $186~$222)

### AWS

**사업 구조**: 글로벌 클라우드 인프라 1위. IaaS/PaaS/AI 인프라(Bedrock, Trainium/Inferentia). Q4 2025 매출 $35.6B(+24% YoY), run rate $142B, backlog $244B(+40% YoY). AWS OI margin 35.4%로 전사 OI의 57% 기여.

| 해자 유형 (키워드) | 검증 |
|---------|------|
| 전환비용 (VPC/IAM/DB 마이그레이션 비용) | ✅ |
| 네트워크 효과 (Marketplace/Partner Network/ISV) | ✅ |
| 효율적 규모 (33 region, 105 AZ, 500+ PoP) | ✅ |
| 원가 우위 (Graviton/Trainium TCO -30~40%) | ⚠️ (회사 공시) |

**전환비용**: 엔터프라이즈의 VPC 아키텍처·IAM 권한·DB·애플리케이션 재작성이 수백만~수억 달러 비용. 마이그레이션 완료 기업의 30~50%가 리쿠드 코드를 재작성해야 하는 구조. Backlog $244B는 다년 계약으로, 전환비용이 계량화된 증거(Synergy Research, Amazon Q4 2025 8-K).

**네트워크 효과**: AWS Marketplace(제3자 SW), 100만+ 인증 개발자(Solutions Architect 등), 200+ 서비스가 서로를 강화하며 신규 진입자 복제 불가.

**효율적 규모**: 글로벌 33개 region, 105개 AZ, 500+ PoP의 물리 인프라(데이터센터·전력·해저케이블)는 10년·수천억 달러 투자 필요. Azure·GCP만 근접 가능.

**원가 우위 (신규 부상)**: 커스텀 실리콘 — Graviton(ARM CPU, Xeon 대비 TCO -30%), Trainium2/3(학습, Nvidia H100 대비 TCO -40%), Inferentia(추론). 커스텀 칩 매출 $20B+ (triple-digit 성장), Trainium2 fully sold out, Trainium3 대부분 예약. 단 Amazon 자체 주장이며 독립 벤치마크 제한적.

**해자 리스크**:
- Azure 추격 가속 (Q4 +31% vs AWS +24%) — 장기 MS 축소 가능, 진행 중 (2026~2028)
- 하이퍼스케일러 CAPEX 군비경쟁 (MSFT+GOOGL+META+AMZN 합산 $500B+/년) → capacity 과잉 가능, 시점 2027~2029
- Nvidia Blackwell Ultra/Rubin(2027~2028)이 Trainium 성능 격차 역전 가능, 시점 2027+

### North America (리테일 + 광고)

**사업 구조**: 1P(자체판매) + 3P(Marketplace) + Prime 구독 + 광고. 미국 E-commerce 점유율 37.6%(WMT 6.4%, AAPL 3.6%, eBay 3%). Prime 미국 180.1M, 미국 가구 77% 침투. Q4 2025 NA 마진 사상 최고 수준(물류 지역화·automation 효과).

| 해자 유형 (키워드) | 검증 |
|---------|------|
| 네트워크 효과 (3P Marketplace, 200M+ SKU) | ✅ |
| 규모 우위 (600+ FC, 500+ delivery station, Rivian 30,000대) | ✅ |
| 전환비용 (Prime 연 $139 + $1,400 평균 지출) | ✅ |
| 데이터 자산 (first-party search-to-purchase) | ✅ |

**네트워크 효과**: 3P가 전체 유닛 60%+. 판매자 증가 → 소비자 선택지 확대 → 더 많은 트래픽 → 더 많은 판매자라는 양면 피드백. 200M+ SKU는 경쟁사 1/10 규모.

**규모 우위**: 2024~25년 8 region → 80+ mini-region으로 물류 지역화하여 last-mile 비용 20%+ 절감 (Q4 2025 콜). FBA(Fulfillment by Amazon)이 3P 판매자를 Amazon 생태계에 종속시켜 네트워크 효과와 결합.

**Prime 전환비용**: 연 $139 + 평균 $1,400 지출 매몰 + Prime Video/Music/Reading/Photos 번들 — 이탈 시 비용·혜택 둘 다 상실. CIRP 2024~2025 기준 미국 이탈률 <5%.

**데이터 자산**: Apple ATT, Google Cookie 종료 이후 차별화. AWS 광고 ROAS가 META/GOOGL 대비 2~3배 우위 (자체 구매 데이터).

**해자 리스크**:
- WMT + Shopify 연합의 3P 경쟁 (WMT Marketplace $100B GMV 돌파), 시점 2028~2032
- FTC 반독점 트라이얼 2026.10 (Marketplace 강제·Buy Box 차별) — 판결 2027~2029
- TikTok Shop/Temu/Shein 저가 침투 — 현재 2~3% MS, 진행 중

### Advertising

**사업 구조**: 리테일 트래픽(월 3B+ 방문) 위에 얹은 광고. 스폰서드 프로덕트 + 디스플레이 + Prime Video(2024 론칭) + Twitch. 2025 매출 $68B+ (+22% YoY). 리테일미디어 $60.6B(eMarketer). 광고 마진 추정 55~65%.

| 해자 유형 (키워드) | 검증 |
|---------|------|
| 효율적 규모 (리테일 트래픽 위 광고, 한계비용 0) | ✅ |
| 퍼스트파티 데이터 (완전한 search-to-purchase) | ✅ |
| 네트워크 효과 (판매자 광고비 지출 강제) | ✅ |

**서브 비즈니스**: 스폰서드 프로덕트 ~$42B(+15~18%), 디스플레이 ~$15B(+25%), Prime Video ~$7B(+100%+, 론칭 급증), Twitch ~$4B(+10~15%).

**해자 리스크**:
- 광고 주가 승수 할인 지속 — META 25x / GOOGL 22x 대비 Amazon 광고는 embedded로 valuation 발견 지연
- Prime Video 광고 수용성 리스크 (가격 인상 여력 제한)

1. **멀티 해자 복합(4 layers) = 리스크 분산** — 클라우드 단일 노출(ORCL/Snowflake) 대비 AWS+광고+리테일+Prime 분산 → 한 레이어 훼손에도 현금흐름 방어
2. **AI 인프라 수직 통합의 TCO 우위** — Trainium/Graviton 자체 설계로 Nvidia 의존도 감소. 2027+ Nvidia vs AMZN 격차가 margin에 반영
3. **광고가 hidden margin driver** — Amazon 광고 $68B × 60% 마진 = ~$40B OI가 리테일 "저마진"에 숨겨져 있음 — SOTP 기준 가치 재발견 여지

**밸류에이션 비교 (FY25 기준 블렌디드)**:

| 지표 | AMZN | MSFT | GOOGL | WMT |
|------|------|------|------|------|
| Forward PE | ~35x | ~33x | ~22x | ~32x |
| EV/EBITDA | ~16x | ~23x | ~15x | ~17x |
| PEG | ~2.0 | ~2.5 | ~1.5 | ~3.0 |

Forward PE는 광고+리테일 peer 대비 프리미엄이나 AWS 성장 감안 시 MSFT 대비 할인은 정당. **단기 FCF Yield는 peer 최악(CapEx $200B 흡수)**이나 이는 일시적(2027~28 정상화). 진입 시점은 CapEx 사이클 peak 2026을 넘기고 2027~2028 monetization 가시화 전이 optimal.

### DCF 방법론

**적용 방식**: **B. SOTP (Sum-of-the-Parts)**

**선택 근거**: Amazon은 이익 성격이 근본적으로 다른 3개 이질 세그먼트(AWS: 고성장 고마진 클라우드 / 광고: 고마진 광고 플랫폼 / Core Retail: 저마진 E-commerce) 보유. Single FCF DCF로는 각 세그먼트의 성장·마진·멀티플 차이를 반영 불가. 특히 광고가 리테일 내 embedded되어 있어 Core 리테일의 "낮은 마진"이 광고 고수익을 가리는 구조 — SOTP만이 해체 가능.

**대안 대비 우위**:
- A. FCF DCF 부적합: $200B CapEx로 NTM FCF negative → terminal value 의존도 90%+ 초과
- C. Excess Returns 부적합: 자본 규제 없음, Book Value 중심 아님
- D. NAV 부적합: 가치 대부분이 Brand/Network/Moat 무형
- E. Forward Multiple 부적합: 단일 멀티플로는 3개 이질 세그먼트 통합 불가

**주요 가정**: WACC 8.5% (Risk-free 4.26% + MRP 5.5% × β 1.05), 예측기간 5년, 세율 23%, 희석 주식수 10.86B, Net Cash $21.2B.

```
리스크           : ⚠️ CapEx 단기 FCF 파괴 + 규제 꼬리 + 경쟁 점유율 압력
────────────────────────────────
종합 의견        : 보유 (신규 진입은 Bear 진입가 ~$190 이하 분할매수 조건부)
────────────────────────────────
핵심 모니터링:
  1. AWS YoY 성장률 (2026.04.30 Q1 실적이 최우선 catalyst)
  2. FY26 실제 CapEx 실행 속도 + AWS backlog monetization
  3. FTC 반독점 트라이얼 결과 (2026.10 시작)
```

**왜 매수가 아닌가**: 4개 독립 해자 레이어가 유지되고 AWS 가속이 확인되는 환경이지만, $200B CapEx 흡수 + FTC 트라이얼 + Azure 추격의 **3중 압력**이 2026~2027 단기 margin·FCF·멀티플에 동시 작용. 사업 구조상 Base 대비 Bull 업사이드(+$105)가 Extreme Bear 다운사이드(-$130)에 미달하는 **구조적 하방 비대칭**이 존재. Wide Moat 유지 자체가 신규 진입 근거는 되지 못하며, 현재 밸류에이션에서는 손익비가 충분하지 않음.

**왜 매도가 아닌가**: 4-layer Wide Moat 구조는 유지되고 있으며, AWS Q4 2025 +24% 가속은 13개 분기 최고치로 thesis 핵심(클라우드 + AI 해자 + 커스텀 실리콘 TCO 우위)이 오히려 강화되는 방향. 광고 +22% 성장·NA 마진 개선·International 흑자 지속·커스텀 칩 매출 $20B+ triple-digit 성장 등 **구조적 성장 드라이버가 동시 작동 중**. Thesis 무효화 증거(Moat 레이어 훼손) 없이 매도는 timing bet이며, $200B CapEx monetization이 2027+ 확인되면 Bull 방향 재평가 여지.

**분할 매수 근거** (DCF 시나리오 가격대):
- Bear 상단 $170 근접 시 첫 진입 — 손익비 개선 (Base $215 대비 업사이드 $45 / EB $85 대비 다운사이드 $85 = 0.53 → 1.0)
- Bear 중간값 $156 근접 시 추가 — (업사이드 $59 / 다운사이드 $71 = 0.83)
- Extreme Bear 상단 $105 근접 시 최대 매수 — 극단적 저평가, 다만 Divestiture 리스크 동반 확인 필요

**가장 취약한 숫자**: **Core Retail 마진 가정 (1%→3.5% Base, →5% Bull)**. 역사적으로 Amazon 리테일 마진은 자체 투자 사이클에 따라 변동이 크고(2022 음수, 2024 3~4% 회복), 5% 달성은 신기록이 필요. Robotics/AI 자동화 효과가 실제 P&L에 반영되는 시점이 불확실 — Bull 시나리오 가장 취약 지점.

### 7-3. Bear → Stress 반영 시 비교

```
Bear $156 → 단순합산 적용 시 $156 × (1-0.26) = $115
         → 동조성 보정 시     $156 × (1-0.17) = $130
         → Extreme Bear $85 와의 위치: 보정값 $130이 Bear-EB 중간
```

**시사점**:
- Stress 누적 리스크를 Bear에 반영하면 **$115~130** 범위 — Bear $156보다 낮고 Extreme Bear $85보다 높음
- Base 분석의 Bear는 stress 꼬리 리스크를 일부만 반영 — 실제 multi-shock 시 Bear-EB 중간 "Stress Bear" 구역 존재
- 단 stress는 tail 사건, 복합 실현 확률 낮음

**주의**: Revaluation 가중평균에는 반영하지 않는다. Base 파일의 가중평균 $202가 공식 내재가치.
