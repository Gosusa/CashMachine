### Intelligent Cloud

**사업 구조**: Azure(퍼블릭 클라우드 IaaS/PaaS), Windows Server/SQL Server, GitHub, 엔터프라이즈 컨설팅. Azure만으로 FY25 $75B+ (+34%), 하이퍼스케일러 2위.

| 해자 유형 | 검증 |
|---------|------|
| 효율적 규모 (CapEx) | ✅ |
| 전환비용 (RPO) | ✅ |
| 네트워크 효과 (생태계) | ✅ |
| 엔터프라이즈 관계 | ✅ |

**상세**:
- **효율적 규모**: FY26 CapEx $120B+ (Q2 단일 $37.5B, +66% YoY). 3대 하이퍼스케일러 합산 CapEx $660~690B — 신규 진입자가 10년 내 복제 불가. 전력·냉각·GPU 확보 경쟁에서 자체 OCF로 $120B+를 감당 가능한 재무체력을 가진 기업은 3개사 뿐(AWS, MSFT, GOOGL).
- **전환비용**: Commercial RPO $625B (+110% YoY)는 기존 고객 계약이 앞으로 인식할 매출의 약속 잔고. 연간 매출 $311B의 약 2배, 분기 매출의 7.7배. 평균 계약 기간 3~7년 다년 ESA 구조로 이탈 비용 막대. Fortune 500의 95%+가 MSFT 고객이며 단일 구매선에서 Azure + M365 + Security 번들 협상.
- **네트워크 효과**: Azure Marketplace, 400,000+ Microsoft Partner Network 파트너, GitHub 100M+ 개발자 → 개발자/파트너/고객 삼각 생태계. 개발자 수가 많을수록 소프트웨어 Azure 호환성 좋아지고, 이는 다시 고객 유치.
- **데이터센터 리전**: 60+ 리전 (AWS 36, GCP 42). 숫자 우위이나 리전당 용량은 비공개. 2026년 6월까지 Azure 공급 제약 지속 (경영진 공식 발표) — 수요가 공급을 초과하는 상태.

**해자 리스크**:
- **하이퍼스케일러 자본 군비경쟁**: AWS·GOOGL·META도 $80~150B 수준 CapEx. 절대 규모 우위는 유지되나 ROIC 압박 (이미 진행 중). 해자 훼손 정도 **중간** — CapEx 정당화 실패 시 단기 수익성 타격
- **전력·공급 제약**: 2026년 2H~2027까지 지속 가능성. 수요는 확인되나 배송 지연 리스크. 해자 훼손 정도 **낮음** — 수요 증명이므로 지연 문제 성격
- **OpenAI 독점관계 균열**: Feb 2026 OpenAI $50B AWS 계약 체결. MSFT "Stateless API 독점" 주장, Amazon/OpenAI "Frontier Stateful Runtime은 계약 외". 2026년 내 소송/협상 결과. 해자 훼손 정도 **중간** — MSFT 인프라 자체는 핵심 유지되나 독점성 약화

**Copilot 확장 현황**:
- 유료 seat (Dec 2025): 16.1M (+160% YoY)
- 35,000+ seat 구매 대기업 전년 대비 3배 (Coca-Cola, Fiserv, ING, NASA, PepsiCo 등)
- Q2 FY26은 seat 추가 역대 최대 분기

**해자 리스크**:
- **Google Workspace + Gemini 번들**: 중소기업·교육시장에서 가격 경쟁력. 영향 제한적이나 신규 성장 둔화 가능 (진행 중). 해자 훼손 **낮음**

### 해자 강도 판정

**MSFT = Wide Moat ✅**

**핵심 근거**:
1. **복수 독립 해자** — IC(효율적 규모+전환비용), PBP(무형자산+네트워크효과), MPC(Windows 전환비용). 한 세그먼트 훼손되어도 다른 세그먼트가 하방 방어. OpenAI 관계 균열조차 MSFT Azure 인프라 자체를 대체하지 못함.

3. **AI 전환 투자 감당 가능한 FCF** — FY25 FCF $71.6B. 하이퍼스케일러 CapEx 경쟁에서 생존 가능한 3사 중 하나. 자체 OCF로 $120B+ 투자 감당.

**주의 구간 (선행 지표)**:
- Azure 성장률 30% 하회 (현재 39% CC → 임계선 30%) → "공급 제약이 수요 제약으로 전환" 신호
- Copilot 유료 seat 성장률 YoY 60% 하회 (현재 +160%) → AI ARPU thesis 훼손 시작
- OpenAI 소송 결과 MSFT 패소 → Frontier/stateful 제품군 AWS 확정 이관

## 리스크 요인

- 가중평균 내재가치 $450는 Base 목표가 $500보다 낮음 (Bear/Extreme Bear 가중 반영 시)
- 손익비 0.70은 비대칭 투자 기준(1.5+) 대비 불충분
- CapEx/OCF 47%로 재무 체력이 AI 베팅에 묶임. FY27까지 FCF 전환 가시성 부족
- OpenAI 분쟁이 2026년 내 결론 나기 전까지는 해자의 AI 레이어 불확실성 존재

### 왜 매도가 아닌가
- Wide Moat 재확인. 3개 독립 해자가 여전히 작동 (OpenAI 균열조차 Azure 인프라 자체 대체 못함)
- M365·Security·Windows base는 AI 리스크와 독립 (FY25 매출 ~50%)
- FY25 FCF $71.6B의 구조적 현금창출력 유효
- Commercial RPO $625B (+110%)의 압도적 백로그 가시성
- 최근 -24% 조정으로 Forward PE 20x는 역사 저점 근처

### 분할 매수 근거
- Bear 수준 $270~$380 구간 진입 시 손익비 개선:
  - 현재가 $422 → Base $500: +18%, Bear $270: -36% (손익비 0.5)
  - $360 근처: Base $500 대비 +39%, Bear $270 대비 -25% (손익비 1.55 → 매수 영역)
- Q3 FY26 실적(2026.4.29) 결과에 따라 Bear 트리거 발동 가능
- 20% 할인(가중평균 $450 대비) = $360 = 강력 매수 영역

### 가장 취약한 숫자
- **CapEx/OCF 47%** — 이 수치가 55% 돌파 시 재무 건전성 재평가
- **Azure 성장률 CC 39%** — 30% 하회 시 해자의 "효율적 규모" 가정 자체 의심
- **Copilot 활성률 35.8%** — AI ARPU 상승 thesis의 증명 구간

**재무/밸류에이션 충격**: FY28 OI 마진 48% → 40% (-8%pt). FY28 Net Income ~$170B (Base 대비 -25%). FY28 EPS ~$24 × Exit PE 15x = $360 undiscounted. 3년 discount $280.

**버티는 근거**: Commercial RPO $625B 유효계약 (Azure 외 M365·Security 다각화). M365 구독 매출은 AI 독립 (연 $150B+). CapEx 30~40% 감축 여력. 자사주 매입 연 $30B로 EPS 방어.

**관찰 지표**: Microsoft Cloud 마진 45% → 40% 하회, Azure AI Services "multi-billion" 언급 감소, 3대 하이퍼스케일러 CapEx/매출 % 상승, Inference 가격 30%+ 하락.

**재무/밸류에이션 충격**: Azure AI Services 성장률 Bull 가정 40%+ → 20% 하락. FY28 Azure 매출 영향 Base 대비 -8~-12% ($200B 기준 -$20B). FY28 Revenue $400B → $380B (-5%). 멀티플 재평가 26x → 22x.

**버티는 근거**: OpenAI 지분 49% 보유 가치($360B 이론값) Balance Sheet에 남음. MSFT 자체 AI 모델(MAI, Phi, Suleyman 체제) 개발 중. Azure 멀티모델 호스팅 가능 (Anthropic, Mistral).

**취약 근거**: 2023~2025년 Azure 차별화의 핵심이 OpenAI 독점이었음. Copilot 제품군은 GPT 기능에 tightly coupled. 자체 MAI 모델 GPT급 성능 달성 불확실.

**관찰 지표**: OpenAI 소송 진행, OpenAI 공식 발표에서 Azure exclusive 표현 변화, MSFT MAI 모델 출시/벤치마크, Copilot 가격 정책 변화.

### Bear DCF 시뮬레이션 합산

| # | 시나리오 | 충격 | 실현가능성 | Bear 기여 ($) |
|---|---------|------|---------|---------|
| 1 | AI ROIC 붕괴 | -44% | 15% | -$17.9 |
| 2 | OpenAI 완전 이탈 | -20% | 30% | -$16.2 |
| 3 | 전력·공급 장기화 | -16% | 25% | -$10.8 |
| 4 | 규제 동시 강화 | -12% | 20% | -$6.4 |
| 5 | 금리+침체 조합 | -40% | 20% | -$21.6 |
|   | **단순 합산** |   |    | **-$72.9** |

**동조성 해석**:
- 시나리오 1(AI ROIC) ↔ 시나리오 2(OpenAI 이탈): 강한 양의 상관 — AI 수요 전반 둔화 or AI 차별화 소멸은 연결됨. 동시 현실화 시 이중 반영 주의
- 시나리오 1 ↔ 시나리오 5(금리+침체): 중간 상관 — 경기 둔화가 AI 투자 정당화 실패 촉진
- 시나리오 3(공급) ↔ 시나리오 5: 독립 — 공급은 물리적, 거시는 재무적
- 시나리오 4(규제): 대부분 다른 시나리오와 독립적으로 작동
- 시나리오 1+2 조합 실현 확률 ≈ 10%로 조합 영향 ~$35
- 동조성 보정 후 Bear 기여: 약 **-$55~$60**

### Bear → Stress 반영 시 비교

```
Base 파일 Bear 중간값 (25%):      $270
Base 파일 Extreme Bear (10%):     $175
────────────────────────────────────────────
Stress 단순합산 적용 시 Bear:  $270 − $72.9 = $197
Stress 동조성 보정 시 Bear:    $270 − $57  = $213
────────────────────────────────────────────
→ 단순합산 시 Extreme Bear $175와 유사
→ 동조성 보정 시 Bear 하단 근처
→ Extreme Bear 대비 동조성 보정 값이 +$38 높음
```

**시사점**:
- Bear에 Stress 모두 반영 시 Extreme Bear($175)에 근접($197~$213)
- Base의 Extreme Bear가 이미 이런 tail 리스크를 종합 반영 중임을 시사
- Stress 테스트의 가장 큰 기여 시나리오: S1(AI ROIC), S5(금리+침체) — MSFT thesis의 가장 취약 지점
- **주의**: 이 시뮬레이션은 Revaluation 가중평균에 반영하지 않는다. "만약 모든 tail을 동시 가중했다면 Bear가 얼마나 더 깊어지는가"를 점검하는 참고 시뮬레이션이다.
