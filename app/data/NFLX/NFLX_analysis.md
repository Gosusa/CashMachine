# NFLX — Netflix, Inc.
> 글로벌 1위 SVOD 스트리밍 플랫폼(유료 회원 325M+, 2025.12). FY2025 매출 $45.2B (+15.9% YoY), 영업이익률 29.5%, FCF $9.46B(+36.7%). 2026 가이던스 매출 $50.7~51.7B(12~14%), OM 31.5%, 광고 매출 ~2배($1.5B → $3B). 2025.11 10-for-1 액면분할 완료(post-split 4.22B 주식).

## 투자 thesis

- **325M 글로벌 유료 회원 + 압도적 시청 시간 점유율** → 네트워크 효과 + 데이터 무형 자산: Family DAU 약 700M+ 추정, Q1 2026 매출 $12.25B(+16.2%), OM 32.3%(전년 31.7% 대비 +0.6%pt). 콘텐츠 추천 알고리즘 + 글로벌 카탈로그 규모로 시청 효율성에서 구조적 우위.
- **광고 사업 본격 가속 + 가격 결정력 동시 작동** → 데이터 무형 자산 + 효율적 규모: 광고 지원 티어 MAU 94M(2025.Q4), FY25 광고 매출 $1.5B+(+150% YoY), 2026 가이던스 ~$3B. Trade Desk·Magnite·Google DV360 12개 시장 통합 + 자체 Ads Suite 출시. 2025년 미국·캐나다 가격 인상에도 churn 통제.
- **콘텐츠 투자 규모 + FCF 전환 동시 달성** → 효율적 규모 + 진입장벽: 2026 콘텐츠 지출 $20B 계획 — Disney+ ~$24B / WBD ~$15B / AMZN ~$15B+ 대비 글로벌 단일 플랫폼 효율 1위. WWE 10년 $10B + NFL Christmas + MLB + FIFA 라이브 스포츠 진입. FY25 FCF $9.46B로 콘텐츠 비용 자체 조달 + 자사주 매입 능력 확보.

### 구독 매출 — 네트워크 효과 + 데이터 무형 자산 + 브랜드

**사업 구조**: 글로벌 190+ 국가 단일 스트리밍 서비스. Standard $15.49/월, Premium $24.99/월, Basic with Ads $7.99/월 (미국 기준). 2025.Q1 미국·캐나다 가격 인상(2024 → 2025 약 14%) 후에도 분기당 +5M+ 신규 가입자 추가 추정. ARM $10.82(FY24) → $11.70(FY25) +8% 성장.

| 해자 유형 | 검증 |
|---------|------|
| 네트워크 효과 (콘텐츠 카탈로그 ↔ 사용자 규모) | ✅ |
| 데이터 무형 자산 (추천 알고리즘) | ✅ |
| 브랜드 (콘텐츠 큐레이션 신뢰) | ✅ |
| 전환비용 (시청 이력·프로필) | ✅ |
| 효율적 규모 (콘텐츠 단가 분산) | ✅ |

**상세 근거**:
- **네트워크 효과**: 325M 회원 × 연 콘텐츠 가치 = 콘텐츠 투자 $20B 자체 조달. 사용자 규모가 콘텐츠 투자 규모를 정당화하고, 콘텐츠 규모가 사용자 유치 — Disney+ 127M / Max 122M / Prime Video 200M+ 대비 압도적 단위 경제성. 콘텐츠비/회원: NFLX $61.5 vs Disney $189 (3배 효율).
- **데이터 무형 자산**: 20년 누적 시청 행동 로그(시청 시작·중단·완료·평점·검색·시간대). 글로벌 단일 카탈로그에서 학습한 추천 모델은 신규 콘텐츠 ROI 사전 예측. Nielsen US streaming 시청 시간 점유율 8.0% (Q4 2025) — 1인당 시청 효율성 1위.
- **브랜드**: "Netflix and chill"이 일상 표현으로 정착. Stranger Things·Squid Game·Wednesday 등 글로벌 컬쳐럴 인덱스 보유 — Disney·Max는 IP 의존, Netflix는 신규 IP 창출 능력 입증.
- **전환비용**: 5명 멀티 프로필 + 시청 진행 + Watchlist + 추천 알고리즘 학습 — 타 플랫폼 이동 시 모두 리셋. 가족 공유 정착 → ARM $11.70 유지.
- **효율적 규모**: 콘텐츠 $20B / 325M 회원 = 회원당 $61.5/년. Disney $24B / 127M = $189 — Netflix가 3배 효율.

**해자 리스크 (해자 훼손 관점)**:
- **분기 가입자 공시 중단(2025.Q1 시작)** — 시장이 회원 모멘텀을 직접 검증할 수 없음. 정보 투명성 약화. 진행 중
- **콘텐츠 hit-driven 변동성** — Stranger Things·Squid Game 메가히트 의존도. 차세대 IP 전환 실패 시 시청 시간 점유율 단기 침식. 2026~2027
- **가격 인상 한계 도달** — UCAN Premium $24.99 OTT 최고 수준. 추가 인상 시 churn 위험. 2026~2028

### 광고 지원 티어 — 데이터 무형 자산 + 효율적 규모

**사업 구조**: 2022.11 Basic with Ads 출시. 2025.Q4 MAU 94M (2024.Q4 70M → +34%). Trade Desk·Magnite·Google DV360 12개 시장 통합(2025.Q2 완료) + 자체 Ads Suite 가동. 2026년 Pause Ads + Interactive Mid-rolls(GenAI) 출시 예정. 신규 가입자의 55%+ 광고 티어 선택(2025).

| 해자 유형 | 검증 |
|---------|------|
| 데이터 무형 자산 (시청 데이터 → 광고 타겟팅) | ✅ |
| 효율적 규모 (광고주 수요 풀) | ✅ |
| 광고 시장 통합 인프라 (Trade Desk·Magnite·DV360) | ✅ |
| 콘텐츠 차별화 (신생, 약함) | ⚠️ — Hulu·Peacock·Max 광고 티어와 동일 경쟁 구도. 콘텐츠 차별화 효과 제한적 |

**상세 근거**:
- 글로벌 시청 행동 데이터를 광고 타겟팅에 활용 — 콘텐츠·시청 맥락 기반 프리미엄 광고 단가 가능
- 94M MAU + 95% 광고 시청 완료율(전통 TV 대비 우위)
- 2026 광고 매출 ~$3B = 글로벌 CTV 광고 시장 ~$30B의 10% 점유 추정
- 광고 인프라는 표준화됨 — 차별화는 콘텐츠 + 시청 데이터에 의존. YouTube $30B+ 광고 매출 절대 규모는 NFLX의 20배 — 절대 격차 큼

**해자 리스크 (해자 훼손 관점)**:
- **광고 시장 침투 속도 둔화** — Q4 2025 글로벌 광고 매출 분석가 예상 +81.5% 대비 +79.1% 미달 (-1.3%). 2026 ~$3B 가이던스 미달 시 Bull 시나리오 약화. 2026 즉시
- **Hulu·Peacock·Max 광고 티어와 가격 경쟁** — 광고 티어는 콘텐츠 가치보다 가격·접근성 경쟁. 2026~2028
- **광고 매출의 매크로 의존** — GDP·소비 지출 연동, 경기 둔화 시 즉각 압박. 매크로 사이클

### 콘텐츠 IP / 라이브 스포츠 — 무형 자산(IP) + 독점 라이센스

**사업 구조**: 자체 제작 오리지널(Stranger Things·Squid Game·Wednesday·Bridgerton) + 라이선스 콘텐츠 + 라이브 스포츠 신규 진입(WWE Raw 10년 $10B 독점, NFL Christmas 마지막 시즌, MLB·FIFA 부분 권리). 2026 콘텐츠 지출 $20B (2025 $18B → +11%). Net Content Assets $32B (FY25 BS).

| 해자 유형 | 검증 |
|---------|------|
| 무형 자산 (IP 라이브러리) | ✅ |
| 독점 라이브 스포츠 라이센스 | ✅ |
| 자체 제작 인프라 (스튜디오, 글로벌) | ✅ |

**상세 근거**:
- 다년간 누적 오리지널 IP 자산 — 단년 콘텐츠 지출 $20B는 Disney $24B 대비 적으나 글로벌 가입자 1위 + 효율적 자산 회전에서 우위
- WWE Raw US/Canada/UK 10년 $10B 독점 — Linear TV 경쟁자 봉쇄
- Albuquerque·런던·서울·마드리드 자체 스튜디오 — 외부 라이선스 의존도 점진 감소

**해자 리스크 (해자 훼손 관점)**:
- **라이브 스포츠 권리 비용 인플레이션** — WWE $10B/10년 = $1B/년. NBA·UFC·MLS 진입 시 추가 $20~50B 권리 비용. 2027~2029
- **WBD 인수 실패 후 IP 라이브러리 격차** — Netflix가 WBD 인수 실패(Paramount에 패배, 2026.2). HBO·DC·Warner 라이브러리 미확보. Paramount+WBD 합병 후 통합 카탈로그가 Netflix와 경쟁. 2026.Q3+
- **YouTube 시청 시간 침식** — Nielsen 2025 데이터: YouTube 미국 TV 시청 시간 12.5%로 Netflix 8% 대비 1.5배 초과. UGC + 쇼츠가 SVOD 시청 시간 잠식. 진행 중

### 해자 강도 판정

**최종 판정**: NFLX = **Wide Moat ✅** (주의 구간 다수)

**핵심 근거**:

- 분기 매출 YoY 성장률 (현재 +16~18% → 12% 이하 시 경고)

- Nielsen 시청 시간 점유율 (현재 8% → 7% 이하 하락 시 콘텐츠 해자 약화 신호)

- **OM 29.5% vs Disney DTC 10%** — SVOD 사업 수익성에서 NFLX가 6년 선행
- **시청 시간 점유율은 YouTube에 1.5배 열위** — SVOD 카테고리에서는 NFLX 1위이나, 종합 스트리밍에서 YouTube에 추월. 광고 사업 경쟁자
- **라이브 스포츠는 NFLX 후발 주자** — NBA·NFL Sunday Ticket·UFC 등 메이저 권리는 Disney·Amazon·Apple 보유. 추가 권리 인수 시 콘텐츠비 압박

### 경쟁 우위 원천

**1. 글로벌 단일 카탈로그 + 콘텐츠 효율 3배 우위**
- 우위 내용: 단일 라이브러리 글로벌 배포(190+ 국가). 한국 Squid Game이 미국·유럽·LATAM에서 동시 시청. Disney·WBD는 지역별 콘텐츠 권리 분리로 효율 낮음
- 정량 근거: 콘텐츠비/회원 $61.5(NFLX) vs $189(Disney+) vs $75(Prime). 콘텐츠 amortization/매출 33%
- 경쟁사 격차: Disney·WBD 합병 후에도 콘텐츠비/회원 ~$75 추정 → NFLX 효율 1.2배 격차 유지
- 복제 난이도: 매우 높음
- 격차 지속 기간 추정: **10년+** (구조적 해자)

**2. 추천 알고리즘 + 시청 데이터 자산**
- 우위 내용: 20년 누적 글로벌 시청 행동 데이터. 신규 콘텐츠 ROI 사전 예측 + 광고 타겟팅 활용
- 정량 근거: Nielsen US streaming 시청 시간 점유율 8%, 신규 가입자 55%+ 광고 티어 선택
- 경쟁사 격차: Disney·WBD 알고리즘은 단일 플랫폼 데이터, Amazon은 거래 데이터 강점이나 시청 데이터는 NFLX 우위
- 복제 난이도: 높음
- 격차 지속 기간 추정: **5~10년**

**3. 가격 결정력 (브랜드 + 전환비용 결합)**
- 우위 내용: 2024.Q1 → 2025.Q1 약 14% 가격 인상에도 분기 가입자 +5M+ 유지. 콘텐츠 가치 기반 가격 결정력
- 정량 근거: ARM $10.82 → $11.70 (+8%), Premium 티어 $24.99/월 (OTT 최고가)
- 경쟁사 격차: Disney+는 가격 인상 후 가입자 둔화. Max·Paramount+ 전환기 가격 압박
- 복제 난이도: 중간
- 격차 지속 기간 추정: **3~5년** (가격 천장 도달 가능성)

**4. 광고 사업 신생 가속 — 단, YouTube 대비 절대 규모 열위**
- 우위 내용: 94M MAU 광고 티어 + Trade Desk·Magnite 통합 + Ads Suite 자체 플랫폼
- 정량 근거: FY25 광고 매출 $1.5B (+150%), 2026 ~$3B 가이던스
- 경쟁사 격차: YouTube 광고 매출 $30B+ — 절대 규모 NFLX의 20배. Hulu/Disney + Prime Video 광고도 NFLX와 유사 또는 우위
- 복제 난이도: 낮음 (광고 인프라는 표준화됨)
- 격차 지속 기간 추정: **불확실** (2~3년 내 직접 경쟁 심화)

- **적용 방식**: A. Standard FCF DCF (주) + E. Forward Multiple (교차검증)
- **선택 근거**: NFLX는 단일 사업(글로벌 SVOD + 광고)으로 안정적 FCF 생성($9.46B FY25, +36.7% YoY), 자본집약도 예측 가능, 성숙 단계 진입. "안정적 FCF 생성 + 단일 사업 + 성숙 단계 → A. Standard FCF DCF" 일치
- **대안 대비 우위**: B. SOTP 부적합(단일 사업), D. NAV 부적합(콘텐츠 자산 가치의 핵심 동인 아님), E. Forward Multiple은 보조 활용(Terminal Value 비중 70%+ 가능)
- **주요 가정**: WACC 9% (RFR 4.31% + ERP 5% × Beta 1.0 + 0.4 자체), Terminal g 3% (장기 GDP 상한), 세율 17%, 예측 기간 5년 (2026~2030)

### Bear → Stress 반영 시 비교

```
Base 파일 시나리오 중간값:
- Bear 목표가: $75
- Extreme Bear 목표가: $48

Bear $75 → 단순합산 적용 시: $75 × (1 - 0.222) = $58
Bear $75 → 동조성 보정 적용 시: $75 × (1 - 0.144) = $64
                                                   (vs Extreme Bear $48)
```

**시사점**:
- 동조성 보정 시 Bear 충격 $75 → $64 (-15%). Extreme Bear $48 와 Bear $75 사이 ($61) 위치
- 5개 스트레스 시나리오 단순 합산 시 Bear 충격이 Extreme Bear보다 깊어짐 ($58 < $48 — 비현실적) → 동조성 보정 필수
- **본 가중평균 내재가치 계산에는 반영하지 않는다** — "만약 모든 외생 충격이 동시 실현되면 Bear가 어디까지 깊어지는가"를 점검하는 참고 시뮬레이션

**활용 방법**:
- 신규 매수 진입 시 Bear $75뿐 아니라 동조성 보정 Bear $64 부근까지 분할 매수 여력 확보 권장
- 다음 분기 실적 발표 (Q2 2026, 2026.7) 후 시나리오별 실현가능성 재평가
