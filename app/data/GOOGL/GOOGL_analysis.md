# GOOGL — Alphabet Inc.
> 글로벌 1위 검색 플랫폼(Google 검색점유율 90%) + 3위 퍼블릭 클라우드(GCP 런레이트 $70B, +48% YoY) + Waymo 자율주행($126B 외부 평가)을 보유한 AI-우선 수직통합 플랫폼. FY2025 매출 $402.8B (+15% YoY), 영업이익률 31.6%.

## 투자 thesis

- **90% 점유 Google Search + Gemini AI 재방어 성공** → 무형 자산(브랜드·데이터) + 네트워크 효과 + 전환비용: Google 글로벌 검색점유율 90.01% (StatCounter, 2026.3), Q4 FY25 Search & Other 매출 +17% YoY. Gemini MAU 750M 돌파(Q4 FY25), AI 챗봇 점유율 5.4%→18.2% (vs ChatGPT 87%→68%) — "검색 캐니벌라이제이션" 내러티브 실패
- **Google Cloud 수익화 변곡점 진입** → 효율적 규모 + 전환비용: Q4 FY25 Cloud 매출 $17.7B (+48% YoY), 영업이익률 30.1% (YA 17.5%, +1,260bp), 클라우드 백로그 $240B (+55% QoQ) — 향후 4~5년 매출 가시성 확보
- **YouTube + Waymo + DeepMind의 옵셔널 가치** → Float 우위 + 무형 자산: YouTube 연매출 $60B+ 돌파(Netflix $45B 상회), Waymo $126B 외부 평가(2026.2 $16B 라운드), Gemini 3가 OpenAI 대비 기술 리더십 탈환

### Google Services

**사업 구조**: Search 광고(전사 매출 ~55%), YouTube 광고/구독(~15%), Google Network 광고(~7%), Subscriptions·Platforms·Devices(~15%). Q4 FY25 Search & Other +17%, YouTube ads +9%, 구독·플랫폼 +17% 성장 — AI Overviews 모니터리제이션이 Search 성장을 재가속했다는 실증.

| 해자 유형 | 검증 |
|---------|------|
| 브랜드 (무형 자산) | ✅ |
| 데이터 자산 (무형 자산) | ✅ |
| 네트워크 효과 | ✅ |
| 전환비용 | ✅ |
| 효율적 규모 | ✅ |

- **브랜드**: "Google"은 Interbrand 2024 글로벌 브랜드 Top 3, "Google it"이 동사화된 유일한 검색 브랜드. 글로벌 검색 점유율 90.01% (StatCounter 2026.3). ChatGPT 등장 후에도 쿼리 80% 이상 유지한 유일한 검색엔진.
- **데이터 자산**: 25년 누적 검색 로그, 10억+ 안드로이드 기기, YouTube 시청 이력 — Gemini 훈련에 직접 활용되는 독점 데이터. 하이퍼스케일러 중 가장 폭넓은 소비자 신호 보유. Bing 4.98%, Yahoo 1.39%는 인덱스·신호 규모에서 도달 불가.
- **네트워크 효과**: 검색(더 많은 검색 → 더 나은 결과 → 더 많은 광고주), YouTube(2B+ 로그인 유저 → 크리에이터 유입 → 더 많은 시청), Android 개발자·OEM 생태계.
- **전환비용**: Gmail/Drive/Calendar/Photos 개인 데이터 락인, Workspace 기업 전환비용, 안드로이드 사용자의 Play 결제·이력 연동.
- **효율적 규모**: 검색 인덱싱·YouTube CDN·광고 옥션 인프라의 고정비가 수십억 쿼리·시청에 분산 → 한계비용 near-zero. 2~3위 경쟁자 진입 불가 구조.

**하위 매출 규모 (FY25 추정)**: Search & Other $220~225B (+17%), YouTube 광고 $36~38B (+9%, FY25 YouTube 총매출 $60B 돌파 — Netflix $45B 상회), YouTube 구독 $22~25B (+17%), Google Network $29~31B (저성장, Q4 전사 +18% 대비 상당 폭 하회), Subscriptions/Play/Devices $40~45B (+17%).

**해자 리스크 (훼손 관점)**:
- **AI 검색 cannibalization 재부상**: 현재까지 방어 성공(Q4 Search +17%, Gemini MAU 750M). 그러나 OpenAI SearchGPT + Perplexity + Anthropic Claude Web가 정보성 쿼리(전체 ~35~40%)를 계속 잠식. 네비게이셔널·상거래 쿼리는 Google 유지, 정보성 쿼리는 AI로 이동 트렌드. 현실화 시점 진행 중 (2026~2028).
- **DOJ 항소 Chrome 분할 리스크 재점화**: 2025.9 Mehta 1심은 Chrome 분할 기각, 2026.2 DOJ 항소. Morgan Stanley 추정 의무적 선택화면만으로도 Search 트래픽 -5~8% → 연 $15~25B 광고 매출 위험. 현실화 2027~2028.
- **DMA / 글로벌 규제 중복**: EU DMA, 영국 CMA, 일본 경쟁당국이 Android·Chrome·Play 수수료 타겟. 누적 준수 비용 증가 진행 중.
- **Google Network 성장 둔화 (⚠️ 해자 균열 조짐)**: Q4 Network 성장 저조, 전사 +18% 대비 상당 폭 하회 — 서드파티 광고 생태계에서의 구조적 약화 조짐.

### Google Cloud

**사업 구조**: Google Cloud Platform(GCP 인프라·AI·데이터) + Google Workspace(SaaS). Q4 FY25 매출 $17.7B (+48% YoY), 영업이익률 30.1% (YA 17.5%, +1,260bp 개선). **백로그 $240B (+55% QoQ from $155B)** — 향후 4~5년 매출 가시성 확보. 연간 런레이트 $70B. AWS/Azure 대비 하이퍼그로스 구간 지속.

| 해자 유형 | 검증 |
|---------|------|
| 전환비용 (엔터프라이즈) | ✅ |
| 효율적 규모 | ✅ |
| AI 무형 자산 | ✅ |

- **전환비용**: 데이터 마이그레이션 비용, BigQuery·Spanner 독점 아키텍처 락인, Kubernetes/AI API 엔지니어링 투자 — 엔터프라이즈는 한 번 GCP에 들어가면 이동 비용이 매출의 수십 %에 달함.
- **효율적 규모**: CapEx FY25 $91.4B(+74% YoY), 자체 TPU 설계로 NVIDIA 의존 부분 탈피 — GPU 부족 구간 경쟁사 대비 공급력 우위.
- **AI 무형 자산**: DeepMind + Google Research + Gemini 3 — AI 모델 성능에서 OpenAI와 동급 또는 우위 영역(멀티모달, 장기 컨텍스트). 네이티브 GCP 통합으로 엔터프라이즈 AI 수요 흡수.

**해자 리스크 (훼손 관점)**:
- **하이퍼스케일러 자본 군비경쟁**: 2026 CapEx 가이던스 $175~185B (FY25 $91.4B 대비 +92%). SemiAnalysis CEO 경고 "Google FCF 2026년 zero까지 하락 가능"(247wallst 2026.4). 현실화 진행 중.
- **GCP OM 지속성 검증 필요**: Q4 OM 30.1%가 일회성이 아닌지 검증 필요. AWS 구조적 OM 35~37%, Azure 45%+ 추정 — Google이 동급 도달까지 2~3년 필요. 2026~2027 검증 구간.
- **NVIDIA 의존/공급 병목**: TPU 자체 설계로 부분 탈피하나 하이엔드 AI 훈련 여전히 NVIDIA H100/H200 의존 비중 큼.

### 해자 강도 판정

**GOOGL = Wide Moat ✅**

핵심 근거 3가지:
① **시간 지평**: Google Search 90% 점유는 브랜드·데이터·네트워크 효과·전환비용의 다중 해자에 기반 — 단일 규제·AI 경쟁자 한 축으로 와해 불가. Gemini MAU 750M·AI 챗봇 5.4%→18.2%는 AI 시대 방어 성공의 실증.
② **전략적 헤지**: Services(현금엔진, 마진 39%) + Cloud(고성장, 이익 확장 초기, OM 30%) + Waymo/Other Bets(옵셔널 외부 평가 $126B) — 3단 구조가 성장 단계별 분산. AWS/Azure·OpenAI·Tesla 모두와 동시 경쟁 가능한 유일한 기업.
③ **AI 수직통합**: DeepMind + Gemini 3 + TPU 자체 설계 + YouTube 훈련 데이터 + GCP 배포 채널 — 상위 6단 수직통합은 경쟁사 복제 불가. 2027~2030 AI 응용 수익화 단계 진입 시 해자 증폭.

**주의 구간 (Wide 균열 선행 지표)**:
- Search & Other YoY 10% 하회 (현재 +17%, 한 자릿수 진입 시 AI 이탈 본격화 시그널)
- GCP OM 25% 하회 2분기 연속 (Q4 30.1% 후퇴 → 가격 전쟁 재점화 신호)
- DOJ 항소심 Chrome 분할 판결 (Base 가정 즉시 무효화 트리거)
- CapEx/매출 비중 30%+ 영구화 (FCF 생성력 구조적 훼손)

### 경쟁 우위 원천 분석

**1. Search 인덱스 + 데이터 자산 (25년 누적)**
- 우위: 웹 전체 크롤 인덱스, YouTube 시청 로그, 안드로이드 10억 기기 데이터, Gmail/Photos 등 개인 데이터 — Gemini 훈련의 독점 재료
- 정량 근거: 글로벌 검색 점유율 90.01%, YouTube 2B+ 로그인 유저
- 격차: Bing 4.98%, ChatGPT는 Bing 인덱스 의존 — 결국 Google 인덱스에 독립 불가
- 복제 난이도 매우 높음, 격차 지속 **10~15년** (규제 리스크 = 데이터 공유 의무만이 약화 요인)

**2. AI 수직통합 (DeepMind → Gemini → TPU → GCP → 배포채널)**
- 우위: AI 모델 연구(DeepMind) → 범용 모델(Gemini) → 전용 하드웨어(TPU) → 자체 클라우드(GCP) → Search/Chrome/Android/Workspace/YouTube 5채널 배포
- 정량 근거: Gemini 챗봇 12개월 5.4%→18.2%, Q4 Cloud OM 30.1%
- 복제 난이도 매우 높음, 격차 지속 **7~10년** — 5단 전부 소유하는 기업 Alphabet 유일

**3. YouTube 동영상 플랫폼**

## 가치평가

### DCF 방법론

- **적용 방식**: **B. SOTP (Sum-of-the-Parts)** + FCF DCF 교차검증
- **선택 근거**: Alphabet은 성격·멀티플·수익성이 근본적으로 다른 3개 세그먼트(Services, Cloud, Other Bets) 구조. **Services**는 성숙 광고 캐시카우(매출 +14%, OM 39%, PE 23~26x), **Cloud**는 하이퍼그로스·이익 변곡(매출 +48%, OM 17.5→30.1% 변곡 중, 엔터프라이즈 SaaS 멀티플 7~9x 매출), **Other Bets(Waymo)** 는 외부 평가액 존재하는 옵셔널 자산($126B, 2026.2 $16B 라운드). 3 세그먼트 이익 구조가 근본적으로 달라 단일 FCF DCF로 통합 시 Cloud의 수익성 변곡과 Waymo 옵셔널 가치가 왜곡.
- **대안 대비 우위**:
  - FCF DCF 부적합: 통합 FCF는 2026 CapEx $175~185B로 일시적 왜곡 — Cloud 내재 성장 가치가 CapEx 부담에 가려짐. Waymo 같은 비영업자산 외부 평가 가치를 무시.
  - Forward Multiple 부적합: Services·Cloud 모두 이미 안정적 FCF·OI 발생 — Forward Multiple은 초기·적자 기업용.
  - NAV 부적합: Alphabet은 부동산·자원기반 아님.
- **주요 가정**:
  - WACC 8.0% (Rf 4.26% + Beta 1.10 × ERP 5% = 9.76% Ke. Alphabet 순현금 $95B+ 구조로 유효 WACC 하향)
  - Terminal g 3.0%
  - 세율 16% (FY25 실효세율)
  - 예측 기간 5년 (FY26E~FY30E)
  - Services 멀티플(세후 OI): 정상 20~24x, 스트레스 15~18x
  - Cloud 멀티플(Forward 매출): 정상 7~9x, 스트레스 5~6x
  - Waymo 지분 평가: 외부 $126B × Alphabet 85% × 30% 유동성 할인 = $75B
  - 희석 주식수: 12.2B (Q3 FY25), 연 -1.5% → FY30 11.35B

### 시나리오별 스트레스 테스트

#### 시나리오 1 — DOJ 항소심 극단: Chrome 분할 확정

**가정**: 2027 초 DOJ 항소심에서 Chrome 브라우저 분할 명령 최종 확정(1심 기각 → 2심 번복). Android 배포 조건 수정 및 Apple Safari 독점 검색 엔진 계약(연 $20B+) 금지. 글로벌 규제당국(EU CMA·영국 CMA)이 판례 인용해 연쇄 구조 분리. Chrome 64% 글로벌 브라우저 점유율이 2~3년 내 55% 이하로 하락.

**재무/밸류에이션 충격**: Search 트래픽 -12~15%(Morgan Stanley 선택화면 단독 -5~8% × 2x), Search 광고 매출 -$29B 영구 손실, Apple TAC $20B 금지, Services OM 39%→26%, Services PE 21x→14x. 주가 충격 **-40~50%**(Services 가치 $3,486B → $1,190B).

**버티는 근거**:
- YouTube·Cloud·Waymo 비 Search 자산의 구조적 다각화 (FY25 Services ex-Search ~$125B)
- 순현금 $95B + Cloud·Waymo 옵셔널 가치로 fire-sale 방어
- Chrome 분할 후에도 Gmail/YouTube/Android 무료 서비스가 검색 유입 대체 채널
- Gemini·AI Mode가 Chrome 외부에서도 Google 디폴트 검색 유지 잠재력

**취약 근거**:
- Search 매출 Alphabet 전사 ~55% 비중 — 해자 중심축 직타
- Apple 계약 해제 시 iOS(프리미엄 유저 20%+) 유입 즉시 상실
- Chrome 분할은 선례 없는 규제 — 시장이 선반영 못한 꼬리 사건
- 1심 기각된 구조적 remedy가 부활 시 투자자 신뢰 손상

**관찰 지표**: DOJ 항소심 일정(2026 말~2027 초), Morgan Stanley·Wells Fargo·BofA 규제 리스크 멀티플 할인 리서치, Apple 검색 엔진 디폴트 계약 갱신 조건, Chrome 글로벌 브라우저 점유율(StatCounter 분기), EU CMA·영국 CMA 조치.

**실현 가능성 15%**: 1심 Chrome 분할 명백히 기각. 항소심이 원심 기각을 뒤집는 역사적 확률 낮음(MS 2000 외 거의 없음). 그러나 DOJ 적극적 항소 + 정치 지형 변수로 꼬리 사건 확률 0이 아님. **Bear DCF 기여 -6.75%pt**.

#### 시나리오 2 — AI 검색 파괴적 이탈 (OpenAI/Perplexity 대약진)

**가정**: 2026~2028 사이 OpenAI SearchGPT + Perplexity + Claude Web이 정보성 쿼리(전체 35~40%)의 20~30%를 영구 잠식. Apple이 iOS 기본 Siri에 ChatGPT·Perplexity 네이티브 통합(2027). Gen Z 검색 주도권이 AI 챗봇으로 이동. AI Overviews 방어 실패 — CPC·CTR 동반 하락.

**재무/밸류에이션 충격**: Search 쿼리 볼륨 -15~20%(정보성 기준) → 광고 매출 -10~12%, $220B → $195B. YouTube 광고 성장 둔화(+9% → +3~5%). Services OM -400bp, Services PE 21x → 16x. 주가 충격 **-35~45%**(Services 가치 $3,486B → $1,472B).

**버티는 근거**:
- 네비게이셔널(25%)·상거래(35%)·로컬 쿼리 = 고마진 광고 슬롯 60%+ Google 유지 기대

**취약 근거**:

**관찰 지표**: Similarweb AI 챗봇 트래픽 점유율(Gemini vs ChatGPT vs Perplexity), Google 글로벌 검색 점유율(90% 하회 경계), Search & Other YoY(+15% 하회 경계), CPC/RPM 추이, Apple WWDC Siri 파트너십, Gen Z(18~24세) 검색 엔진 선호도(eMarketer 분기).

**실현 가능성 25%**: AI 검색 잠식 진행 중이나 "정보성 30% 영구 이탈" 조합은 중간 확률. Gemini 3 기술 우위로 일정 부분 방어 중. 기술 사이클 1~2년이면 반전 가능. **Bear DCF 기여 -10.0%pt**.

#### 시나리오 3 — AI CapEx 과잉 투자·FCF 붕괴

**가정**: 2026 CapEx $175~185B **+30% 추가 상향** → $225~240B. 2027 CapEx도 $200B+ 지속. 데이터센터 전력·부품·인력 병목으로 실효 투자수익률 저하(TPU/GPU 과잉 설비). AI 수요가 CapEx 증가를 못 따라감 → Cloud 수익성 변곡 지연. SemiAnalysis 경고(2026.4) 현실화: FCF 2026년 near-zero 및 2027년 미회복.

**재무/밸류에이션 충격**: FCF FY26E $73B → **-$5~10B**(자사주매입/배당 중단 리스크), FY27~28 FCF $30~50B. Cloud OM 30.1% → 22~25%. Net Debt 순현금 $95B → 0~순부채 $30B. 신용 스프레드 확대 + WACC +100bp → 9%. Cloud EV/매출 7.5x → 5x. 주가 충격 **-25~35%**(Cloud 가치 $1,373B → $750B).

**버티는 근거**:
- Q4 FY25 백로그 $240B(+55% QoQ) — CapEx가 실제 수요에 기반
- TPU 자체 설계로 NVIDIA 대비 단위당 경제성 우위 주장 가능

#### 시나리오 4 — EU/글로벌 규제 패키지 확산

**가정**: EU DMA 추가 위반 판정 → 연 매출 10% 반복 벌금(최대 연 $40B 노출). 영국 CMA·일본 공정위·인도 CCI 동시 유사 규제 패키지(Android 기본 앱·Play 수수료·Ad 경매). Play 스토어 수수료 30% → 15% 강제 하향(Apple Epic 판례 인용). Google Ad 경매 투명성 의무화. Search·Ad·Android 3개 전선 동시 규제 — 준수 비용 연 $10B+, 매출 침식 연 $20B+.

**재무/밸류에이션 충격**: 누적 규제 침식 연 $25~35B 매출 + 벌금 $10~20B. Services OM 39% → 33%. Play/Devices 매출 타격(수수료 15%로 -50%). Services PE 21x → 17x. 주가 충격 **-20~30%**(Services 가치 $3,486B → $1,615B).

**버티는 근거**:
- YouTube/Cloud/Waymo는 규제 영향 제한적 (광고 의존도 낮은 분야)
- Google 규제 대응 조직 성숙(1998 이후 경험 누적)
- EU DMA 이미 부분 준수 중 → 추가 악화 여지 제한적
- 순현금 $95B + 강한 영업이익률로 규제 비용 흡수 가능
- 규제가 ChatGPT·Meta에도 동일 적용 시 상대적 타격 완화

**취약 근거**:
- 글로벌 개별 규제 누적은 규모의 경제 해자 훼손(준수 비용 매출 연동)
- 규제 멀티플 할인은 2020년 이후 영구화된 프리미엄으로 작용
- Play 수수료 하향은 Apple App Store 판례로 급속 확산 가능
- Ad 경매 투명성 의무화 시 YouTube 광고 모델에도 파급
- 규제는 정치적 상수 — 양당 모두 빅테크 규제 강화

**관찰 지표**: EU DMA 추가 제재(2026~2027), 영국 CMA Android/Chrome 조사, Play 수수료 판결(Epic v Google 항소), Alphabet 연 준수 비용 공시, Services OM 분기(37% 하회 시 경계), 글로벌 실효세율 상승(OECD Pillar).

**실현 가능성 30%**: 개별 규제 상수. "EU+영국+일본+인도 동시 패키지 + Play 50% 하향" 조합은 중간. 누적 개별 실현 확률 합산 시 발생 가능성 있음. **Bear DCF 기여 -7.5%pt**.

#### 시나리오 5 — Cloud 가격 전쟁·OM 변곡 역전

**가정**: AWS/Azure가 GCP 백로그($240B) 뺏기 위해 가격 공세 — 핵심 AI 추론 -30% 인하. Oracle OCI가 엔터프라이즈 AI·DB에서 공격적 침투(OCI Q2FY26 +52% 성장). Anthropic·OpenAI의 Google TPU 의존 완화(자체 칩 또는 AWS Trainium·Azure Maia 대체). GCP 백로그 성장률 QoQ +55% → +10% 둔화. Gemini 4 상용화 지연.

**재무/밸류에이션 충격**: Cloud 매출 성장 +48% → +25%(일시) → +15%(장기 둔화). Cloud OM 30.1% → 18~20%. Cloud OI $18B → $12B. 백로그 실현 5년 → 3~4년 이동. Cloud EV/매출 7.5x → 4.5x. 주가 충격 **-15~25%**(Cloud 가치 $1,373B → $690B).

**버티는 근거**:

- OCI는 규모·글로벌 리전 제한적 — 구조적 위협 제한

**취약 근거**:
- GCP 3위 사업자 — 가격 전쟁 시 2위 Azure보다 먼저 마진 압박
- OM 30% 달성 후 1개 분기만에 역전 가능성(2023 AWS 경험)

**관찰 지표**: GCP 성장률(+35% 하회 2분기 연속 경계), Cloud OM(25% 하회 경계), 백로그 QoQ 변동, AWS/Azure 가격 인하 공시, Anthropic·OpenAI 멀티클라우드 전략 보도, Oracle OCI 성장률(+60% 지속 시 경쟁 압박), Gemini 4 출시 일정·벤치마크.

**실현 가능성 20%**: 가격 전쟁 업계 반복이나 현 수요 공급 초과로 전면 가격 전쟁 유인 낮음. 백로그 실현기 진입하면서 경쟁 격화 가능성. **Bear DCF 기여 -4.0%pt**.

### Bear → Stress 반영 시 비교

**기준**: Base 파일의 실제 시나리오 중간값
- Extreme Bear 중간값: **$150**
- Bear 중간값: **$239**

**Stress 반영 시뮬레이션**:
- 단순합산 적용 시: Bear $239 × (1 − 0.3725) = **$150**
- 동조성 보정 시: Bear $239 × (1 − 0.242) = **$181**
- 비교: Extreme Bear $150 ≈ 단순합산 $150 < 동조성 보정 $181

```
Bear $239  →  단순합산 적용 시 $150  /  동조성 보정 시 $181  (vs Extreme Bear $150)
```

**시사점**:
- 스트레스 5개 시나리오 **모두 동시 실현** 시 Bear 중간값 $239가 Extreme Bear $150 수준까지 추가 하락
- 동조성 보정 시 $181 — 현실적 다중 충격 시나리오는 Base의 Bear와 Extreme Bear **사이 구간에 위치**
- Alphabet Bear $239는 이미 DOJ 선택화면·CapEx $180B·AI 이탈 일부 반영한 보수 가정 → 스트레스 추가 충격 흡수력이 Extreme Bear 수준에 맞닿음
- **Bear가 스트레스 반영 시 Extreme Bear까지 밀리는 이유**: GOOGL 핵심 리스크 5종(규제·AI·CapEx·Cloud 전쟁)이 상호 강화적 성격이 강해 연쇄 반응. 반면 독립 리스크 기업(예: AAPL 공급망·폼팩터)은 Bear→Extreme Bear 갭이 더 큼

**투자 함의**:
- **주의**: 본 계산은 Revaluation 가중평균에 반영하지 않는다. "만약 모두 반영했다면" 참고 시뮬레이션.
- 분할 매수 계획 시 Bear $239 → 스트레스 반영 $181 구간에서의 추가 진입 여력 확보 권장
- $150 부근(Extreme Bear ≈ 단순합산 Stress 수렴점) 도달 시: 사업 모델 근본 훼손 여부 Thesis 재점검 후 분할 매수
- 손익비 개선(Bull $430 / Bear 스트레스 $181 = 2.4x) — 감정적 청산보다 규율 있는 분할 매수가 이성적
