- **HBM AI 메모리 supercycle 직접 수혜 — 효율적 규모(공급 과점) + 무형 자산(공정 노하우)**: HBM TAM CAGR ~40% (2025 $35B → 2028 $100B), MU CY2026 HBM 생산능력 100% 계약 sold out, NVDA GB200/GB300 + AMD MI325X/MI350 디자인 인 확보. HBM 시장은 SK Hynix(~55%) + Samsung(~25%) + MU(~21%) 3사 과점 구조

### 2-2. 세그먼트별 상세

#### CNBU — HBM Wide Moat + 범용 DRAM Narrow

**사업 구조**: 데이터센터 AI 가속기용 HBM(고대역폭메모리), 서버 DDR5, 게이밍 GDDR7, 데이터센터 SSD. AI Capex super-cycle의 직접 수혜 영역. NVDA·AMD·하이퍼스케일러가 핵심 고객. CY2026 HBM 100% 계약 sold out.

| 해자 유형 | 검증 |
|---------|------|
| 효율적 규모 (HBM 3사 과점) | ✅ |
| 무형 자산 (DRAM 1γ EUV 공정 노하우) | ✅ |
| 전환비용 (JEDEC 인증 + GPU 패키지 락인) | ✅ |
| 원가 우위 (스케일) | ✅ |

**효율적 규모**: HBM 시장은 SK Hynix(~55%) + Samsung(~25%) + Micron(~21%) 3사 독점. 신규 진입 장벽 = 1c (10nm 5세대) DRAM 공정 + TSV/CoWoS 패키징 + JEDEC 인증 = 자본/시간/인증 3중 장벽. CXMT(중국) 등 잠재 진입자는 BIS 수출 통제로 HBM stacking 장비 접근 차단. TrendForce/Counterpoint Q2-Q3 2025 데이터 기반(✅ 독립 검증).

**무형 자산**: DRAM 1y/1z/1α/1β/1γ/1c 노드 미세화 노하우. MU는 1γ(10nm 6세대) 양산 진입 — 업계 최초 EUV 적용. HBM3E 12-Hi(8H 대비 50% 용량) 디자인 인 확보 — NVDA GB300 표준 채택.

**전환비용**: HBM은 GPU 패키지에 직접 포함되어 디자인 인 사이클이 12~18개월. 한번 디자인 인되면 GPU 양산 수명(~3년) 내내 공급. NVDA·AMD가 HBM 공급사 변경 시 패키지 재설계 + 재인증 필요.

**원가 우위**: 12인치 wafer 월 capacity 대만(Taoyuan)·일본(Hiroshima)·미국(Boise/Manassas)·싱가포르 분산. CapEx $25B+ 규모는 SK Hynix·Samsung 수준.

**주요 디자인 인 (2026-04 기준)**:
| 계약/제품 | 고객 | 시점 |
|---------|------|------|
| HBM3E 8H | NVDA GB200, AMD MI325X/MI350 | 양산 진행 중 |
| HBM3E 12H | NVDA GB300 | 양산 진행 중 |
| HBM4 final samples | NVDA Rubin 등 | CY2026 Q2 ramp |
| HBM CY2026 100% sold out | 다수 | 2025년 말 확정 |

**해자 리스크**: HBM4(NVDA Rubin)에서 SK Hynix가 ~70%, Samsung ~25%, MU "3rd"로 표시 — MU의 HBM4 점유가 HBM3E 21% 대비 5~10%로 위축 가능 (UBS·TweakTown 분석, ⚠️ sell-side 추정). 현실화 시점 2026~2027.

#### MBU — Narrow (모바일 메모리)

**사업 구조**: 스마트폰·태블릿용 LPDDR5/LPDDR5X(저전력 모바일 DRAM), UFS(모바일 NAND). Apple·Samsung·Xiaomi·Honor 등 모바일 OEM 공급. AI on-device 트렌드(Apple Intelligence, Samsung Galaxy AI)로 메모리 함량 증가가 수혜.

#### EBU — Narrow (자동차·산업)

**사업 구조**: 자동차 인포테인먼트·ADAS·자율주행용 DRAM/NAND, 산업용 메모리. Tesla·BMW·NVDA Drive·Mobileye 등 공급.

**사업 구조**: 데이터센터 SSD(엔터프라이즈), 클라이언트 SSD(PC/노트북), 모바일 NAND 단독 판매.

### 2-3. 해자 강도 판정

**최종 판정**: **Narrow Moat ⚠️**

**핵심 근거**:
1. **시간 지평**: HBM 시장 3사 과점은 향후 3~5년 유지 가능 (CXMT 등 진입 BIS 통제로 차단). 단 사이클 진폭이 매우 커서 "지속적 초과이익 20년"의 Wide 기준 미충족. 메모리는 전형적 commodity-with-tech-moat 산업.
2. **전략적 헤지**: HBM(Wide 가능) + DRAM(Narrow) + NAND(None~Narrow) + Mobile/Embedded(Narrow) 다각화. HBM 호황이 NAND 사이클 하단을 부분 상쇄하나 모든 메모리 동일 사이클 동조성 보임 (2018·2022 동시 약세).
3. **계약/구조적 보호**: CY2026 HBM 100% sold out은 향후 12개월 매출 가시성 확보. 그러나 그 이후 HBM4·HBM4E 사이클은 SK·Samsung 양강 강화로 MU 위치 약화 가능.

**주의 구간 (Narrow → Wide 또는 Bear 진입 선행 지표)**:
- HBM 분기 매출 성장률: $4B+ 분기 수준에서 둔화 시 HBM 점유 축소 신호 (NVDA Rubin 사이클 진입 시)
- GM 81% 가이던스 후속 분기 추이: Q4 FY26 / Q1 FY27 GM이 75% 밑으로 이탈 시 cycle peak 확정 신호
- HBM4 디자인 인 점유율 (NVDA Rubin): 30%+ 확보 시 Narrow → Wide 재평가 가능, 10% 이하 시 Bear 진입

## 리스크 요인

### 1. 메모리 사이클 정점 — Reversion 리스크 ⚠️ (최대 리스크)

**리스크 설명 및 규모**: 메모리 산업은 historical 사이클 산업. 모든 정점(2014, 2018, 2021)은 이후 GM 50%+ 압축, EPS 80%+ 감소, 주가 50~70% 하락으로 귀결. 현재 GM 81% 가이드는 history 모든 사이클 상단(60~70%)을 돌파한 수치 — 정의상 더 갈 곳 없는 정점.

**Micron 사이클 history**:
- FY18 정점: GM 61%, EPS $11.95 → FY19 GM 45%, EPS $6.35 (-47%) → FY20 GM 31%, EPS $2.83 (-76%)
- FY22 정점: GM 46%, EPS $8.35 → FY23 GM -9% (적자), EPS -$4.45 → 100%+ 하락 후 적자
- FY26 정점 가이드: GM 81%, FY26E EPS ~$58 → FY28-29 reversion 시 EPS $10~25 가능

**현실화 시점**: 2027~2029

**시나리오별 영향**:
- Base: FY27 정점 EPS ~$70 → FY28 reversion ~$40 → FY29 ~$30
- Bear: FY27 정점 ~$60 → FY28 급락 ~$20 → FY29 ~$15

### 2. HBM 사이클 점유 축소 리스크 ⚠️

**리스크 설명 및 규모**: HBM3E에서 21% 점유했던 MU가 HBM4(NVDA Rubin 사이클)에서 ~5~10%로 위축 가능. UBS·TweakTown 분석 기준 SK 70%·Samsung 25%로 양강 강화. HBM이 CY2026 $20B+ 매출 기여 추정. 점유 축소 시 $10B+ 매출 영향 가능.

**현실화 시점**: 2026~2027

**시나리오별 영향**:
- Base: MU HBM 점유 21% → 18% (HBM4 사이클), 절대 매출은 TAM 성장으로 유지
- Bear: 21% → 12%, 매출 둔화
- Extreme Bear: 21% → 5%, HBM 사업 차세대 사이클에서 marginalize

**완화 요인**: (a) HBM4E·HBM5에서 MU가 EUV 1γ 노드 우위로 재진입 가능 (b) AMD·하이퍼스케일러 HBM 채택은 NVDA보다 다각화 — MU의 헤지

**팩트체크 상태**: ⚠️ — UBS/sell-side 추정. 실제 NVDA HBM4 분배는 2026 하반기 확정

### 3. CapEx 과잉 → 차세대 공급 과잉 사이클 ⚠️

**리스크 설명 및 규모**: MU $25B+ FY26 CapEx + Samsung·SK 동반 증설 → 2027~2029 글로벌 DRAM 공급 capa +30~40% 가능. 메모리 모든 사이클이 동일 패턴 (2018 정점 → 2019 capa 과잉 → 2020 trough). 글로벌 DRAM CapEx 2026E ~$80B (3사 합산) — 사상 최대 수준.

**현실화 시점**: 2027~2029

**팩트체크 상태**: ✓ — TrendForce/Goldman 등 capa 분석 일관

### 4. NVDA Rubin 사이클 의존도 — 단일 시점 리스크 ⚠️

**현실화 시점**: 상시 (정책 변동성)

**완화 요인**: (a) HBM 구조적 성장이 사이클 reversion 일부 상쇄 (b) 미국 자본 회귀로 멀티플 지지 (c) 자사주 매입·배당 안정성

**팩트체크 상태**: ⚠️ — 사이클 historical pattern + 현재 valuation 결합 분석

### 7. 매크로 리스크 — 금리·경기 ⚠️

## 가치평가

### 5-1. DCF 방법론

**적용 방식**: **A. Standard FCF DCF** (Exit Multiple Terminal — FY29 EPS × 사이클 PE)

**선택 근거**: MU는 (i) 단일 핵심 산업 (메모리 IDM) (ii) FCF 생성 안정적이나 사이클 변동성 큼 (iii) 자본 규제 미적용 (iv) Balance Sheet NAV 중심 아님 (v) 적자 사이클 기업 아님 → Step 1 판별에서 Option A 부합. 사이클 변동성을 반영하기 위해 시나리오별 EPS 궤적을 사이클 정점→reversion 모델링, Terminal은 Exit Multiple 방식 (Gordon 부적합 — 메모리는 영구 성장률 정의 어려움).

**대안 대비 우위**:
- SOTP 부적합: CNBU/MBU/EBU/SBU 세그먼트는 동일 메모리 사이클 동조성 — 이질 멀티플 적용 의미 없음
- Forward Multiple 부적합: MU는 FCF 안정적으로 생성되는 성숙 기업 — "초기 성장·적자 사이클"에 해당하지 않음
- NAV 부적합: 자산 기반 비즈니스 아님 — 이익 기반
- Excess Returns 부적합: 자본 규제 없음

**주요 가정**:
- WACC: **10.5%** (Rf 4.26% + 베타 1.5 × ERP 5.5% + 사이즈 프리미엄 0% — NVDA 대비 베타 높음, 사이클 변동성 반영)
- 예측 기간: 3년 (FY27~FY29), 투자 기간 일치
- Terminal: FY29 EPS × 시나리오별 Applied PE
- 희석 주식수: FY26 ~1.13B → FY29 ~1.10B (자사주 매입 반영)
- 실효세율: 13% (CHIPS Act 세제 혜택 반영)

**멀티플 기준 (역사적 실측)**:
- MU 5년 평균 Forward PE: 약 12x (사이클 평균)
- 사이클 정점 PE: 3~5x (FY18 정점 PE 3x, FY22 정점 PE 6.3x)
- 사이클 회복기 PE: 10~15x
- 시나리오 배정: Extreme Bear 6x / Bear 7x / Base 9x / Bull 11x

> **판단 포인트**: 멀티플 기준에서 "사이클 정점에서 PE가 낮다"는 점이 핵심. 시장이 EPS reversion을 미리 가격에 반영하기 때문. 따라서 Bull 시나리오에서도 PE 11x를 적용 (NVDA처럼 30x 절대 불가).

**가정**: 한반도 긴장 고조 (북한 도발 또는 중국 압박) — SK Hynix Icheon·Samsung Pyeongtaek 팹 단기 차질. 또는 대만 봉쇄 → TSMC HBM 패키징 (CoWoS) 6~12개월 차질 → 전체 HBM 공급 -30%. Micron Taiwan 팹 (Taichung) 직접 영향 + Idaho 팹 가동 가속 압박. 단기 메모리 공급 부족 → 가격 급등 (단기 호재) → 12개월 이상 지속 시 수요 파괴 (장기 악재).

| 항목 | 값 |
|------|---|
| 재무/밸류에이션 충격 | 단기 +30% (DRAM 가격 +50%) → 중기 -50% (수요 파괴), GM 81% → 50%, FY28~FY29 EPS Base 대비 -40%, PE 7x → 5x |
| 주가 충격 | -50% (평균 효과) |
| 실현가능성 | 10% |
| Bear DCF 반영 시 기여 | -5.0%pt |

**버티는 근거**: Micron US 본사 + Idaho 팹 (FY27~FY28 가동) — 미국 내 capacity 보호. 일본 Hiroshima 팹 (FY26 가동) 분산 — 대만/한국 의존도 낮음. US 정부 CHIPS Act 보조금 + 정부 안보 보장 직접 지원. 단기 가격 급등으로 EPS 일시 급증 가능.

**취약 근거**: HBM 패키징은 TSMC CoWoS 의존 — 대만 봉쇄 시 단기 대체 불가. SK Hynix·Samsung 차질 시 글로벌 메모리 공급 -50% → 단기 호재이나 수요 파괴. 글로벌 risk-off 시 메모리 사이클 주식 매도 압력. Taiwan/Korea 의존도가 메모리 산업 자체.

**관찰 지표**: 한반도 긴장 지수 (CSIS, CFR), 대만-중국 군사 긴장 지수 (CBAS), TSMC 월간 CoWoS 공급 capacity, Micron Idaho 팹 가동 진행률.

### 7-3. Bear → Stress 반영 시 비교

Base 파일의 Bear 현재 내재가치 $77 (FY29 목표가 $105) 기준:

```
원본 Bear 현재 내재가치:        $77
단순 합산 적용 시:              $77 × (1 - 0.876) = $9.5  (Extreme Bear $22 하회)
동조성 보정 적용 시:            $77 × (1 - 0.394) = $46.7
Base 파일 Extreme Bear:         $22
────────────────────────────────────────
```

**시사점**:
- 스트레스 단순 합산 시 Bear가 $9.5로 Extreme Bear($22)도 크게 하회 — 비현실적 수준
- 동조성 보정 시 $46.7 — Bear($77)와 Extreme Bear($22) 사이로 이동
- Extreme Bear $22는 모든 스트레스 시나리오 동시 발현 + BV floor도 하회한 극단 케이스
- **결론**: Base 가중평균 내재가치 $192는 적절 수준이나, 메모리 사이클 산업 특성상 Bear 확률을 25% → 30~32%로 상향 검토 필요. 시나리오 #1(사이클 reversion)의 40% 실현가능성이 Base의 Bear 25% 가정과 정합성 차이 — 사용자 thesis 단계에서 재검토 권장
- 단, Bull 시나리오(20%)도 현재 실적 흐름이 강하게 지지하므로 Bull 비중 조정은 신중

**주의**: Revaluation 가중평균에는 반영하지 않음. "참고용 시뮬레이션"으로만 활용.
