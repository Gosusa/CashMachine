# CSCO — Cisco Systems, Inc.

## 투자 thesis

- **Silicon One 기반 AI 하이퍼스케일러 수주가 3개 분기 연속 가속 중** → 효율적 규모 + 무형자산(실리콘 IP). Q1 FY26 $1.3B → Q2 FY26 $2.1B (QoQ +62%), FY26 $5B+ 가이드. AI infra 매출 인식 FY26 $3B+. P200(MSFT Azure·Alibaba) + G300(2026 2월 발표)으로 FY27~FY28 모멘텀 지속 예상
- **Splunk + 네트워킹 통합이 Observability/Security 플랫폼으로 전환** → 전환비용 + 무형자산. Splunk ARR·product RPO 두 자릿수 성장, H1 FY26 500 신규 로고(연 1,000 목표). 클라우드 구독 전환으로 Security -4% YoY 드래그이나 FY27부터 재가속 예상
- **FY26 매출 +8% 가이드 + FCF $13.6B + 50%+ 자본환원이 가치 방어선** → 무형자산 + 전환비용. 구독 매출 $7.8B(51%), 총 ARR $31B(+3%), 제품 ARR +6%. 분기 배당 $0.42 + $10.8B 자사주 한도

### Networking

**사업 구조**: Catalyst/Nexus 스위치, ASR/8000 라우터, Meraki 클라우드 WiFi/SD-WAN, Silicon One ASIC. 하이퍼스케일러 AI back-end는 P200/G200/G300 실리콘 기반 판매.

**해자:**

| 해자 유형 | 검증 |
|---------|------|
| 무형자산 (Silicon One IP) | ✅ |
| 전환비용 (IOS/NX-OS + CCIE 엔지니어 풀) | ✅ |
| 효율적 규모 (글로벌 85%+ Fortune 500) | ⚠️ (회사 주장, 시장점유율 방증) |
| 계약 lock-in (EA, 서비스 유지보수 95%+) | ⚠️ (갱신율 공식 공시 없음) |

**Silicon One IP**: G200이 FY25 $600M+ AI 매출 기여. P200(51.2T 라우팅)은 Microsoft Azure·Alibaba에 초기 공급 중. G300은 2026-02 발표로 FY27 공급 시작 예정. Broadcom Tomahawk에 의존하는 ANET과 달리 Cisco는 자체 ASIC 설계로 수직통합 — R&D는 크나 차별화·마진 우위 가능.

**IOS/NX-OS 전환비용**: Catalyst·Nexus 운영체제 의존 엔터프라이즈 네트워크 엔지니어 풀이 수백만 명(CCIE/CCNA). 경쟁사 전환 시 재훈련·재인증 3~6개월, 다년 EA 계약은 해지 위약금 존재.

**효율적 규모**: Cisco 장비가 Fortune 500의 85%+ 운용 (회사 주장 — IDC/Gartner Magic Quadrant Leader 지속이 간접 확인). 글로벌 유통 파트너 70,000개사+.

**AI infra 수주 트렌드:**

| 분기 | AI infra 오더 | 누적 FY26 |
|------|-------------|-----------|
| Q4 FY25 | ~$800M 추정 | — |

**해자 리스크 (훼손 관점):**
- ANET 고속 DC 스위칭 추월(400G/800G에서 40%+) — 진행 중, 2026~2028 가속 / 해자 훼손 중간

### Security (Splunk 포함)

**사업 구조**: Cisco Security(SASE·Secure Firewall·Umbrella·Duo) + Splunk(SIEM·SOAR·observability). Splunk는 $28B에 2024년 3월 인수, ARR $4B 기반.

**해자:**

| 해자 유형 | 검증 |
|---------|------|
| 전환비용 (Splunk 데이터) | ✅ |
| 통합 플랫폼 시너지 | ⚠️ (증명 초기 단계) |
| 신규 로고 유입 | ✅ |

**Splunk 데이터 lock-in**: SIEM 구축은 수개월~2년. Splunk SPL 검색 언어·대시보드·룰셋 lock-in. 이전 시 운영 노하우 재구축 필요.

**통합 플랫폼 시너지**: Splunk 데이터 + Cisco 네트워크 텔레메트리 통합 XDR 비전은 전략적으로 합리적이나 22개월 인수 후 정량적 cross-sell 공시는 제한적. MSFT Sentinel(E5 번들)·PANW Cortex XSIAM이 공격 중.

**Splunk 전환 상세:**

| 지표 | 수치 |
|------|------|
| Splunk ARR (인수 시, 2024-03) | $4B |
| Splunk ARR/RPO (Q2 FY26) | 두 자릿수 성장 (회사 공시, 구체 수치 비공개) |
| Security 세그먼트 매출 Q2 FY26 | $2.0B (-4% YoY), 온프레→클라우드 전환 드래그 |
| 신규 로고 H1 FY26 | 500개 (연 1,000 목표) |

**해자 리스크 (훼손 관점):**
- Splunk 클라우드 전환 드래그 FY26~FY27 / 일시적
- SIEM 경쟁 격화 (MSFT Sentinel, PANW XSIAM, CRWD Next-Gen SIEM) — 진행 중 / 중간
- 통합 시너지 미증명 — FY27 중 검증 / 중간

### 해자 강도 판정

**CSCO = Wide Moat ✅** (단, AI 데이터센터 스위칭 세그먼트만 따로 떼면 Narrow)

**핵심 근거:**
① **엔터프라이즈 네트워킹 lock-in은 30년 누적 해자** — IOS/NX-OS, CCIE/CCNA 엔지니어 풀, EA 계약·서비스 유지보수 네트워크가 경쟁사 진입을 3~5년+ 지연. ANET의 DC 스위칭 승리는 "greenfield hyperscaler" 한정이며 Fortune 500 레거시 네트워크가 아님
② **Silicon One 수직통합 실리콘이 AI 네트워킹에서 해자 재구축** — FY25 $600M → FY26 $3B+ AI 오더는 구조 반등의 초기 증거. P200/G300으로 Nvidia InfiniBand·Broadcom Tomahawk 의존을 낮추려는 hyperscaler와 이해 일치
③ **$7.8B 구독 매출 + $31B ARR + 갱신율 95%+ 현금흐름 방어선** — 성장 둔화 시나리오에서도 FCF $13.6B 유지 가능. 50%+ 자본 환원이 수익률 하단 지지

**주의 구간:**
- ANET의 엔터프라이즈 campus/branch 시장 진입 가속 (2026~2028 선행 지표: ANET Campus revenue 공시, 엔터프라이즈 수주 빈도)
- Splunk 통합 시너지 정량 증명 (FY27 중) — Non-GAAP EPS accretive 약속 이행, cross-sell 데이터 공시 여부

### 투자 차별화 근거

1. **Wide Moat 엔터프라이즈 1위 + AI 재참여의 이중 레버리지**: ANET(AI only $10.65B) + HPE(엔터프라이즈 $43B) 장점을 Cisco가 통합 보유. 성숙 밸류(FwdPE 20.8x)에서 AI 재도전 성공 시 멀티플 리레이팅 여지 — ANET 45x 대비 50% 할인
2. **FCF $13.6B + 자본환원 50%+의 하방 방어**: 성장 둔화 시에도 배당+buyback으로 EPS +6~8% 확보. ANET(성장 의존)·HPE(레버리지) 대비 수익률 변동성 낮음
3. **Silicon One이 Tomahawk-ANET 구도에 대안 제공**: 하이퍼스케일러들은 복수 공급자 유지 필요 — ANET 독점 꺼림. Cisco가 2nd source로 자리잡으면 AI infra에서 구조적 점유율 확보

**밸류에이션 비교:**

| 지표 | CSCO | 네트워킹 peer 평균 |
|------|------|-----------|
| Forward PE (FY26E) | ~20.8x | ~30x (ANET 45x, AVGO 34x, HPE 10x) |
| EV/Revenue | ~5.8x | 혼재 |

**해석**: CSCO Forward PE 20.8x는 peer 평균 대비 31% 디스카운트. 성장률 열위(+10% vs ANET +29%) 반영하면 합리적. PEG 2.5x는 성장 대비 비싸 보이나 자본환원을 감안한 TSR 기준에서 합리적. AI 오더 가속 FY27~FY28 지속 시 5년 평균 forward PE 복귀 + EPS 가속으로 $100 이상 가능.

**결론**: 성장률 격차가 축소되면(Silicon One 확산·AI 매출 $5B+ 달성) ANET 대비 50% 할인 재평가 여지.

- 가이드 하단 미달 시: Bear 경계 이동 → Security -4% 장기화가 트리거

**핵심 관찰:**
- 가장 중요한 변수: AI infra 분기 오더 ($2B+ 유지 여부)
- 확인 시점: Q3 FY26 실적 (2026년 5월) — AI 오더 궤도, Security 반전 여부, FY26 가이드 재확인

### 가치평가 결과

**손익비 (Base 목표가 기준):**
- Bull 업사이드 = $140 − $100 = $40
- Bear 다운사이드 = $100 − $72 = $28
- 손익비 = $40 / $28 ≈ **1.43**

| 지표 | 수치 | 평가 |
|------|------|------|
| Base Forward PE | 18.5x (FY29E) | 5년 평균 19.9x 근접, 합리적 |
| Base 매출 CAGR | +5.7% | 성숙 기업 + AI 재가속 반영 |
| Base EPS CAGR | +9% | buyback 레버리지 포함 |
| Base FCF Yield | ~4.0% (FY26E) | 성숙 기업 프리미엄 |
| PEG (Base EPS CAGR 9%) | ~2.3x | 성장 대비 비쌈, 자본환원 감안 시 적정 |
| 손익비 (Base vs Bear) | 1.43 | 비대칭 상방 |
| 손익비 (Base vs Extreme Bear) | $40 / $49 = 0.82 | 비대칭 하방 |

**결론**: Base 시나리오 $100 기준 Bull 업사이드 $40, Bear 다운사이드 $28 — 손익비 1.43. Extreme Bear 대비 0.82로 극단 시나리오에서는 비대칭 하방이 더 큼. AI 오더 FY26 $5B 가이드 달성 + ANET DC 스위칭 점유율 30% 아래 유지 시 Base → Bull 진입. 반대로 Q3 FY26 AI 오더 $1.5B 미만 감속 시 Bear 진입, ANET 35%+ 돌파 시 Extreme Bear.
