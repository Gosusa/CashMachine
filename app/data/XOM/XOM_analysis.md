# XOM — Exxon Mobil Corporation

> 글로벌 1위 통합 석유 메이저 — Permian/Guyana/LNG advantaged assets + 4세그먼트 통합 다각화 + 43년 연속 배당 인상 + 메이저 최고 ROCE

## 투자 thesis

- **Permian + Guyana + LNG "Advantaged Assets" 저비용 우위** → 원가 우위 + 대체 불가 실물 자산: FY25 net production 4.6 MMboed (+20% YoY, Pioneer 인수 효과), 2030 plan 5.4 MMboed 목표, breakeven Brent **$35 by 2027 / $30 by 2030**
- **메이저 최고 ROCE + 자본 배분 규율** → Float 우위 + 효율적 규모: FY25 ROCE 9.3% (5년 평균 ~11%, 메이저 1위), 2030 plan ROCE >17% 목표, FY25 distributions $37.2B ($17.2B 배당 + $20B 자사주매입), 43년 연속 배당 인상
- **다각화된 4개 세그먼트로 단일 사이클 리스크 완충** → 효율적 규모 + 무형 자산: FY25 segment earnings Upstream $21.4B + Energy Products $7.4B + Chemical $0.8B + Specialty $2.9B = $32.5B, 다운스트림·케미컬은 유가 하락 시 헤지 작용

### 2-2. 세그먼트별 상세

#### Upstream (E&P) — 원가 우위 + 대체 불가 매장량

**① 사업 구조** — 글로벌 1위 IOC. FY25 net production 4.6 MMboed(역대 최고), 2030 plan 5.4 MMboed. 핵심 advantaged assets는 Permian Basin (1.6 → 2030 2.5 MMboed), Guyana Stabroek (650 → 1,700 kboed), LNG Golden Pass (2026 가동). 2030년 60%+ 생산이 advantaged assets에서.

**② 해자 유형 / 검증**

| 해자 유형 | 검증 |
|---------|------|
| 원가 우위 (Permian breakeven $35-45) | ✅ |
| 원가 우위 (Guyana breakeven $25-30) | ✅ |
| 대체 불가 실물 자산 (매장량 19.9 GOEB) | ✅ |
| 효율적 규모 (capex $28-33B/yr) | ✅ |
| Permian 2030 2.5 MMboed 가이던스 | ⚠️ (회사 가이던스) |
| Guyana 2030 1.7 MMboed 가이던스 | ⚠️ (회사 가이던스) |
| Breakeven $35/2027 → $30/2030 | ⚠️ (회사 가이던스) |

**상세 내용**:
- **Permian (Pioneer 인수 효과)**: 2024.5월 $60B all-stock 인수 완료로 1.4M acre 확보, 미국 최대 Permian 생산자. 합성 시너지 연 $4B (당초 $2B의 2배 상향). 자체 lightweight proppant 기술로 회수율 +20%. 2030년 2.5 MMboed 목표는 연 +9% growth가 필요하므로 가이던스 의존.
- **Guyana Stabroek**: 운영자 지분 45%. 2024년 말 매장량 11+ Bboe, FPSO 6기 가동 중 → 잠재 10기. Hammerhead $6.8B FID(2025.9), 2029 가동. 세계 최저급 breakeven $25-30/bbl로 Brent 어떤 하락 시나리오에도 마지막까지 흑자 생산자.
- **매장량 19.9 GOEB (YE 2024)**: proved reserves, 그 중 7.4 GOEB가 proved undeveloped. 4.6 MMboed 생산 기준 reserve life ~12.6년. 2024년 1.1 GOEB undeveloped→developed transfer로 replacement ratio 100%+ 입증.
- **메가 프로젝트 동시 추진**: Permian + Guyana FPSO + Golden Pass LNG + CCS + 리튬 — 단일 IOC 중 유일하게 4개+ mega project 동시 가능.

**③ 해자 리스크 (해자 훼손 관점)**:
- **장기 석유 수요 정점 (2030~2040 점진적)**: 전기차 + 정책 가속 시 advantaged assets도 마진 위축. 단 Permian/Guyana 저비용은 "마지막까지 생존하는 생산자" 위치 유지 — 해자 훼손 정도 **중간**
- **Reserves replacement 의존 (2030+)**: 매장량 12.6년 분 — 신규 발견·M&A 지속 필요. Pioneer 같은 $60B M&A 기회는 제한적
- **Hess/Chevron Stabroek 파트너 변경 (2026~2028 조기 신호)**: ICC 중재 패소, Chevron 30% 파트너 진입. XOM 운영자 유지(45%)이나 협력 마찰 가능 — 해자 훼손 **낮음** (operator 유지)

#### Energy Products (Downstream Refining) — 효율적 규모 + 입지 우위

**① 사업 구조** — FY25 earnings $7.4B (vs FY24 $4.0B, +85% YoY 정제 마진 회복). 4.6 MMbpd 정제 능력 (세계 1위). 미국·유럽·아시아 통합 정제소. 전기차 전환 역풍 vs 글로벌 항공/해운/디젤 수요 견조.

**② 해자 유형 / 검증**

| 해자 유형 | 검증 |
|---------|------|
| 효율적 규모 (가동률 92%+) | ✅ |
| 입지 진입장벽 (1976년 이후 미국 신규 정제소 거의 무) | ✅ |
| 무형 자산 (Exxon/Esso/Mobil 브랜드 + 12,000+ 주유소) | ✅ |
| 수직통합 우위 (Upstream→정제→화학→마케팅) | ✅ |
| Q1 2026 downstream timing 충격 -$3.3~5.3B | ✅ |

**상세 내용**:
- **입지 진입장벽**: 미국 신규 정제소는 1976년 이후 사실상 신축 무 — 환경 인허가 사실상 불가능. 기존 정제소가 영구 자산화. EU·미국 모두 동일 패턴.
- **수직통합 우위**: Upstream 원유 → 자체 정제 → 자체 화학 피드스톡 → 자체 마케팅 chain. 마진 캡처 일관성으로 단일 단계 IOC(예: Phillips 66, Marathon Refining) 대비 우위.
- **Q1 2026 일회성 변동성**: Hormuz spike로 feedstock 상승 vs product 가격 시차 → -$3.3~5.3B timing/derivative 손실. 구조적 해자 영향은 아니지만 분기 EPS noise 발생 (XOM 8-K 가이던스 공식 확인).

**③ 해자 리스크 (해자 훼손 관점)**:
- **EV 가솔린 수요 정점 (2027~2032)**: 가솔린 수요 정점 2025-2030 추정. 디젤·항공유는 2040+ 견조 — 해자 훼손 **중간**
- **단기 timing/derivative 변동성**: 분기 EPS noise는 해자 영향 없음 (구조적 우위 무관)

#### Specialty Products — Mobil 1 무형 자산 + 전환비용

**① 사업 구조** — FY25 earnings $2.9B. 윤활유(Mobil 1) + 합성유 + 베이스오일. 자동차 OEM 사양 인증(BMW LL-04, Porsche A40, Mercedes 등) — 전환비용 형성. **메이저 중 가장 안정적이고 고마진** 세그먼트 (FY24 $3.1B → FY25 $2.9B, -6%만 변동).

**② 해자 유형 / 검증**

| 해자 유형 | 검증 |
|---------|------|
| 무형 자산 (Mobil 1 글로벌 1위 합성 윤활유) | ✅ |
| 전환비용 (OEM 인증 사양) | ✅ |
| 기술 우위 (합성유 base oil 노하우) | ✅ |
| Specialty earnings 안정성 ($2.5B+ 유지) | ✅ |

**상세 내용**:
- **Mobil 1 브랜드**: 세계 1위 합성 윤활유. F1·고성능 차 마케팅 자산. 시장 조사(Kline, NPD) 1위 검증.
- **OEM 인증 전환비용**: 자동차 제조사 보증 사양에 Mobil 1 명시 — OEM 변경 비용 큼. B2B (산업·해운) 윤활유도 동일.
- **기술 우위**: 석유화학 통합 시너지로 합성유 base oil 자체 제조 — Castrol, Shell Helix 대비 원가 구조 우위.
- 시장이 별도로 평가하지 않는 안정 캐시 — Specialty가 본 분석의 hidden floor.

**③ 해자 리스크 (해자 훼손 관점)**:
- **EV 보급 → 엔진 윤활유 수요 감소 (2030+ 점진)**: BEV는 엔진오일 불필요. 단 산업·해운·항공 윤활유는 견조 — 해자 훼손 **낮음~중간**

#### Chemical Products — 효율적 규모 + 원가 우위

**① 사업 구조** — FY25 earnings $0.8B (cycle bottom, vs FY24 $2.6B / FY22 $7B+). 폴리에틸렌·폴리프로필렌·고가치 화학제품. 중국 신규 capacity 추가로 마진 압박. China Chemical Complex(중국 후이저우) 가동 ramp-up.

**② 해자 유형 / 검증**

**상세 내용**:

- **미국 ethylene cost leadership**: Permian 자체 NGL 피드스톡 → 글로벌 최저 cost curve 위치. cycle bottom에서도 흑자 유지.
- **통합 입지**: 정제소 옆 화학단지 — 피드스톡 비용·물류 우위.

**③ 해자 리스크 (해자 훼손 관점)**:
- **중국 capacity overhang (진행 중)**: 2024-2026 중국 신규 ethylene 추가 → 글로벌 마진 다년 압박 — 해자 훼손 **낮음** (전사 이익 3% 비중)
- **사이클 변동성**: $0.8B(2025) ~ $3.0B(2024) ~ $7B+(2022) 대폭 변동 — 해자가 아닌 cycle 특성

### 2-3. 해자 강도 판정

**최종 판정: XOM = Wide Moat ✅**

평가 기준: Morningstar Wide Moat — "향후 20년 이상 초과이익을 유지할 수 있는 구조적 우위"

**핵심 근거 3가지**:
1. **시간 지평 — 매장량 + 저비용**: 19.9 GOEB 매장량 + Permian/Guyana breakeven $25-45는 "마지막까지 생존하는 생산자" 위치. 석유 수요 정점이 와도 고비용 한계 생산자가 먼저 퇴출되며 XOM의 점유율은 오히려 상승 가능 (industry consolidation thesis)
2. **전략적 헤지 — 4개 세그먼트**: Upstream(유가 노출) + Downstream(가격 spread 헤지, 유가 하락 시 정제 마진 확대) + Specialty(안정 캐시) + Chemical(피드스톡 통합). 2025년 Upstream -$4B를 Energy Products +$3.4B로 상쇄한 패턴이 헤지 작용 입증
3. **자본 배분 규율 — 43년 배당 + ROCE 9~17%**: 메이저 중 최고 ROCE 유지(2025 9.3%, 2030 plan >17%), 43년 연속 배당 인상은 capital cycle 통과 능력 입증. $20B/yr 자사주매입은 주가 floor 제공

**주의 구간 (Wide 약화 선행 시그널)**:
- Brent $60 미만 영구 진입 — 2030 breakeven $30 가이던스 신뢰성 시험대
- Reserve replacement ratio < 100% 2년 연속 — 매장량 감소 시작
- Permian/Guyana 생산 가이던스 미달 1년 — 2030 plan 신뢰도 훼손
- 45Q 정책 폐지 + IRA 후퇴 — Low Carbon 옵션 가치 소멸

## 가치평가

### 5-1. DCF 방법론

**적용 방식**: **B. SOTP (Sum-of-the-Parts)** — Forward Multiple per segment + Net Debt 차감, FCF DCF 보조 교차검증

**선택 근거**: ExxonMobil은 4개 + 1개 이질적 세그먼트로 구성된 통합 IOC. Upstream(원유 가격 노출, 매장량 자산 기반), Energy Products(downstream 정제 마진 cyclical), Specialty(stable B2B franchise), Chemical(cyclical petrochemical), Low Carbon(early-stage option) — 각각의 이익 성격·멀티플·cycle 특성이 근본적으로 상이. 단일 FCF DCF는 (a) Upstream의 매장량 자산 가치를 반영하지 못하고, (b) Specialty의 안정성 프리미엄을 손실하며, (c) Chemical의 cycle bottom 정상화 옵션을 놓친다. SOTP는 segment별 mid-cycle 이익에 적정 멀티플을 적용하는 통합 IOC의 표준 평가법.

**대안 대비 우위**:
- A. Standard FCF DCF 부적합: 매장량(Upstream)이 reproducible cash flow로 모델링되지 않음. Capex가 mega project 단위로 lumpy
- D. NAV 부적합: Upstream만 적용 가능 — Downstream/Chemical/Specialty 자산 가치 누락
- C. Excess Returns 부적합: 자본 규제 하 금융기관 모델 — IOC에 부적합

**주요 가정**:
- WACC: **8.5%** (Rf 10Y UST 4.26% + Beta 0.85 × ERP 5%)
- 세율: **24%** (FY25 실효세율 — XOM 다국적 mix)
- 예측 기간: 5년 (FY26E~FY30E), Base는 FY28-29 mid-cycle 시점 segment earnings
- Brent 가정 (시나리오별): Extreme Bear $40, Bear $55, Base $70-75, Bull $90+
- Mid-cycle 멀티플: Upstream 6-9x, Energy Products 6-8x, Specialty 12-15x, Chemical 8-10x

### 7-3. Bear → Stress 반영 시 비교

**기준**: Base 파일의 실제 시나리오 중간값
- Extreme Bear 중간값: **$52**
- Bear 중간값: **$103**

**Stress 반영 시뮬레이션**:
- 단순합산 적용 시: Bear $103 × (1 − 0.217) = **$81**
- 동조성 보정 시: Bear $103 × (1 − 0.141) = **$88**
- 비교: Extreme Bear $52 < 단순합산 $81 < 동조성 보정 $88 < Bear $103

```
Bear $103  →  단순합산 적용 시 $81  /  동조성 보정 시 $88  (vs Extreme Bear $52)
```

**시사점**:
- 스트레스 시나리오 다수 동시 실현 시 Bear 중간값 $103이 $81~$88 수준으로 추가 하락 (-14~22%)
- 그러나 Extreme Bear $52까지는 도달하지 않음 → **Extreme Bear 시나리오는 본 스트레스 테스트보다 더 깊은 사업 모델 자체의 훼손 (메가 자산 가치 손상, 매장량 stranded asset, 자본 환원 중단)을 반영한 상태**
- Bear 시나리오가 스트레스 반영 시에도 Extreme Bear 수준까지 밀리지 않는 이유:
  1. **자산 가치 floor**: 19.9 GOEB 매장량 + Permian/Guyana 저비용 자산은 Brent $40에서도 일부 가치 보존
  2. **자본환원 규율**: 43년 배당 트랙 레코드 + Net Debt $30B (메이저 최저) → 충격 흡수 여력
  3. **다각화 헤지**: 4개 세그먼트 자연 헤지가 stress 시나리오에서도 부분 작동

**투자 함의**:
- **주의**: 본 계산은 Revaluation 가중평균에 반영하지 않는다. 스트레스 테스트의 합산 기여는 "만약 모두 반영했다면" 시뮬레이션이다.
- 분할 매수 계획 시 Stress 반영 Bear $81~$88 구간에서의 추가 진입 여력을 확보. 이 구간은 Bear 진입가 $103 대비 -15~21% 추가 하락
- 해당 구간 도달 시 Forward PE 11~12x (peer 평균), Dividend Yield 5%+ (43년 배당 트랙 + Net Debt 여력 감안 시 컷 가능성 매우 낮음)으로 손익비 크게 개선
- 스트레스 시나리오 1·3 동시 실현 시그널 (Brent $50 미만 sustained + EV 침투율 가속 동시 확인)이 monitoring 핵심 — 두 시그널 동시 발생 시 $80 밑까지 reprice 가능성 검토
