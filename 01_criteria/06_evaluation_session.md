# 6. 종목 평가 세션 가이드

Claude에게 종목 평가를 요청할 때의 구조와 기준을 정의한다.

---

## 세션 호출 방법

### 기본 명령어
```
"{종목명} 평가해줘"
"{종목명} 투자 근거 점검해줘"
"{종목명} 거장 관점으로 평가해줘"
```

### 심화 명령어
```
"{종목명} 풀 평가해줘"       → 4개 criteria + 거장 관점 + DCF 전부
"{종목명} 리스크만 평가해줘" → 04_risk_return 기준 집중
"{종목명} 버핏 관점으로 봐줘" → 특정 거장 관점 단독 적용
```

---

## 평가 세션 구조

평가 요청 시 Claude는 아래 순서로 분석한다.

### Step 1 — 비즈니스 퀄리티 점검 (01_business_quality.md 기준)
- 경제적 해자 유형과 강도
- 성장 지속성 (매출/이익 CAGR)
- 경영진 신뢰도
- **판정**: ✅ 통과 / ⚠️ 주의 / ❌ 미달

### Step 2 — 시장 환경 점검 (02_market_environment.md 기준)
- 섹터 트렌드 방향
- 경쟁 구도 변화
- 거시경제 영향도
- **판정**: ✅ 통과 / ⚠️ 주의 / ❌ 미달

### Step 3 — 가치평가 점검 (03_valuation_scenarios.md 기준)
- DCF Base 기준 업사이드
- Bear/Base/Bull 가중평균 vs 현재가
- 안전마진 충분 여부
- **판정**: ✅ 매력적 / ⚠️ 적정 / ❌ 고평가

### Step 4 — 리스크 점검 (04_risk_return.md 기준)
- 핵심 리스크 요인 3가지
- 포지션 크기 적정성
- 손절 기준 해당 여부
- **판정**: ✅ 수용 가능 / ⚠️ 관리 필요 / ❌ 과도한 리스크

### Step 5 — 거장 관점 (05_masters.md 기준)

### Step 6 — 종합 판정

```

────────────────────────────────

리스크           : ✅ / ⚠️ / ❌

```

## 내가 고른 종목의 투자 근거 기록

종목 매수 시 아래 양식으로 근거를 작성해두면,
평가 세션에서 "내 가정이 맞았는가" 를 점검하는 데 활용한다.

### 양식
```markdown
## [종목명] 매수 근거 — YYYY-MM-DD

**매수가**: $XX
**목표가**: $XX (Base DCF 기준)
**투자 기간**: X년

**핵심 thesis (1~2줄)**:

**주로 참고한 거장**:

**Bear 시나리오에서 감수할 수 있는 이유**:

**손절 기준**:
  - 가격: $XX 이하
  - 사건: (예: 매출 성장률 X% 이하로 연속 2분기)

**분기 점검 체크포인트**:
  - [ ] 
  - [ ] 
```
