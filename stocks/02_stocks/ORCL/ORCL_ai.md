## 6. 취약 가정 / Watch-out

- **RDMA 성능 우위** — 독립 벤치마크 제한, 마케팅 claim 요소 (⚠️)
- **OCI 시장점유율 ~3%** — AWS 30% / Azure 20% / GCP 13% 대비 열위
- **하이퍼스케일러 자본경쟁** — MSFT/GOOGL/META Capex $80~120B/연 vs Oracle $50B
- **Net Debt $88B + FCF 음전환** — 하이퍼스케일러 중 최고 부채비율, 금리 상승에 가장 취약

- **Thesis 근거 3** (국가주도자본주의 → Oracle 직접 수혜) ⚠️ 간접 연결
- **PE 신규 capacity 공급** — 장기(5~10년) Oracle 희소성 프리미엄 희석 가능
- **LLM 효율 개선이 토큰 수요 증가 초과 시** RPO capacity 수요 감소
