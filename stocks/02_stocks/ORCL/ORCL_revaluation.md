### 근거 4. 베어메탈 서버 — Big Tech 락인 회피 차별화 **[신규]**

| 검증 항목 | 수치 / 독립 소스 | 판정 |
|---------|-----------------|------|

| 데이터 egress 가격 | OCI 10 TB/mo 무료, 추가 분 경쟁사 대비 **10배 저렴** | ✅ |
| Big Tech 실제 채택 | OpenAI $300B 파트너십, xAI Supercluster, Meta $20B 논의, Stargate 5개 신규 데이터센터 | ✅ |
| 베어메탈 = 플랫폼 비종속 | 가상화 오버헤드 없음, 고객이 자체 스택/API 구동 가능 (Oracle 공식 + 업계 확인) | ✅ |

**판정: ✅ 독립 소스로 가장 강하게 지지. Oracle 단독 차별화 논거로 유효.**

**이 근거의 특별한 의미**:
- 근거 1~3은 "하이퍼스케일러 섹터 전체 순풍" 논거라 Oracle 직접 수혜에 감쇠가 필요했음.
- 근거 4는 **Oracle만의 구조적 차별화** → 섹터 공통 수혜 감쇠 불필요.
- 개발능력 보유 Big Tech(OpenAI/xAI/Meta 등)에게 AWS/Azure의 plat-in-plat 구조는 **불필요한 오버헤드 + 가격 프리미엄**. OCI는 raw metal + RDMA만 제공하므로 고객이 자유롭게 스택 구축.
- 이는 단순 "가격 경쟁"이 아니라 **아키텍처적 포지셔닝 차이** — AWS/Azure가 단기간에 모방 어려움 (기존 플랫폼 매출 cannibalization 문제).

**어드버서리얼 리스크**:
- AWS도 EC2 Bare Metal, Azure도 제한적 베어메탈 제공 — "유일"은 마케팅 과장. 정확히는 **"AI GPU 베어메탈의 주력 상품화 + 가격 투명성"** 이 Oracle 차별점.
- Big Tech 중 Google(자체 TPU)·Amazon(Trainium)·Microsoft(MAIA) 등 **자체 칩 전략**으로 OCI 베어메탈 수요 일부 잠식 가능. 단 속도는 느림 (칩 R&D 5~7년 주기).
- 베어메탈은 초대형 고객에만 매력. 중견/엔터프라이즈 고객은 managed 서비스 선호 → Oracle의 TAM은 상위 20~50개 고객에 집중 → 고객집중도 리스크와 연결.

**판정: ✅ 독립 소스로 압도적 지지.**

**이 근거의 의미**:
- 근거 3(국가주도자본주의)은 **거시 프레임**. 근거 5는 **섹터 자본배분의 실증 데이터**.
- smart money(KKR, Blackstone, BlackRock, Brookfield)가 AI 인프라를 집중 매수 = 해자와 수익성에 대한 **시장 검증(validation)**.
- "AI가 돈이 된다" 계산은 끝났다는 주장 → PE의 12~18% 목표 IRR이 실제로 확보되고 있다면 사실에 부합.

**양날의 검 (어드버서리얼)**:
- **긍정 해석**: smart money 공감 → 시장 멀티플 리레이팅 가속, Oracle 인프라 가치 재평가.
- **부정 해석**: PE 자본이 **신규 capacity 공급** (Aligned, Compass, STT GDC, GTR) → 장기적으로 공급 증가로 병목 완화, Oracle 희소성 프리미엄 희석 가능.
- 중재: 공급 증설은 전력·그리드 물리 병목으로 **5~10년 걸림**. 5년 투자기간 내에는 **수요 우위 지속 가능성 높음**. 단 장기(10년+) 변수로 기록.

**Oracle 직접 연결고리**:
- 이 PE 자본은 대부분 **신규 빌딩(data center build)**에 투입. Oracle이 해당 capacity를 임차/활용하거나, 혹은 Oracle 경쟁자의 capacity가 되거나 둘 중 하나.
- Oracle의 OpenAI/Meta/xAI 계약은 **이미 Oracle 자체 capacity에 락인**된 RPO $553B → PE 신규 capacity와 별개 레이어. 따라서 Oracle 기존 계약 가치 훼손 없음.
- 단 신규 계약 경쟁에서는 PE-backed neo-cloud(CoreWeave, Lambda 등)와 경쟁 심화.

## 2. Thesis 실현 확률 산정

### Thesis Case 정의

Thesis 실현 시 Base 대비 달라지는 것:
- OCI가 "AI 인프라 희소성 프리미엄 + 베어메탈 락인 회피 프리미엄"을 멀티플로 수취 (PE 26~30x)
- FY27 매출 $95~100B (가이드 $90B 초과)
- FY28 매출 $150~160B (Bull 상단 초과)
- 마진 확장 (capacity 희소재 + 베어메탈 가격결정력)

### 실현 확률 분해 (v3)

| 요소 | v1 | v2 | **v3** | v3 변경 근거 |
|------|----|----|------|------------|
| 인프라 병목 지속 (≥2년) | 70% | 70% | **68%** | PE 자본 신규 capacity 공급으로 -2%p |
| Oracle이 차별적 수혜 향유 | 50% | 65% | **65%** | 변동 없음 (베어메탈 차별화 핵심) |
| 멀티플 리레이팅 실현 (26x+) | 55% | 60% | **68%** | Smart money($3.2T) 진입으로 시장 서사 가속 (+8%p) |

**복합 실현 확률**: 68% × 65% × 68% ≈ **30.1%**

### 팩트체크 감쇠

- 근거 3 간접성 감쇠: **-10%** (v2 -15%에서 완화 — 근거 5가 PE 자본배분 실증으로 보강)
- 섹터 공통 순풍 감쇠: -5% (유지)
- 30.1% × 0.85 ≈ **25.6% → 약 25%**

**Thesis Case 최종 확률: 25%** (v1 15% → v2 22% → v3 25%로 상향)

## 7. 남는 의심 포인트 (지속 모니터링)

1. **베어메탈 경쟁자 진입** — AWS·Azure가 AI 전용 베어메탈 상품군을 강화할 경우 차별화 희석. 분기별 신규 상품 출시 추적.
2. **Big Tech 자체 칩 전략** — Google TPU v7+, Amazon Trainium 3, Microsoft MAIA 차세대 칩이 OCI 베어메탈 수요 잠식 여부. 5~7년 주기이나 진행 상황 체크.
3. **PE 자본의 양방향 효과** — KKR/Brookfield/BlackRock의 신규 capacity 빌딩이 장기(5~10년)에 공급 과잉으로 작용할 가능성. neo-cloud(CoreWeave, Lambda 등) 경쟁 강도 추적.
4. **LLM 효율 개선의 속도** — 알고리즘·칩 효율이 토큰 수요 증가를 초과하면 RPO 물리적 capacity 수요 감소.
5. **OCI 멀티플 리레이팅 시장 수용도** — Q4 FY26 실적(2026년 6월) 및 FY27 가이드 상향 여부가 key.
6. **공급병목 해소 변수** — SMR·차세대 GPU·에너지 정책 변화.
7. **고객 집중도 리스크** — 베어메탈 TAM이 상위 20~50개 Big Tech에 집중되므로 10-K 고객집중도 공시 필수 확인.
8. **Smart Money 추세 역전** — PE 섹터가 AI 인프라 신규 투자를 줄이기 시작하는 시점이 멀티플 천장 신호. 분기별 신규 펀드 규모 추적.
