# GOOG — Alphabet Inc. (Class C Capital Stock)
> 글로벌 1위 검색 플랫폼(Google 글로벌 검색점유율 90%) + 3위 퍼블릭 클라우드(GCP FY25 런레이트 $70B, +48% YoY) + Waymo 자율주행(2026.2 기준 평가액 $126B) 을 보유한 AI-우선 복합 플랫폼. FY2025 매출 $402.8B (+15% YoY), 영업이익률 31.6%. **본 분석은 Alphabet Class C(무의결권, GOOG)** 기준이며, 사업·재무·SOTP 내재가치는 Class A(GOOGL)와 동일하다(주당 경제권 동일, 무의결권만 차이).

## 투자 thesis

- **90% 점유 Google Search + Gemini AI 재방어 성공** → 무형 자산(브랜드·데이터) + 네트워크 효과 + 전환비용: Google 글로벌 검색점유율 90.01% (StatCounter, 2026.3), Q4 FY25 Search & Other 매출 +17% YoY. Gemini MAU 750M 돌파(Q4 FY25), AI 챗봇 점유율 5.4%→18.2% (vs ChatGPT 87%→68%) — "검색 캐니벌라이제이션" 내러티브 실패
- **Google Cloud 수익화 변곡점 진입** → 효율적 규모 + 전환비용: Q4 FY25 Cloud 매출 $17.7B (+48% YoY), 영업이익률 30.1% (YA 17.5%, +1,260bp), **클라우드 백로그 $240B (+55% QoQ)** — 향후 4~5년 매출 가시성 확보
- **YouTube + Waymo + DeepMind의 옵셔널 가치** → Float 우위 + 무형 자산: YouTube 연매출 $60B+ 돌파(Netflix $45B 상회), Waymo $126B 외부 평가(2026.2 $16B 라운드), Gemini 3가 OpenAI 대비 기술 리더십 탈환. Google Services ex-Search의 구조적 다각화

**매수 근거 작성일**: 2026-04-19
**현재가**: $338.89 (2026-04-17 종가, 52주 고점 $350.15 대비 -3.2%, 저점 $148.40 대비 +128.4%)
**목표가**: $294 (Base SOTP DCF 가중평균 내재가치 — 아래 8-3 참조. Class C/A 동일)
**투자 기간**: 5년

## DCF 시나리오 & 가치평가

### 8-0. DCF 방법론 선택

- **적용 방식**: **B. SOTP (Sum-of-the-Parts)** + FCF DCF 교차검증
- **선택 근거**: Alphabet은 성격·멀티플·수익성이 근본적으로 다른 3개 세그먼트(Google Services, Google Cloud, Other Bets) 구조이다. **Services**는 성숙 광고 캐시카우(매출 +14%, OM ~39%, Forward PE 23~26x 상당), **Cloud**는 하이퍼그로스·이익 변곡(매출 +48%, OM 17.5→30.1% 변곡 중, 엔터프라이즈 SaaS 멀티플 7~9x 매출), **Other Bets(Waymo)** 는 외부 평가액 존재하는 옵셔널 자산($126B, 2026.2 $16B 라운드 실측). 3 세그먼트 이익 구조가 근본적으로 달라 단일 FCF DCF로 통합 시 Cloud의 수익성 변곡과 Waymo 옵셔널 가치가 왜곡된다.
- **대안 대비 우위**:
  - **FCF DCF 부적합**: Alphabet 통합 FCF는 2026 CapEx $175~185B로 일시적 왜곡 예상 — Cloud의 내재 성장 가치가 CapEx 부담에 가려짐. 또한 Waymo 같은 비영업자산의 외부 평가 가치를 무시
  - **Forward Multiple 부적합**: Services·Cloud 모두 이미 안정적 FCF·OI 발생 — Forward Multiple은 초기·적자 기업용
  - **NAV 부적합**: Alphabet은 부동산·자원기반 아님
- **주요 가정 요약**:
  - WACC: **8.0%** (Rf 10Y UST 4.26% + Beta 1.10 × ERP 5% = 9.76% Ke. Alphabet 순현금 $95B+ 구조로 유효 WACC 하향. 8% 채택)
  - Terminal g: **3.0%** (장기 미국 GDP 상한)
  - 세율: **16%** (FY25 실효세율, Alphabet 공시)
  - 예측 기간: 5년 (FY26E~FY30E)
  - Services 멀티플(세후 OI): 정상 20~24x, 스트레스 15~18x
  - Cloud 멀티플(Forward 매출): 정상 7~9x, 스트레스 5~6x (엔터프라이즈 SaaS peer - Snowflake·ServiceNow·Oracle SaaS 역사 범위)
  - Waymo 지분 평가: 외부평가 $126B × Alphabet 지분 85% × 30% 유동성 할인 = **$75B**
  - 희석 주식수: **12.2B (Class A + B + C 합계, Q3 FY25)**, 연 1.5% 감소 가정(FY30 11.35B) — 클래스별 주당 내재가치 동일하게 적용

### 8-1. DCF 구조 설계 원칙

**SOTP 밸류에이션 공식**:
```
Alphabet EV = Services 가치 + Cloud 가치 + Other Bets 가치
주주가치    = EV + 순현금 - 비핵심 부채
목표가      = 주주가치 / 희석 주식수  (Class A/B/C 합계, 클래스 무관 동일)

Services 가치 = (Services 세후 OI × 멀티플)
Cloud 가치    = (Cloud 차년 매출 × 멀티플) 또는 (Cloud 정상 OI × 멀티플)
Other Bets   = Waymo 지분 NAV + 기타 투자 - 영업손실 PV
```

**기본 가정 테이블**:

| 항목 | FY25 Actual (추정) | 5Y 기대 |

| 총 매출 | $402.8B | CAGR 10~11% → FY30 $650B |
| Services 매출 | ~$345B | CAGR 7% → FY30 $484B |
| Cloud 매출 | ~$60B | CAGR 25% → FY30 $183B |
| Services 세후 OI (FY25E) | ~$113B | CAGR 8% → FY30 $166B |

| 희석 주식수 | 12.20B | 연 -1.5% → FY30 11.35B |
| 순현금 | ~$95B | 안정 유지 |
