## 시나리오 1 — FTC Divestiture 강제 (구조 분리 판결)

**가정**:
- 2026.10 시작 FTC 반독점 트라이얼에서 2027~2028년 Logistics/Fulfillment 부문 분리 강제 판결
- Marketplace와 1P/풀필먼트 사업의 구조적 분리 — 3P 판매자 풀필먼트 외주 선택권 부여
- 광고-리테일 데이터 연계도 제한 조치 (DMA 수준 유사)
- Amazon이 항소하더라도 가처분 명령으로 2027 이행 시작

**재무/밸류에이션 충격**:
- 매출 직접 충격: NA 세그먼트 3P 수수료 수익 -15% (Seller가 풀필먼트 외주 선택) → 연 $20~30B 매출 손실
- 광고 수익성: 데이터 연계 제한으로 광고 ROAS 저하 → 광고 매출 성장률 22% → 10%로 둔화, 멀티플 20x → 14x 재조정
- 합산 OI 충격: -$15~20B 연간
- 멀티플 압축: 전체 평가에서 구조 리스크 프리미엄 적용 → -10~15%
- 주가 충격 추정: **-35~45%** (내재가치 $202 × 0.60 ≈ $121, 현재가 $250에서 -52%)

**버티는 근거**:
- AWS는 분리 대상 아님 → 전체 OI의 57%는 무관
- 분리된 Logistics 엔티티가 별도 상장 시 sum-of-parts 가치 부분 회수 가능
- Amazon의 법적 항소 (5~7년 지연) 동안 실제 이행 영향 제한적

**취약 근거**:
- 시장 멀티플 즉시 재조정 (판결 발표 ~3개월 내)
- 글로벌 모방 규제(EU/UK/인도) 연쇄 가능성
- Prime 생태계 번들 파괴 시 네트워크 효과 도미노

**관찰 지표**:
- FTC 트라이얼 1차 심리 결과 (2026.11~12)
- 판사(Seattle 연방지방법원 John Chun) 중간 판단 성향
- 유사 소송(주 법무장관 copycat) 진행 상황
- Amazon 법무팀 reserve 규모

**실현 가능성**: **10%**
- 근거: Chamber of Progress 등 "FTC 소송의 legal holes"을 지적하는 분석 + 유사 MSFT/GOOGL 반독점 결과(대부분 Consent Decree)를 감안. Divestiture 강제는 최악 tail. Base 분석에서는 Consent Decree(50%) + 기각(25%) + Divestiture(25% 중 실질 실행 25%)로 reflective probability 6~10%.

**Bear DCF 반영 시 기여**: 주가 충격 -40% × 실현가능성 10% = **-4.0%pt Bear 추가 하락**

## 시나리오 2 — AI capacity 수요 쇼크 (하이퍼스케일러 CAPEX 과잉)

**가정**:
- 2027~2028 AI 훈련 수요 둔화 (모델 수렴 + 효율화 알고리즘 + 엣지 AI로 중앙 추론 수요 분산)
- 하이퍼스케일러 $500B+ 연 CAPEX 공급 vs 수요 증가율 둔화 → capacity overhang
- AWS backlog $244B 소화율 기대 대비 저조, 신규 계약 capture rate 하락
- Trainium/Nvidia 전량 추론 프로세서 일부가 idle 상태
- 2028~2029 $55B+ D&A가 OI에 full 반영되는 시점

**재무/밸류에이션 충격**:
- AWS 매출 성장 둔화: 20% → 10%대로 급감
- AWS OI margin: 35% → 28% (idle capacity + 가격 경쟁)
- Asset impairment: $30~50B 일회성 데이터센터·장비 손상
- 전체 OI -$25~40B 연간 (정상 수준 대비)
- 주가 충격: **-30~40%** (AWS 가치 할인 × Retail 상대적 안정성 평균)

**버티는 근거**:
- AWS 1st-party 워크로드(Alexa/리테일 AI 추천/광고 타겟팅)는 자체 소비로 capacity 흡수
- Anthropic 수년 계약 + Apple partial 워크로드 → 베이스라인 수요 확보
- 광고·리테일이 AWS와 역사적으로 역상관 (경기 민감도 차이) — 전체 충격 완화

**취약 근거**:
- 커스텀 실리콘 투자가 sunk cost화 → Trainium/Graviton 투자 회수 지연
- 경쟁사(Azure)도 동시 둔화 시 가격 경쟁 격화 → 장기 margin 압박
- 주주환원 압박 (자사주 재개 지연) → 멀티플 재평가

**관찰 지표**:
- AWS backlog 증가율 (+30% 이하로 둔화 시 경고)
- 데이터센터 가동률 공시 (Amazon 별도 비공개지만 전력 소비 proxy 추적)
- Nvidia/AMD 데이터센터 매출 성장률 (동시 둔화 시 AI 수요 정점 신호)
- Anthropic/OpenAI 모델 발표 주기

**실현 가능성**: **25%**
- 근거: 역사적으로 CAPEX 사이클은 과잉 투자 → 둔화 패턴 반복(2001년 통신 버블, 2015 commodity cycle). AI 수요는 구조적이나 training compute 수요는 모델 수렴과 알고리즘 효율화로 2027~2028 변곡점 가능. 단 전체 AI 수요가 붕괴하는 것이 아닌, capacity 과잉에 의한 margin 압박이 핵심.

**Bear DCF 반영 시 기여**: 주가 충격 -35% × 실현가능성 25% = **-8.75%pt Bear 추가 하락**

## 시나리오 3 — 미·중 관세 쇼크 + 중국 소싱 차단

**가정**:
- 미 행정부 2026~2027 대중국 관세 60% 영구 부과 + 보편관세 20% 도입
- Amazon 3P 판매자의 40%+가 중국 직구/소싱 → 원가 급등 또는 시장 철수
- TikTok Shop/Temu/Shein 등 중국 플레이어가 미국 진입 차단되어 경쟁은 일부 완화되나 Amazon 자체도 공급 측 타격
- 소비자 지출 둔화 (가처분 소득 감소)

**재무/밸류에이션 충격**:
- NA 매출: -5~8% 충격 (원가 전가 불가 부분 + 수요 감소)
- NA OI margin: 7% → 5% (원가 흡수)
- International: EU/일본 위주 상대적 안정
- 광고: 판매자 광고비 축소 → 성장 22% → 13%로 둔화
- AWS: 무관 (AWS 매출은 enterprise 기반, 직접 충격 없음)
- 주가 충격 추정: **-15~25%** (Retail+광고 층의 자체 충격 — 전체 주가 대비)

**버티는 근거**:
- AWS $128.7B 매출은 관세와 무관 → 전체 OI의 57% 방어
- Amazon 소싱 다각화 (인도·베트남·멕시코) 진행 중
- AmazonBasics 등 1P 브랜드로 가격 결정력 부분 확보
- 경쟁사(Temu/Shein/TikTok Shop) 차단으로 Amazon 관련 저가 시장 회복

**취약 근거**:
- 3P 판매자 수가 급감할 경우 Marketplace 네트워크 효과 훼손
- Prime 회원 해지율 상승 (배송 속도·가격 이점 약화)
- 광고주(판매자) 축소로 광고 수익성 저하

**관찰 지표**:
- 미 관세 정책 공식 발표 (섹션별, 세율별)
- Amazon 중국 vs 인도/베트남 소싱 비중 공시 변화
- NA 3P 판매자 수 YoY 변화 (현재 900만+ 판매자)
- Consumer Confidence Index (미국)
- Amazon 1P 상품 가격 지수 (CPI 리테일 서브)

**실현 가능성**: **20%**
- 근거: 미 행정부의 대중국 정책은 양당 합의 방향, 관세 인상은 "when not if". 단 60% 영구는 tail. 보편관세는 법적 도전 받을 가능성 높음.

**Bear DCF 반영 시 기여**: 주가 충격 -20% × 실현가능성 20% = **-4.0%pt Bear 추가 하락**

## 시나리오 4 — 금리 쇼크 (10Y Treasury 5.5%+ 돌파)

**가정**:
- 인플레이션 재점화 또는 재정 리스크 프리미엄으로 10Y Treasury 4.26% → 5.5%+
- WACC +150bp 상향 (8.5% → 10%)
- 모든 growth stock 듀레이션 재조정 → Terminal Value 중심 평가 압축
- 소비자 신용 악화 → E-commerce 수요 둔화

**재무/밸류에이션 충격**:
- 멀티플 전면 압축: AWS 22x → 17x, Advertising 21x → 16x, Retail 14x → 11x
- 내재가치 직접 충격: Base $202 × 0.78 ≈ $158
- 주가 충격 추정: **-25~35%** (멀티플 압축 + 소비 둔화 복합)
- Amazon LT Debt $65.6B 리파이낸싱 비용 증가 (단기 이자비용 $500M~1B 추가)

**버티는 근거**:
- Amazon 현금 $86.8B + AWS cash cow → 신규 자금조달 의존도 낮음
- FCF 회복 시 duration 문제 완화 (growth → 성숙 레토릭 전환 가능)
- 금리 상승은 경쟁사(Shopify, Snowflake 등 growth name) 대비 상대 매력 강화

**취약 근거**:
- $200B CapEx 집행 중 자본비용 상승 부담
- Forward PE 38x는 금리 상승에 민감 (1%p 상승 시 멀티플 3~4x 압축 일반적)
- 소비 둔화가 NA 리테일 매출 직접 타격

**관찰 지표**:
- 10Y Treasury 4.5% 돌파 여부
- Fed 가이던스 (인하 사이클 유지 여부)
- ISM Services PMI
- 신용 스프레드 (IG spread 150bp+ 확대 시 경고)

**실현 가능성**: **15%**
- 근거: Fed 완화 기조 하에서 5.5% 돌파는 재정 쇼크·지정학 리스크 필요. 단 구조적 인플레 지속 + 미 재정적자 확대 시 가능.

**Bear DCF 반영 시 기여**: 주가 충격 -30% × 실현가능성 15% = **-4.5%pt Bear 추가 하락**

## 시나리오 5 — Azure-OpenAI 재결속 + 커스텀 실리콘 역전

**가정**:
- MSFT-OpenAI 관계가 2026~2027 re-깊어지고, 독점 infrastructure 파트너십 재복구
- Nvidia Blackwell Ultra/Rubin 세대(2027~2028)가 Trainium 대비 성능·전력 효율 모두 우위 확립
- Anthropic과의 AWS 파트너십은 유지되나 OpenAI 관련 생태계(ChatGPT + 기업 API)가 Azure 전용화
- AWS 커스텀 실리콘 TCO 우위 축소 → 외부 판매 둔화, 내부 전용 축소

**재무/밸류에이션 충격**:
- AWS 성장 18% → 12%로 둔화
- AWS OI margin: 35% → 31% (Nvidia 고사양 의존 재상승 → 칩 원가 증가)
- 커스텀 칩 매출 $20B → $12B로 축소 (외부 판매 감소)
- AWS 가치 멀티플 22x → 17x (성장 둔화 + 차별화 약화)
- 주가 충격 추정: **-20~30%** (AWS 가치 충격이 전체 주가의 40%)

**버티는 근거**:
- AWS 규모(32% MS) + backlog $244B는 5~7년 visibility
- Anthropic 독점 ASIC 파트너십 유지 → 주요 AI 개발자 1개 확보
- 광고·리테일 독립 성장 지속

**취약 근거**:
- AI 시대 narrative에서 AWS 기술 우위 서사 훼손 → 멀티플 재평가
- Trainium 3/4 사전 주문 일부 취소 가능성
- 하드웨어 사이클(2~3년) 특성상 이번 패배가 차기 세대에도 이연 가능

**관찰 지표**:
- Azure AI revenue run rate (분기별 추격 속도)
- Nvidia 제품 로드맵 공식 발표 (GTC 2026, 2027)
- Anthropic API 매출 & AWS 전용 비중
- Trainium3/4 독립 벤치마크 (MLPerf 공식)
- MSFT-OpenAI 파트너십 재편 공식 공시

**실현 가능성**: **20%**
- 근거: MSFT-OpenAI 관계는 2025~2026 긴장이 있었으나 재결속 여지 존재. Nvidia 차세대가 Trainium 대비 우위 확립은 역사적 패턴(Nvidia 지속 세대 개선)과 일치. 단 AMZN 반격 여지도 존재(Trainium3).

**Bear DCF 반영 시 기여**: 주가 충격 -25% × 실현가능성 20% = **-5.0%pt Bear 추가 하락**

## Bear → Stress 반영 시 비교

**Base 파일 참조값**:
- Base DCF 시나리오 "Bear" 중간값: $156
- Base DCF 시나리오 "Extreme Bear" 중간값: $85
- 가중평균 내재가치: $202

**비교 블록**:
```
Bear $156 → 단순합산 적용 시 $156 × (1-0.26) = $115
         → 동조성 보정 시     $156 × (1-0.17) = $130
         → Extreme Bear $85 와의 위치: 보정값 $130이 Bear-EB 중간
```

**시사점**:
- Stress 시나리오 누적 리스크를 Bear에 반영하면 **$115~130 범위**로 내려감 — 이는 현재 Bear $156보다 낮고 Extreme Bear $85보다 높음
- 즉 **Base 분석의 Bear는 stress 꼬리 리스크를 일부만 반영** — 실제 multi-shock 복합 시나리오는 Bear와 Extreme Bear 사이에 독립 "Stress Bear" 구역 존재
- 단, stress 시나리오는 정의상 꼬리(tail) 사건이며 복합 실현 확률이 낮음 → Revaluation 가중평균에는 반영하지 않음. 참고 시뮬레이션으로만 사용

**주의**: Base 가중평균 계산에는 위 stress 시나리오 기여를 포함하지 않는다. Base 파일의 가중평균 $202가 공식 내재가치.
