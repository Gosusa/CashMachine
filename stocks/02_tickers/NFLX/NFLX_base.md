# NFLX — Netflix, Inc.
> 글로벌 1위 SVOD 스트리밍 플랫폼(유료 회원 325M+, 2025.12). FY2025 매출 $45.2B (+15.9% YoY), 영업이익률 29.5%, FCF $9.46B(+36.7%). 2026 가이던스 매출 $50.7~51.7B(12~14%), OM 31.5%, 광고 매출 ~2배($1.5B → $3B). 2025.11 10-for-1 액면분할 완료(post-split 4.22B 주식, 분석 전반에서 분할 후 기준 사용).

## 투자 thesis

- **325M 글로벌 유료 회원 + 압도적 시청 시간 점유율** → 네트워크 효과 + 데이터 무형 자산: Family DAU 약 700M+ 추정(가구당 2~3인), Q4 2025 글로벌 시청 시간 점유율 8% (Nielsen 미국 TV 기준), Q1 2026 매출 $12.25B(+16.2%), OM 32.3%(전년 31.7% 대비 +0.6%pt) — 콘텐츠 추천 알고리즘 + 글로벌 카탈로그 규모로 타사 대비 시청 효율성(시간/회원/$ 콘텐츠 지출)에서 구조적 우위.
- **광고 사업 본격 가속 + 가격 결정력 동시 작동** → 데이터 무형 자산 + 효율적 규모: 광고 지원 티어 MAU 94M(2025.Q4 기준), FY25 광고 매출 $1.5B+(+150% YoY), 2026 가이던스 ~$3B(roughly doubling). Trade Desk·Magnite·Google DV360 12개 광고 시장 통합 + 자체 Ads Suite 출시. 2025년 미국·캐나다 가격 인상에도 churn 통제(분기 가입자 +5M+ 유지) — 콘텐츠 가치 기반 가격 결정력 입증.
- **콘텐츠 투자 규모 + FCF 전환 동시 달성** → 효율적 규모 + 진입장벽: 2026 콘텐츠 지출 $20B 계획(2025 $18B → +11%) — Disney+ ~$24B / WBD ~$15B / AMZN(Prime Video) ~$15B+ 대비 글로벌 단일 플랫폼 효율 1위. WWE 10년 $10B + NFL Christmas + MLB + FIFA로 라이브 스포츠 진입 확장 중. FY25 FCF $9.46B로 콘텐츠 비용 자체 조달 + 자사주 매입 능력 확보.

**매수 근거 작성일**: 2026-04-19
**현재가**: $97.31 (2026-04-17 종가, 52주 고점 $134.12 대비 -27.4%, 저점 $75.01 대비 +29.7%, post-split 기준)
**목표가**: $102 (Base DCF 가중평균 내재가치 — 아래 8-3 참조)
**투자 기간**: 5년

> 현재가 대비 가중평균 내재가치 **+4.8%**. 매수 기준(20%+ 할인) 미달, 분할 매수 기준(15%) 미달. 본 세션 결과는 **"보유"** 수준이며 신규 매수는 Bear 중간값 $75 부근 구간 권장. 애널리스트 컨센서스 $119는 본 가중평균보다 낙관적(Base + Bull 가중) — 본 분석은 Bear 이하 40% 보수 가중치 반영. Q1 2026 EPS $1.23 beat에도 Reed Hastings 보드 이탈 발표(2026.4.16)로 -10% 시간외 하락한 점은 거버넌스 프리미엄 약화의 신호. 상세는 9번 종합 판정.

## 사업 구조 및 경제적 해자

### 2-1. 세그먼트 구조 요약

NFLX는 단일 사업(글로벌 스트리밍 SVOD + 광고 지원 티어) 구조이나, 수익원·해자 측면에서 다음 4개 sub-경제로 분해된다:

| 세그먼트 | 수익원 | 규모 지표 (FY25) | 해자 유형 | 해자 강도 |
|---------|------|---------|---------|---------|
| **구독 매출 (광고 없는 티어)** | Standard / Premium 월 구독료 | ~$43.7B (96.7% 비중), ARM ~$11.70 | 네트워크 효과(콘텐츠 카탈로그 규모), 데이터 무형 자산(추천 알고리즘), 브랜드, 전환비용(시청 이력) | Wide |
| **광고 지원 티어 (Ad-Tier)** | Basic with Ads 구독료 + 광고 매출 | ~$1.5B 광고 + 일부 구독, MAU 94M | 데이터 무형 자산(시청 데이터로 광고 타겟팅), 효율적 규모(광고주 수요 풀), 신생 — 진입장벽 약함 | Narrow → Wide 진화 중 |
| **콘텐츠 IP / 라이브 스포츠** | 자체 IP·라이선스(Stranger Things·Squid Game·Bridgerton 등) + WWE·NFL·MLB·FIFA | 콘텐츠 자산 $32B+ (BS Net Content Assets) | 무형 자산(IP), 독점 라이센스(WWE 10년) | Narrow (스포츠), Wide (오리지널 IP) |
| **국제 확장 (APAC·LATAM)** | 신흥시장 저가형 모바일 플랜 + 광고 티어 | $4.0B 합산(8.8% 비중), APAC +17% | 효율적 규모(글로벌 콘텐츠 단일 라이브러리), 현지 콘텐츠 제작 우위 | Narrow |

> 출처: Netflix Q4 2025 shareholder letter (ir.netflix.net, 2026.1.20), 10-K FY2025 (SEC, 2026.1.23), Q1 2026 shareholder letter (ir.netflix.net, 2026.4.16).

**세그먼트별 해자 집중도**:
- 구독 매출: 회사 가치의 핵심. 콘텐츠 카탈로그 + 추천 알고리즘 + 브랜드 복합 해자가 약 **75% 가치 기여**
- 광고 지원 티어: 미래 성장 동력. 2025~2028 매출 기여 비중 4% → 12~15% 추정. 약 **15% 가치 기여 (옵셔널리티 포함)**
- 콘텐츠 IP / 라이브 스포츠: 독점 IP는 평가절하되어 자산 인식되나 시청 시간·구독 유지의 근본 동력. 약 **8% 가치 기여**
- 국제 확장: 신흥시장 침투. 약 **2% 추가 옵셔널리티**

### 2-2. 세그먼트별 상세

#### 구독 매출 — 네트워크 효과 + 데이터 무형 자산 + 브랜드

**사업 구조**: 글로벌 190+ 국가 단일 스트리밍 서비스. Standard($15.49/월 미국), Premium($24.99/월 미국), Basic with Ads($7.99/월 미국). 2025년 미국·캐나다 가격 인상(2024.Q1 → 2025.Q1 약 14% 상승)에도 분기당 +5M+ 신규 가입자 추가 — 가격 비탄력적 수요 확보. ARM(Average Revenue per Member) FY25 $11.70 (FY24 $10.82 → +8%).

| 해자 유형 | 내용 |
|---------|------|
| **네트워크 효과 (콘텐츠 카탈로그 ↔ 사용자 규모)** | 325M 회원 × 연 $4~8 시청료(직간접) = 콘텐츠 투자 $20B 자체 조달 능력. 사용자 규모가 콘텐츠 투자 규모를 정당화하고, 콘텐츠 규모가 다시 사용자 유치 — Disney+ 127M / Max 122M / Prime Video 200M+ 대비 압도적 단위 경제성 |
| **데이터 무형 자산 (추천 알고리즘)** | 20년 누적 시청 행동 로그(시청 시작·중단·완료·평점·검색·재시청·시간대). 글로벌 단일 카탈로그에서 학습한 추천 모델은 신규 콘텐츠 ROI를 사전에 예측. Nielsen US streaming 시청 시간 점유율 약 8% (Q4 2025) — 1인당 시청 효율성 1위 |
| **브랜드 (콘텐츠 큐레이션 신뢰)** | "Netflix and chill"이 영어 일상 표현으로 정착. Stranger Things·Squid Game·Wednesday 등 글로벌 컬쳐럴 인덱스 보유 — Disney·Max는 IP 의존, Netflix는 신규 IP 창출 능력 |
| **전환비용 (시청 이력·프로필·구독 자동결제)** | 5명 멀티 프로필 + 시청 진행 상태 + Watchlist + 추천 알고리즘 학습 — 타 플랫폼 이동 시 모두 리셋. 가족 공유 정착 및 ARM $11.70 유지 |
| **효율적 규모 (콘텐츠 단가 분산)** | 콘텐츠 $20B / 325M 회원 = 회원당 $61.5/년 콘텐츠 비용. Disney $24B / 127M = $189 — Netflix가 3배 효율 |

**하위 매출 규모 (FY2025)**:

|-----------|----------|---------|
| 구독 매출 (광고 없는 티어 + 광고 티어 구독료) | ~$43.7B | +14% 추정 |
| 광고 매출 | ~$1.5B | +150% 이상 |
| 합계 (Total Revenue) | $45.2B | +15.9% |

|------|-------------|-----|

#### 광고 지원 티어 — 데이터 무형 자산 + 효율적 규모

**사업 구조**: 2022.11 Basic with Ads 출시. 2025.Q4 MAU 94M 도달(2024.Q4 70M → +34%). Trade Desk·Magnite·Google DV360 12개 시장 통합(2025.Q2 완료) + 자체 Ads Suite 플랫폼 가동. 2026년 Pause Ads + Interactive Mid-rolls (GenAI) 출시 예정. 신규 가입자의 55%+ 광고 티어 선택(2025).

| 해자 유형 | 내용 |
|---------|------|
| **데이터 무형 자산 (시청 데이터 → 광고 타겟팅)** | 글로벌 시청 행동 데이터를 광고 타겟팅에 활용. 광고 단가가 콘텐츠·시청 맥락(특정 쇼·장르) 기반으로 프리미엄 가격 가능 |
| **효율적 규모 (광고주 수요 풀)** | 94M MAU + 95% 광고 시청 완료율(전통 TV 대비 우위). 2026 ~$3B 광고 매출은 글로벌 CTV 광고 시장 ~$30B의 10% 점유 추정 |
| **광고 시장 통합 인프라** | Trade Desk·Magnite·DV360 직접 연결 + 자체 Ads Suite — 광고주 입장 진입 단계 단순화 |
| **콘텐츠 차별화 (신생, 약함)** | Hulu·Peacock·Max 광고 티어와 동일 경쟁 구도. 콘텐츠 카탈로그 우위가 광고 티어 ARPU 프리미엄 형성 |

**광고 사업 진척**:

| 시점 | MAU | 광고 매출 | YoY |
|------|-----|----------|-----|
| 2022.Q4 출시 | 1M | <$50M | — |
| 2024.Q4 | 70M | $0.6B (추정) | +200%+ |
| 2025.Q4 | 94M | $1.5B+ | +150%+ |
| 2026 가이던스 | 130M+ 추정 | ~$3B | +100% |
| 2028 추정 | 200M+ | $6~8B | — |

> 2028 광고 매출 $6~8B 추정 시 전사 매출의 10~12% 비중 — 광고 사업이 Bull 시나리오 핵심 동인.

#### 콘텐츠 IP / 라이브 스포츠 — 무형 자산(IP) + 독점 라이센스

**사업 구조**: 자체 제작 오리지널(Stranger Things·Squid Game·Wednesday·Bridgerton) + 라이선스 콘텐츠 + 라이브 스포츠 신규 진입(WWE Raw 10년 $10B 독점, NFL Christmas 3년 마지막 시즌, MLB·FIFA 부분 권리). 2026 콘텐츠 지출 $20B (2025 $18B → +11%).

| 해자 유형 | 내용 |
|---------|------|
| **무형 자산 (IP 라이브러리)** | 다년간 누적 오리지널 IP 자산. 단년 콘텐츠 지출 $20B는 Disney $24B 대비 적으나, 글로벌 가입자 1위 + 효율적 자산 회전(시청 시간/콘텐츠 비용)에서 우위 |
| **독점 라이브 스포츠 라이센스** | WWE Raw US/Canada/UK 10년 $10B 독점 — Linear TV 경쟁자 봉쇄. NFL Christmas Day는 단발성이나 라이브 스포츠 제작 역량 검증. MLB·FIFA 부분 권리로 점진 확장 |
| **자체 제작 인프라 (스튜디오, 글로벌)** | Albuquerque·런던·서울·마드리드 등 자체 스튜디오 보유 — 외부 라이선스 의존도 점진 감소 |

**콘텐츠 자산 규모** (FY2025 BS):

| 항목 | FY25 |
|-----|------|
| Net Content Assets | ~$32B |
| 연간 콘텐츠 지출(현금) | ~$18B |
| 콘텐츠 amortization | ~$15B |
| 콘텐츠 amort./매출 | 33% |

> 콘텐츠 amortization은 5년 내 현금 콘텐츠 지출의 80%+를 비용 인식. 단년 OM 29.5%는 콘텐츠 비용 분산 효과 반영.

#### 국제 확장 (APAC·LATAM) — 효율적 규모

**사업 구조**: 신흥시장은 모바일 전용 플랜($2~5/월) + 광고 지원 티어로 침투. APAC YoY +17%, LATAM +15% 성장률은 UCAN·EMEA(+18%)와 유사하나 ARM 격차 큼. 한국 콘텐츠(Squid Game) 글로벌 히트 사례 — 신흥시장 콘텐츠가 글로벌 가치 창출 가능성.

| 해자 유형 | 내용 |
|---------|------|
| **효율적 규모 (글로벌 단일 라이브러리)** | 한국·인도·브라질 콘텐츠 제작비가 미국 시청에서도 가치 창출. 단일 플랫폼 글로벌 배포 |
| **현지 콘텐츠 제작 (선점 우위)** | 한국·인도·일본·브라질 콘텐츠 제작 hub — 현지 1위 SVOD (Disney+ Hotstar 인도 외 대부분) |
| **모바일 침투 인프라** | Android Go 디바이스, 통신사 번들 (Reliance Jio 인도 등) — 신흥시장 데이터 비용 부담 회피 |

> 단, 신흥시장 ARM이 평균 ARM의 1/3~1/4 수준 → 매출 성장 기여 < 회원 성장 기여.

### 5-3. 경쟁 우위 원천 분석

**1. 글로벌 단일 카탈로그 + 콘텐츠 효율 3배 우위**
- 우위 내용: 단일 라이브러리 글로벌 배포(190+ 국가). 한국 Squid Game이 미국·유럽·LATAM에서 동시 시청. Disney·WBD는 지역별 콘텐츠 권리 분리로 효율 낮음
- 정량 근거: 콘텐츠비/회원 $61.5(NFLX) vs $189(Disney+ 단독) vs $75(Prime). 콘텐츠 amortization/매출 33%
- 경쟁사 격차: Disney·WBD 합병 후에도 콘텐츠비/회원 ~$75 추정 → NFLX 효율 1.2배 격차 유지
- 복제 난이도: 매우 높음 — 글로벌 가입자 베이스 + 단일 카탈로그 권리 구조 동시 필요
- 격차 지속 기간 추정: **10년+** — 구조적 해자

**2. 추천 알고리즘 + 시청 데이터 자산**
- 우위 내용: 20년 누적 글로벌 시청 행동 데이터. 신규 콘텐츠 ROI 사전 예측 + 광고 타겟팅 활용
- 정량 근거: Nielsen US streaming 시청 시간 점유율 8%, 회원당 시청 시간 효율 1위 (정확한 수치 회사 비공개), 신규 가입자 55%+ 광고 티어 선택
- 경쟁사 격차: Disney·WBD 알고리즘은 단일 플랫폼 데이터, Amazon은 거래 데이터 강점이나 시청 데이터는 NFLX 우위
- 복제 난이도: 높음 — 시청 데이터 규모 + 콘텐츠 카탈로그 결합 필요
- 격차 지속 기간 추정: **5~10년** — AI 추천 모델 자체는 따라잡힐 수 있으나 데이터 규모 우위 유지

**3. 가격 결정력 (브랜드 + 전환비용 결합)**
- 우위 내용: 2024.Q1 → 2025.Q1 약 14% 가격 인상에도 분기 가입자 +5M+ 유지. 콘텐츠 가치 기반 가격 결정력
- 정량 근거: ARM $10.82 → $11.70 (+8%), Premium 티어 $24.99/월 (OTT 최고가)
- 경쟁사 격차: Disney+는 가격 인상 후 가입자 둔화 사례. Max·Paramount+ 전환기 가격 압박
- 복제 난이도: 중간 — 콘텐츠·브랜드 결합에서 도출되므로 단순 모방 불가
- 격차 지속 기간 추정: **3~5년** — 가격 천장 도달 가능성 (UCAN Premium $24.99 이미 높음)

- 정량 근거: FY25 광고 매출 $1.5B (+150%), 2026 ~$3B 가이던스
- 경쟁사 격차: YouTube 광고 매출 $30B+ — 절대 규모 NFLX의 20배. Hulu/Disney 광고 +Prime Video 광고도 NFLX와 유사 또는 우위
- 복제 난이도: 낮음 — 광고 인프라는 표준화됨. 차별화는 콘텐츠 + 시청 데이터에 의존

### 5-4. 투자 차별화 근거

1. **SVOD 영업이익률 29.5%**: 글로벌 SVOD 중 유일하게 30% 근접 — 경쟁사(Disney DTC ~10%) 대비 **+19%pt**. 콘텐츠 효율 3배 우위에서 도출
2. **325M 회원 + 단일 글로벌 카탈로그**: 콘텐츠 $20B를 회원당 $61.5로 분산 가능 — 경쟁사 중 유일. Paramount+WBD 합병 후에도 격차 유지
3. **광고 사업 2배씩 성장 (FY25 $1.5B → FY26 ~$3B)**: 광고 사업은 5년 내 NFLX 매출의 12~15% 기여 가능. 단, YouTube 대비 절대 규모 열위 — Bull 시나리오 핵심 변수

## DCF 시나리오 & 가치평가

### 8-0. DCF 방법론 선택

- **적용 방식**: A. Standard FCF DCF (주) + E. Forward Multiple (교차검증)
- **선택 근거**: NFLX는 단일 사업(글로벌 SVOD + 광고)으로 안정적 FCF 생성($9.46B FY25, +36.7% YoY), 자본집약도 예측 가능(콘텐츠비 39.2% / 매출 가이던스), 성숙 단계 진입(미국 시장 mature, 신흥시장 성장). 02_dcf_guide.md Step 1 판별 테이블의 "안정적 FCF 생성 + 단일 사업 + 성숙 단계 → A. Standard FCF DCF" 일치.
- **대안 대비 우위**: 
  - B. SOTP 부적합 — 단일 사업 구조, 광고 사업이 별도 분리되지 않고 시청 데이터·콘텐츠와 통합 운영
  - D. NAV 부적합 — 콘텐츠 자산($32B BS)이 가치의 핵심 동인 아님 (브랜드·알고리즘·가입자 베이스가 핵심)
  - E. Forward Multiple은 **보조 활용** — Terminal Value 비중이 70%+ 가능성 높아 Multiple 교차검증 필수
- **주요 가정 요약**: WACC 9% (10Y Treasury 4.31% + ERP 5% + Beta 1.0 + 0.4 small premium adjusted), Terminal g 3% (장기 GDP 상한), 세율 17% (NFLX 역사적 실효세율), 예측 기간 5년 (2026~2030). Forward Multiple 교차검증은 2027 EPS × 적용 PE 28~32x.

### 8-1. DCF 구조 설계 원칙

**이익 변수**: NFLX의 이익은 ① 구독 매출 (96.7%, 안정·반복) + ② 광고 매출 (3.3%, 변동·성장) + ③ 콘텐츠 amortization (비용·계산적 안정). FCF는 영업현금흐름 - CapEx (콘텐츠 cash spend는 현금흐름 흐름표 별도 항목으로 처리). NFLX FCF는 콘텐츠 cash spend가 amortization과 거의 일치하는 시점에 안정화.

**밸류에이션 공식**:
```
EV = Σ [ FCF_t / (1+WACC)^t ]  +  Terminal Value / (1+WACC)^5
주주가치 = EV - Net Debt
목표가 = 주주가치 / 희석 주식수

Terminal Value (Gordon) = FCF_2030 × (1+g) / (WACC - g)
교차검증: 2027 EPS × Forward PE
```

**기본 가정 테이블**:

| 항목 | 값 | 근거 |
|------|-----|------|
| FY25 FCF | $9.46B | 10-K FY2025 |
| FY26 FCF (가이던스 추정) | $11.5~13B | OM +2%pt 가이던스 + 콘텐츠비 +11% |
| 희석 주식수 (현재) | 4.22B (post-split) | 10-K FY2025 |
| 5년 후 희석 주식수 | 4.05B (자사주 매입 -0.8%/년) | NFLX 자사주 매입 트랙레코드 |
| 투자 기간 | 5년 (2026~2030) | 분석 가이드 표준 |
| WACC | 9% | RFR 4.31% + ERP 5% × Beta 1.0 + 0.4 자체 |
| Terminal g | 3% | 장기 GDP 상한, NFLX 매출 mid-단자릿 성장 가정 |
| Net Debt | $4.5B | Cash $9.0B - LT Debt $13.5B (FY25) |

**멀티플 기준** (Forward Multiple 교차검증용):

| 환경 | Forward PE 범위 | 근거 |
|------|---------------|------|
| 정상 | 28~32x | NFLX 역사적 평균 35x ± 변동, 성숙도 반영 보수적 조정 |
| 스트레스 | 18~22x | Disney·Max 등 SVOD peer 수준 |

> NFLX 역사적 PE는 25~50x 광범위하게 변동 (성장률·가입자 모멘텀에 민감). 공식 설계는 보수적으로 정상 28~32x 적용.
