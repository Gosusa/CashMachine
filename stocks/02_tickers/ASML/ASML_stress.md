## 시나리오별 스트레스 테스트

### 1. MATCH Act 전면 통과 + EU 동조 → 중국 DUV 전면 봉쇄

**가정**:
- 미국 MATCH Act 2026년 말 상·하원 통과, 2027년 시행
- EU는 자체 제재 패키지로 동조 (ASML 본사 네덜란드 영향)
- ASML의 대중국 DUV 수출 **전면 금지**
- 이미 설치된 중국 DUV에 대한 **서비스/부품 공급 제한** 확대 (부분적)

**재무/밸류에이션 충격**:
- 중국 DUV 매출 즉시 소실: 2026E 기준 €6~7B (전체 매출의 17~18%)
- IBM의 중국 서비스 매출 3년간 단계적 축소: 연 €1.5B (전체 IBM €8B의 18%)
- 2027년 매출 €32B 수준으로 후퇴 (2025 수준)
- GM 150~200bp 훼손 (고정비 지렛대 감소)
- 멀티플 de-rating: 30x → 22x 수준
- **주가 충격: -35~-45%**

**회사가 버티는 근거**:
- 로직 (66%) 은 대부분 TSMC/Samsung/Intel → 중국 외 지역으로 이동 가능
- 중국 DUV 수요는 **잃더라도 글로벌 수요 초과 상태** (High-NA/EUV 공급 제약 해소 효과 있음)
- 수주잔고 €40B는 중국 외 고객 중심

**취약한 근거**:
- 중국 수요 소멸 시 DUV 공장 가동률 저하 → 고정비 지렛대 악화
- IBM 중국 비중 상실은 **장기 복구 불가능**
- 중국 정부 보복 (희토류 수출 제한 등) 간접 영향

**관찰 지표**:
- MATCH Act 하원 투표 일정 (2026 Q3 예상)
- EU 집행위원회 반도체 수출통제 공식 입장
- ASML 경영진 컨콜에서 "중국 가이던스" 언급 변화
- 네덜란드 정부 공식 입장 (DUV 수출 허가 연장 여부)

**실현가능성**: **35%**
- 미 의회 양당 합의 가능성 중간 (선거 결과에 좌우)
- EU 동조 가능성 50~60% (ASML 본사 영향으로 신중)
- 결합 확률: 0.5 × 0.6 ≈ 30%, 상향 조정하여 35%

**Bear DCF 반영 시 기여**:
```
충격: 주가 -40% (중앙값) × 실현가능성 35% = Bear 기여 -14%pt
```

### 2. AI Capex 버블 붕괴 (Hyperscaler 대규모 CAPEX 삭감)

**가정**:
- MSFT/META/GOOGL/AMZN 4사 2027년부터 AI CAPEX 30%+ 삭감
- 원인: GenAI ROI 실망, ASIC 경쟁 심화, 전력/발전소 병목 지속 → 실질 capex 실행 불가
- TSMC/Samsung 이 2027 파운드리 CAPEX 20~30% 삭감으로 반응
- ASML 신규 수주 감소, 수주잔고 6개월 내 €40B → €30B 하락

**재무/밸류에이션 충격**:
- 2027~2028 매출 €38~40B → €30~32B로 후퇴 (-20%)
- EUV 수주 연 20대 미만으로 급감 (2025 48대 → 25대)
- GM 48~50%로 하락 (가동률 저하)
- Multiple compression 25x → 18x
- **주가 충격: -40~-50%**

**회사가 버티는 근거**:
- IBM 매출 (€8B) 은 설치기반 기반이라 사이클 저항
- 수주잔고 €40B는 2027 매출의 1년치 커버
- 역사적 사이클 (2019, 2022~23) 에서 ASML 회복력 입증
- 메모리 HBM 수요는 AI와 부분 독립 (추론용 독립 수요)

**취약한 근거**:
- ASML 전체 매출의 70%+ 가 시스템 (장비) 인 점
- 로직 66% 의존도 높음 → AI가 로직 CAPEX의 주 드라이버
- 2025년 고점 매출에서의 자연 사이클 돌입 리스크

**관찰 지표**:
- 하이퍼스케일러 분기 CAPEX 가이던스 (분기별 -5% QoQ 시 경고)
- TSMC 분기 CAPEX 발표 (2027 가이던스 <$50B 시 경고)
- ASML 분기 신규 수주 (분기별 €5B 미만 시 경고)
- GenAI 상용화 ROI 지표 (OpenAI/Anthropic 가격 전쟁)

**실현가능성**: **25%**
- AI 버블 역사적 사이클 반복 가능성 (2000 닷컴) 중간
- 단 AI는 현재 실질 생산성 확인 중 → 완전 붕괴 확률 낮음
- "30%+ 삭감" 시나리오로 한정 → 25%

**Bear DCF 반영 시 기여**:
```
충격: 주가 -45% (중앙값) × 실현가능성 25% = Bear 기여 -11%pt
```

### 3. TSMC A10 High-NA Skip (고객 adoption 지연)

**가정**:
- TSMC가 2027년 발표에서 A10 (1.0nm) 도 High-NA 대신 Double Patterning + Low-NA 유지 결정
- Samsung/Intel 외 추가 High-NA 주요 고객 확보 실패
- High-NA 출하 연 10대 미만으로 고착 (ASML 기대 연 20~30대 대비 절반)

**재무/밸류에이션 충격**:
- 2030 매출 €50~52B (Base) → €44~45B (하한)
- 2030 GM 56% (하한, 가이던스 하단)
- High-NA ASP 효과 제한 → FCF margin 개선 지연
- 멀티플: Bull premium 상실 (22x → 18x)
- **주가 충격: -25~-35%**

**회사가 버티는 근거**:
- Low-NA EUV 수요는 Double Patterning 시 **더 증가** (동일 노드에 이중 노광 → Low-NA 장비 수요 증가)
- Intel High-NA 양산 단독 성공 시에도 레퍼런스 확보 가능
- Samsung/SK Hynix DRAM High-NA 채택 진전 가능

**취약한 근거**:
- High-NA ASP $360~400M × TSMC 미채택 = 2030 매출 상단 €60B 불가
- Bull 시나리오 전제 붕괴 → multiple compression
- TSMC = ASML 최대 고객 (33%) 의 기술 경로 이탈 심리적 충격

**관찰 지표**:
- TSMC 2027 Technology Symposium에서 A10 공정 발표
- TSMC 분기 컨콜에서 High-NA 언급 빈도
- Samsung/Intel High-NA 대수 확대 페이스
- ASML 컨콜에서 High-NA 수주 가이던스 변화

**실현가능성**: **30%**
- TSMC는 이미 A14에서 skip 선언 → A10 skip도 자연 연장선 가능성 30~40%
- 그러나 2030년까지 미루지는 못할 것이라는 반론 (경쟁사 대비 노드 열위)
- 중간 확률 30%

**Bear DCF 반영 시 기여**:
```
충격: 주가 -30% (중앙값) × 실현가능성 30% = Bear 기여 -9%pt
```

### 4. WACC Shock (금리 +200bp 상승)

**가정**:
- 미 10Y 4.26% → 6.26% 수준까지 상승 (2027~2028년)
- 원인: 인플레이션 재발 또는 재정적자 우려
- ASML EUR WACC 8% → 10%
- 고성장 멀티플 구조적 압축 (Growth stocks de-rating)

**재무/밸류에이션 충격**:
- Base DCF 재계산 (WACC 10% 적용):
  - TV PV: 422.4 × 0.621 = €262.3B (vs 기존 €287.7B)
  - 추가 Explicit PV 영향: 약 -5B
  - EV: €317B → Equity €326B → €840/share → ADR **$924**
  - Base 목표가 $1,019 → $924 (**-9%**)
- 멀티플 압축 효과 (22x → 18x): 추가 -15~20%
- **주가 충격: -15~-25%** (DCF + 멀티플 이중 효과)

**회사가 버티는 근거**:
- ASML 현금 보유 €8~9B → 금리 상승 시 이자 수익 증가
- 부채 최소 (부채 대비 현금 넷포지션)
- 고객도 동일한 WACC 환경 → 경쟁력 유지

**취약한 근거**:
- Forward PE 33x 에서 20x로 축소 가능성 (반도체 장비 peer 평균 수준)

**관찰 지표**:

- 30Y 모기지 금리 7.5%+
- 나스닥 성장주 지수 de-rating 속도

**실현가능성**: **20%**

- 그러나 재정 리스크 (미 부채 증가) 상존

### 5. 중국 반도체 자립 가속 (SSMB/SiCarrier 실제 돌파)

- 중국이 2030~2032년 내 양산급 EUV 또는 28nm ArF Immersion 대안 기술 실증

- 중국 파운드리 (SMIC) 가 ASML 없이 14nm 이하 양산

**재무/밸류에이션 충격**:
- 이미 중국 매출 비중 축소 중이므로 단기 영향 제한적
- 그러나 **Wide Moat 훼손 심리적 충격** → 장기 성장 가정 붕괴
- 5년 후 (2031~) 중국 외 제3국 수출 가능성 확대 시 추가 위협
- 멀티플 de-rating 영구적 (독점 premium 상실)
- **주가 충격: -30~-40%** (구조적, 회복 장기화)

**회사가 버티는 근거**:
- 중국 기술 실증과 글로벌 확산 간 격차 5~10년
- 비중국 고객 (미국, EU, 한국, 대만) 은 여전히 ASML 유일
- ASML의 10년 선행 로드맵 (Hyper-NA 등) 으로 격차 재확보

**취약한 근거**:
- "EUV 독점" 내러티브 붕괴 시 PE 40x → 20x 급락
- 미국 정부 지원 약화 시 EU 시장에서도 중국 진입 가능성
- Zeiss 광학 기술의 구조적 우위 약화 가능성

**관찰 지표**:
- SSMB 실험기 양산급 스펙 공개 (현재는 claim 수준)
- SMEE 28nm ArF Immersion 실증 (현재 KrF 단계)

- CSIS/SIA 전문가 그룹 전망 변화

**실현가능성**: **15%**

- 그러나 중국 정부 보조금 1조 위안 수준 투입 중

### 동조성 보정 (시나리오 간 상관관계)

**상관관계 분석**:

- **시나리오 6 (Zeiss)**: 대체로 독립적
- **시나리오 1 ↔ 2**: 낮음 (규제 vs 사이클, 독립)

**동조성 보정 방법**: 상관관계 높은 그룹의 중복 기여를 0.5~0.7 할인. 구체적으로:
- 그룹 A (1+5): -14.0 + (-5.3) × 0.6 = -14.0 - 3.18 = -17.18%pt
- 그룹 B (2+3+4): -11.3 + (-9.0) × 0.7 + (-4.0) × 0.8 = -11.3 - 6.30 - 3.20 = -20.80%pt
- 독립 (6): -3.0%pt
- **동조성 보정 합계: -40.98 %pt** (약 -41%)

### Bear → Stress 반영 시 비교

Base.md 파일의 Bear 중간값 $633, Extreme Bear 중간값 $473 을 가져와 비교:

```
원본 Bear (Base DCF)               : $633
단순합산 적용 시 (-46.6%)           : Base $1,019 × (1 - 0.466) = $544
동조성 보정 시 (-41.0%)             : Base $1,019 × (1 - 0.410) = $601
원본 Extreme Bear (Base DCF)        : $473
────────────────────────────────────────
```

**시사점**:
- 스트레스 테스트를 Bear에 단순 합산하면 $544 수준 (Base Bear $633 보다 낮음)
- 동조성 보정 시 $601 (Base Bear $633 와 근접)
- **Base의 Bear ($633) 는 이미 주요 리스크 1~3번을 상당 부분 반영**한 수치로 해석 가능
- Extreme Bear ($473) 는 **모든 스트레스 복합 실현 + 추가 Terminal multiple 압축** 시나리오에 해당
