# PLTR — 스트레스 테스트

> Base DCF 시나리오(Extreme Bear / Bear / Base / Bull)로 포착이 어려운 **외생 충격·꼬리 위험**에 대한 시나리오 테스트.
> **Revaluation 가중평균에는 반영하지 않는다.** 참고용 시뮬레이션.

---

## 시나리오별 스트레스 테스트

### 1. 금리 급등 + WACC 재평가 (+200bp)

**가정**:
- 미국 인플레이션 재점화 + 10Y Treasury 4.31% → 6.5%로 상승
- PLTR 같은 장기 성장 기업 WACC 10% → 12% (+200bp)
- SaaS 멀티플 전반 20~30% 압축 연쇄
- FY26 Q3~Q4 금리 매크로 쇼크 시나리오

**재무/밸류에이션 충격**:
- Y1-Y10 FCF PV: WACC +200bp 시 약 -15% 감소 (장기 가치 집중 구조)
- Terminal Value 공식 (Exit Multiple 28x 유지하되 할인율 상승): TV PV -25%
- Base 목표가: $158 → $125 (약 -21%)
- Bear 목표가: $60 → $48 (약 -20%)

**회사가 버티는 근거**:
- 순현금 $7B+ + FCF 마진 51% → 부채 의존도 없어 자본비용 직접 충격 제한
- Rule of 40 127% → 성장 기업 중 가장 먼저 "안전 자산"으로 재평가될 수 있음

**취약 근거**:
- EV/Sales 47x는 저금리 환경 전제 — 금리 정상화 시 멀티플 자연 압축 우선 타깃
- PLTR은 FCF 대비 시총 $352B → 금리 민감도 높은 장기 현금흐름 기업

**관찰 지표**:
- 10Y Treasury >5%
- SaaS 지수(IGV) -15% 조정
- Fed 금리 인상 사이클 재개 공식화

**실현가능성**: **15%** — 2026년 금리 인상 재개보다는 동결/인하 전망 우세. 단 인플레이션 서프라이즈 가능성 상존
**Bear DCF 반영 시**: 주가 충격 -20% × 실현가능성 15% = **Bear에 -3%p 기여** (Bear $60 → $58 방향)

### 2. Foundation 모델 공급자 상방 통합 (Anthropic/OpenAI Enterprise 진출)

**가정**:
- Anthropic 또는 OpenAI가 2026~2027 중 Enterprise Ontology/Workflow 제품 직접 출시
- Claude Enterprise Data 또는 GPT Enterprise Ops가 AIP와 직접 경쟁
- AIP가 LLM 라우팅/오케스트레이션 역할만 남고 의사결정 계층 잠식
- 상업 신규 고객 확보 속도 50% 둔화

**재무/밸류에이션 충격**:
- 상업 매출 성장률 FY27~FY30 50%→25% 감속
- Y10 매출 $55B(Base) → $38B (-31%)
- FCF 마진 50% → 42% (경쟁 압력)
- Exit Multiple 28x → 20x (차별화 약화)
- Base 목표가: $158 → $95 (약 -40%)

**회사가 버티는 근거**:
- 기존 고객 Ontology 락인은 LLM 공급자가 즉시 복제 불가 (수년 데이터 통합 경험)
- 정부·국방 시장은 Anthropic/OpenAI 접근 난이도 매우 높음 (보안 인증)
- PLTR은 LLM 중립(Anthropic/OpenAI/Google 모두 통합) — Foundation 모델 간 경쟁이 강할수록 중립 레이어 가치 상승

**취약 근거**:
- Burry의 핵심 베어 논거 ("Anthropic is eating its lunch")
- Foundation 모델 기업이 뛰어난 UX + 낮은 단가로 신규 고객 포섭 가능
- AIP의 LLM 오케스트레이션 기능은 Anthropic/OpenAI가 직접 제공 가능

**관찰 지표**:
- Anthropic "Claude for Enterprise Operations" 또는 유사 제품 공식 발표
- OpenAI Custom GPT Enterprise Ontology 기능 확장
- Fortune 500에서 AIP와 Anthropic/OpenAI 병행 도입 사례 공시
- 분기 신규 상업 고객 수 YoY 증가율 <20% 하락

**실현가능성**: **30%** — 현재 업계 트렌드 강함. Anthropic 2025 Enterprise 매출 공격적 확장, OpenAI Custom GPT Enterprise 기능 확대 중
**Bear DCF 반영 시**: 주가 충격 -40% × 실현가능성 30% = **Bear에 -12%p 기여** (Bear $60 → $53)

### 3. 미국 정권 교체 + 정부 계약 정리 (2028년 이후)

**가정**:
- 2028년 민주당 대선 승리 → 2029년 초 DOGE·ICE·국경 관련 계약 대폭 정리
- Trump 2기 시절 급성장한 연방 계약의 30~50% 재검토
- NHS FDP break clause 2027 초 실제 발동 → 유럽 정부 확장 위축
- 미 육군 Enterprise Agreement $100억은 10년 프레임워크이나 연간 집행 -20% 조정 가능

**재무/밸류에이션 충격**:
- 미 정부 매출 FY29~FY32 성장률 +35%→+10% 감속
- 영국·유럽 정부 파이프라인 위축
- Y5 정부 매출 -25% (Base 대비)
- Base 목표가: $158 → $128 (약 -19%)

**회사가 버티는 근거**:
- 미 국방부(DoD) 주요 계약은 정치 교체와 무관하게 전략 필수
- 동맹국(한국·일본·이스라엘·호주) 정부 확장으로 미국 정부 의존도 완화 가능
- 정부 매출 비중 54% → 상업 성장 가속으로 자연 하락 중

**취약 근거**:
- ICE·DOGE 관련 계약 집중도 증가 중 — 정권 교체 시 사회적 압력 강함
- 영국 NHS 사례처럼 정부가 자체 개발 또는 경쟁사 교체 옵션 보유
- 민주당 정책 우선순위에서 "Palantir 탈의존" 정치 구호화 가능

**관찰 지표**:
- 2028 미 대선 여론조사 민주당 우세
- NHS FDP break clause 실제 발동
- 독일·프랑스 등 EU 회원국 Palantir 계약 축소 공시
- ICE·DOGE 관련 의회 청문회 개최

**실현가능성**: **20%** — 정권 교체는 구조적 확률. 단 DoD 주요 계약은 지속될 가능성 높아 충격 제한적
**Bear DCF 반영 시**: 주가 충격 -19% × 실현가능성 20% = **Bear에 -3.8%p 기여** (Bear $60 → $58)

### 4. FDE 확장성 붕괴 + 컨설팅 멀티플 재평가

**가정**:
- 상업 고객 수 확장(954 → 2,000+) 시 FDE 인력 확보 병목 가시화
- 매출/직원 $1.02M → $0.75M로 하락
- 시장이 PLTR을 "소프트웨어 + 컨설팅" 하이브리드로 재분류
- 멀티플이 프리미엄 SaaS(PE 45~55x) → 평균 서비스(PE 20~25x)로 압축

**재무/밸류에이션 충격**:
- FCF 마진 51% → 38% (인력 비용 증가)
- Exit Multiple 28x → 15x
- Y10 FCF $27.5B(Base) → $18B, × 15x = $270B (vs Base $770B)
- Base 목표가: $158 → $65 (약 -59%)
- 사실상 Extreme Bear 수준 수렴

**회사가 버티는 근거**:
- AIP Bootcamp + 자동화 도구로 FDE 생산성 개선 중
- 매출/직원 비율 이미 업계 최상위 ($1.02M vs MSFT $950K, CRM $480K)
- SI/컨설팅 파트너 생태계(Accenture, Deloitte 등) 확장으로 인력 아웃소싱 가능

**취약 근거**:
- Burry 베어 논거의 핵심, 증거 축적 시 감성·수급 쇼크 가속
- 고객 Ontology 커스터마이징은 본질적으로 전문 서비스 성격
- 직원 YoY 증가율 통계 공시 부족 — 공시되는 순간 시장 재평가 가능

**관찰 지표**:
- 매출/직원 비율 <$0.9M로 하락
- 직원 YoY 증가율 > 매출 YoY 증가율 × 60%
- Gross Margin <75% 하락 시 (소프트웨어 수준 탈락)
- Professional Services 매출 비중 공시 + 상승

**실현가능성**: **20%** — 이미 매출/직원 $1M+이어서 급락 가능성 낮지만, 고속 확장 시 구조적 병목 가시화 가능
**Bear DCF 반영 시**: 주가 충격 -59% × 실현가능성 20% = **Bear에 -11.8%p 기여** (Bear $60 → $53)

## Bear DCF 시뮬레이션 합산

| # | 시나리오 | 주가 충격 | 실현가능성 | Bear 기여 (%pt) |
|---|---------|---------|---------|----------------|
| 1 | 금리 +200bp | -20% | 15% | -3.0 |
| 2 | Foundation 모델 상방 통합 | -40% | 30% | -12.0 |
| 3 | 정권 교체 + 정부 정리 | -19% | 20% | -3.8 |
| 4 | FDE 붕괴 + 컨설팅 멀티플 | -59% | 20% | -11.8 |
| — | **단순 합산** | — | — | **-30.6%** |

**동조성 해석**:
- 시나리오 #2(경쟁 상방 통합)와 #4(FDE 붕괴)는 **강한 양의 상관** — Foundation 모델 경쟁 압력이 Palantir를 컨설팅화로 밀어붙이는 경로
- 시나리오 #1(금리)과 #3(정권 교체)은 다른 시나리오와 상관 **중립~약함**
- 따라서 **단순 합산은 과대계상**, 동조성 보정 필요 (예: #2+#4는 절반 중복, 합산의 60~70% 수준만 독립 효과)
- 보정 계수 0.7 적용 시: 총 기여 = -30.6% × 0.7 ≈ **-21.4%**

## Bear → Stress 반영 시 비교

Base 파일의 Bear 목표가 $60이 기준:

```
Bear $60 → 단순 합산 -30.6% 적용 → $41.6
Bear $60 → 동조성 보정(×0.7) -21.4% 적용 → $47.2
참고: Extreme Bear (Base 파일) = $22
```

| 구분 | 값 | 해석 |
|------|------|------|
| 원본 Bear (Base 파일) | $60 | 본문 시나리오 |
| Stress 단순합산 적용 | $41.6 | 4개 시나리오 독립 가정, 상관 무시 |
| Stress 동조성 보정 | $47.2 | 경쟁·컨설팅화 동조 50% 중복 제거 |
| Extreme Bear (Base 파일) | $22 | 본문 시나리오 |

**시사점**:
- 스트레스 시나리오를 Bear에 모두 반영하면 $47~$48 수준 — 이미 본문 Bear($60)보다 약 20~23% 더 낮은 지점
- 하지만 Extreme Bear $22까지 가려면 4개 시나리오가 동시에 **상한(High-end) 강도로** 실현되어야 함 → Extreme Bear의 15% 확률 가이드와 일관
- 실제 Revaluation 가중평균에는 반영하지 **않는다**. 이 시뮬레이션은 "Bear 시나리오가 얼마나 깊어질 수 있는가"에 대한 참고
- 결론: 본문 Bear $60은 스트레스 미반영 기준, Bear+Stress 반영 시 $47 전후가 "현실적 다운사이드" — 현재가 $148 대비 -68% 수준의 꼬리 위험이 있음을 인지
