## 투자 thesis

- **AIP Bootcamp 구동 상업 플라이휠** → 무형 자산(FDE 전달 모델) + 전환비용(Ontology) + FY25 미국 상업 +109%, Q4 2025 미국 상업 +137% 성장, 고객수 954명(+34% YoY), AIP Bootcamp 1,300+회 개최·전환율 75%+
- **Ontology 기반 전환비용 해자** → 전환비용 + 무형 자산, 고객 핵심 운영 데이터/워크플로우가 Palantir Ontology에 통합되면 탈출 비용 폭증. Q4 2025 TCV $4.26B(+138% YoY), Remaining Deal Value $11.2B(+105% YoY)로 장기 계약 락인 가시화
- **정부·국방 신뢰 트랙레코드 + 규제 진입장벽** → 규제 진입장벽 + 무형 자산(장기 운용 실적). 미 육군 10년·$100억 Enterprise Agreement, ICE Gotham 연장, 영국 국방 £1.5B 수주. FY25 미 정부 매출 $1.85B(+55%)

### 판정

**PLTR = Narrow Moat ⚠️ (Wide Moat 전환 중)**

핵심 근거 3가지:
① **Ontology 전환비용은 강력하나 검증 부족** — 실제 이탈 사례 부재가 고착성 방증이지만 독립 검증이 어려움. 정부 계약은 장기이나 정치 사이클 노출
② **복수 해자 공존하나 각각 훼손 가능성 존재** — 정부는 정치 리스크, 상업은 Foundation 모델 상방 통합 리스크. 5~7년 투자 기간 내 복수 리스크 현실화 가능
③ **AIP·Ontology 네트워크 효과가 Wide로 전환 가능성** — AIPCon·Warp Speed 생태계가 확장되고 있고, 2~3년 내 이탈 사례 없이 고객 954 → 2,000+ 도달 시 Wide Moat 재평가 필요

**단, 주의 구간**: 다음 선행 지표가 무너지면 Narrow → None으로 재평가
- Q4 2026 이후 미국 상업 성장률이 80% 미만으로 감속
- Net Dollar Retention이 130% 미만으로 하락 (현재 추정 140%+)
- AIP Bootcamp 전환율이 공식적으로 60% 미만 발표
- 대형 고객(Top 20) 이탈 공시 발생

### 5-3. 경쟁 우위 원천

- 경쟁사 격차: Databricks는 개발자·데이터 팀, Snowflake는 데이터 분석가 타겟. Palantir는 의사결정자·운영자 타겟
- 복제 난이도: **높음** — 20년 축적 FDE 플레이북 + 고객 도메인 지식
- 격차 지속 기간 추정: 5~7년 (단, Foundation 모델 애플리케이션화에 따라 변동)

**2. 정부·국방 규제 진입장벽**
- 우위 내용: FedRAMP High, IL6, TS/SCI 등 최상위 인증 + 20년 정부 트랙레코드

- 복제 난이도: **매우 높음** — 보안 인증 + 신뢰 + 기밀 인력 조합 3~5년 구축 필요
- 격차 지속 기간 추정: 7~10년

**3. AIP Bootcamp 기반 고속 전환 엔진**
- 우위 내용: 1~5일 워크숍으로 고객이 자사 데이터로 AIP 활용해 즉시 가시적 성과 생성 → 다년 계약 전환

- 경쟁사 격차: Databricks·Snowflake는 셀프서브·시험 계정 중심, 구조화된 Bootcamp 프로그램 부재
- 복제 난이도: **중간** — 경쟁사가 모방 가능하나 FDE 인력·방법론 축적 필요
- 격차 지속 기간 추정: 2~4년 (모방 가능성 존재)

**4. 자본 배분 우위 (FCF·현금 지배력)**
- 우위 내용: FY25 조정 FCF $2.27B (51% 마진), 순현금 $7.2B. 성장 기업 중 예외적 현금 창출력

- 격차 지속 기간 추정: 3~5년

### 5-4. "왜 이 기업인가" — 투자 차별화 근거

1. **AI "마지막 1마일" 실행력**: Foundation 모델은 상품화되나, 기업 운영 데이터·워크플로우와 연결하는 계층은 고유 IP가 필요. PLTR Ontology + FDE = 경쟁사 대비 실행 속도 격차

## DCF 시나리오 & 가치평가

### 8-0. DCF 방법론 선택

- **적용 방식**: **A. Standard FCF DCF** (10년 explicit + Exit Multiple TV + Forward Multiple 교차검증)
- **선택 근거**: PLTR은 (1) **이미 흑자 전환** (FY25 GAAP 순이익 $1.6B, 조정 FCF $2.27B 51% 마진), (2) **단일 통합 플랫폼** (Foundry/Gotham/AIP/Apollo)에서 Government·Commercial로 판매 채널만 분화 — SOTP 필요 없음, (3) 안정적 FCF 창출 체제 진입. 10년 explicit 투영 + Exit Multiple Terminal Value로 고성장 기업의 장기 정상화를 반영
- **대안 대비 우위**:
  - **E. Forward Multiple 단독은 부적합** — DCF 가이드가 "보조용"으로만 허용. FCF가 이미 안정적으로 생성되고 있어 주(main) 방법론으로는 부적절
  - **B. SOTP 부적합** — 정부/상업은 **판매 채널 분화**이지 이익 구조 이질이 아님. 동일 Ontology·Foundry·AIP 플랫폼 공유, 유사 영업마진 수준, 유사 멀티플 적용. 단일 사업으로 취급하는 것이 회계상·구조상 정확
  - **C. Excess Returns 부적합** — 자본 규제 미적용
  - **D. NAV 부적합** — 자산 기반 사업 아님
- **주요 가정 요약**:
  - WACC **10%** (베타 2.0 × MRP 5.5% + 10Y Treasury 4.31% ≈ 15.3% 상한, 자본 구조 무부채·현금 완충 고려 실무 10% 채택)
  - Terminal Exit Multiple: 시나리오별 12x~32x (FCF 기준)
  - Terminal g 3% (Gordon 교차검증용)
  - 세율 21% (GAAP 기준 정상화, 세금 자산 소진 후)
  - 희석 주식수 2.60B (SBC 디루션 연 1.5% 반영)

### 8-1. DCF 구조 설계 원칙

**이익 변수**:
- 주요 변수: **매출 → 조정 FCF 마진 → 조정 FCF → 성장 감속 + 터미널 멀티플**
- 보조 변수: Non-GAAP EPS (Forward Multiple 교차검증용)

**밸류에이션 공식**:
```
Equity Value = [Σ(FCF_t / (1+WACC)^t for t=1..10)] + [FCF_11 × Exit Multiple / (1+WACC)^10] + Net Cash
목표가 = Equity Value / 희석 주식수(Y10)
```

**기본 가정 테이블**:

| 항목 | Y0 (FY25 실적) | Y1 (FY26 가이던스) | 비고 |
|------|------|------|------|
| 매출 | $4.48B | $7.19B (+60%) | FY26 가이던스 중앙값 |
| 조정 FCF | $2.27B (51% 마진) | $4.03B (56% 마진) | FY26 가이던스 중앙값 |
| 조정 EPS | ~$0.60 | ~$1.34 (컨센서스) | 컨센서스 |
| 희석 주식수 | 2.55B | 2.60B | 연 1.5~2% 디루션 |
| 순현금 | $7.2B | $10~11B | FCF 누적 반영 |

**멀티플 기준 (Exit Multiple at Y10)**:

| 환경 | FCF 배수 | 근거 |
|------|---------|------|
| 정상 (Base) | 28x | 정상화된 성숙기 고품질 SaaS 평균 (피어 22~30x, PLTR 프리미엄 +10%) |

### 8-5. 가치평가 결과

| 지표 | 수치 | 평가 |
