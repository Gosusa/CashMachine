# LRCX — 스트레스 테스트

> 본 파일은 Base DCF 가중평균에 **반영하지 않는** 외생 충격·꼬리 위험 시나리오 집합이다. 목표가 가중평균 계산에 섞지 않고, **참고용 시뮬레이션**으로만 사용.
> Base 분석: [LRCX_base.md](LRCX_base.md)
> 작성일: 2026-04-19

## 스트레스 시나리오 개요

LRCX의 구조적 취약점 상위 5개에 대한 시나리오 점검:

1. **금리 상승 (WACC +200bp)** — 매크로 할인율 쇼크
2. **글로벌 경기 침체 + 반도체 사이클 급락** — 수요 쇼크
3. **미·중 반도체 디커플링 전면화** — 규제·정책 쇼크 (LRCX 기업 특성 반영)
4. **TEL Cryogenic Etch NAND 독점 붕괴 극한 시나리오** — 기술 파괴 쇼크 (LRCX 기업 특성 반영)
5. **HBM/AI CAPEX 과잉투자 → 급격한 조정** — 수요 과열 역전 (LRCX 기업 특성 반영)

> Base 6번의 "리스크 요인"에 이미 포함된 리스크와 **강도 한 단계 상향된 버전**으로 구성. Base가 기저 시나리오라면 Stress는 그 확률 분포의 tail에 해당.

## 1. 금리 상승 쇼크 (WACC +200bp)

**가정**:
- 인플레이션 재점화 또는 Fed hawkish 선회로 10Y Treasury yield 4.3% → 6.3%
- Equity Risk Premium 5.5% 유지 가정 → LRCX WACC 10.5% → 12.5%
- Forward PE 멀티플 압축: 고성장주·고 듀레이션 종목의 DCF 기저 영향 큼

**재무/밸류에이션 충격 추정**:
- Base DCF 목표가 $137 → WACC 12.5% 재계산 시 $108 (-21%)
- Forward PE 압축 효과 (고금리 → 멀티플 재평가): 28x → 22x → 목표가 $131 → $103 (-21%)
- **주가 충격: -25~30%** (현재 $267.60 → $190 내외)

**회사가 버티는 근거**:
- 순현금 $2.7B, 이자비용 부담 미미
- CAPEX 매출의 3~4%로 low — 재투자 부담 제한적
- 배당·자사주 매입 여력 유지

**취약한 근거**:
- 고 멀티플 종목은 rate-sensitive — 할인율 100bp 상승 시 FCF DCF 밸류 10~15% 감소
- AI/HBM 투자의 capex financing 금리 상승 시 고객 수요 감소

**관찰 지표**:
- 10Y Treasury yield 5%+ 돌파 여부
- Fed Funds Rate 가이던스 hawkish 선회
- High-yield credit spread 확대
- NASDAQ/반도체 sector 멀티플 compression

**실현가능성 (%)**: **20%**
- 근거: 2024~25 디스인플레이션 진행 중이나 재점화 가능. 트럼프 2기 재정 확장 기조 + 관세 인플레이션 영향

**Bear DCF 반영 시 기여**: -25% × 20% = **-5.0%p**
- 해석: Base Bear $81에서 추가로 -5.0%p 하락 = -$4 → $77

## 2. 글로벌 경기 침체 + 반도체 사이클 급락

**가정**:
- 2027 글로벌 GDP -1% 경기 침체
- 소비자 전자기기 수요 -20%, 자동차 -15%, 데이터센터 -10%
- 메모리 ASP -35%, Foundry utilization 75% → 60%
- WFE 2027 YoY -30% (2018·2023 수준 상회)
- Lam 매출 -25% (Base 6번의 Bear 시나리오 -15%보다 심각)

**재무/밸류에이션 충격 추정**:
- FY28 매출 가정 $21B × (1-0.25) = $16B (Bear $24B 대비 -33%)
- Op Margin: 34% → 22% (downturn margin compression)
- FY28 EPS: $2.28
- 적용 PE: 16x (stress)
- 목표가(FY28): $36.5 → PV 2yr @ 11% = $29.6
- **주가 충격: -89%** (현재 $267.60 → $30 근처)

**회사가 버티는 근거**:
- 순현금 $2.7B + 유동성 충분
- CSBG $7.2B 중 절반은 사이클 독립 (필수 서비스)
- R&D 지속 가능 (downturn에서도 유지 시 다음 up-cycle 우위)

**취약한 근거**:
- Systems 매출은 사이클에 강하게 연동
- Lam Op Margin 35%는 피크 — 하락 시 큰 leverage 손실
- 고평가 멀티플이 downturn에서 더 급격히 하락 (공포심리)

**관찰 지표**:
- SEMI World Fab Forecast 분기 수정
- 주요 파운드리 CAPEX 가이던스 (TSMC, 삼성, Intel)
- 메모리 3사(삼성/SK/Micron) 가이던스
- ISM 제조업 PMI <45
- 소비자 전자기기·자동차 판매량

**실현가능성 (%)**: **12%**
- 근거: 2027~28 cycle correction은 역사적 패턴(5~7년 주기). 단 심각한 경기 침체까지 동반될 확률은 제한적

**Bear DCF 반영 시 기여**: -85% × 12% = **-10.2%p**
- Base Bear $81에서 추가로 -10.2%p 하락 = -$8.3 → $73

## 3. 미·중 반도체 디커플링 전면화

**가정**:
- 트럼프 2기 또는 후속 행정부가 BIS 규제를 극한 수준으로 확대
- Lam China 전체 매출 금지 (현재 43% 비중)
- 재고 조정 + 기존 서비스 계약 잔여만 수행
- 2027~28 2년간 매출 -$9B 직접 손실
- 대체 시장(미국/일본/한국/대만 CAPEX 증가)로 30% 만회 가정

**재무/밸류에이션 충격 추정**:
- FY28 매출: Base $25.5B → $19B (-25%)
- Op Margin: 33% → 27% (고정비 흡수 악화)
- FY28 Net Income: $4.4B, EPS $3.60
- 적용 PE: 17x (geopolitical 프리미엄)
- 목표가(FY28): $61 → PV 2yr @ 10.5% = $50
- **주가 충격: -81%** (현재 $267.60 → $50)

**회사가 버티는 근거**:
- 지정학 리스크 분산 진행 중 (non-China 매출 확대 노력)
- US CHIPS Act·Samsung/TSMC US 팹 CAPEX 수혜
- HBM은 주로 한국, Foundry는 대만 — China 의존도 낮음

**취약한 근거**:
- China CAPEX가 최근 1~2년 Lam 성장의 큰 축
- 규제 + 중국 로컬 업체 대체 효과로 영구 시장 상실
- 역설적으로 규제 강화 시점에 중국 로컬 업체(AMEC) 성장 가속

**관찰 지표**:
- BIS Entity List 확대 발표
- AMEC/Naura 중국 로컬 장비 매출 성장률
- Lam 분기 China 매출 비중
- 미·중 정상회담 결과 / 반도체 관련 협정

**실현가능성 (%)**: **10%**
- 근거: 전면 금지는 양국 모두에 고통. 점진적 확대는 지속되나 "전면"은 tail risk

**Bear DCF 반영 시 기여**: -80% × 10% = **-8.0%p**
- Base Bear $81에서 추가로 -8.0%p 하락 = -$6.5 → $75

## 4. TEL Cryogenic Etch NAND 독점 붕괴 극한 시나리오

**가정**:
- TEL Cryogenic Etch가 수율·throughput에서 Lam Vantex 대비 확실한 우위 입증
- 2027년까지 NAND 채널홀 etch 점유율 Lam 30% / TEL 70%로 역전
- Lam Cryo 3.0 경쟁 실패 → NAND etch 매출 50% 상실
- 타 segment(DRAM, HBM TSV, Foundry GAA)는 방어 성공

**재무/밸류에이션 충격 추정**:
- Lam Etch 매출 구성: NAND ~30% × 50% 상실 = Etch 매출 15% 감소
- Systems 매출: $11B × 0.85 = $9.4B (-15%)
- Total 매출: $21.5B → $19.5B (-10%)
- Op Margin: 33% → 30% (고정비 흡수 + R&D 효율 악화)
- FY28 Net Income: $5.0B, EPS $4.10
- 적용 PE: 18x (해자 훼손 시 프리미엄 축소)
- 목표가(FY28): $74 → PV 2yr @ 10.5% = $60
- **주가 충격: -78%** (현재 $267.60 → $60)

**회사가 버티는 근거**:
- Etch 전체 시장의 일부만 손실 (NAND 채널홀 한정)
- HBM TSV Syndion 독점 유지
- Foundry GAA etch 대체 성장 엔진
- Lam Cryo 3.0 후속 세대 개발 가능

**취약한 근거**:
- 한 번 뒤집힌 POR은 되돌리기 매우 어려움 (5~7년 사용 후 재검증)
- TEL 선행자 이점 영구화
- Lam의 "NAND etch 독점" 내러티브 붕괴 → 시장 멀티플 재평가
- 경쟁사(AMAT)가 TEL 협공하는 2차 파급

**관찰 지표**:
- TEL 분기 실적에서 NAND etch tool 매출 가이던스
- 삼성 NAND 400L/500L 양산 POR 공식 발표
- SK hynix·Micron NAND 후속 POR 결정
- Lam Cryo 3.0 고객 확보 발표 — 2026 말~2027 초 기한

**실현가능성 (%)**: **18%**
- 근거: TEL 기술 우위 실제 존재 + 삼성 POR 1개 확보 + Lam 1.5년 지각. 단 완전 역전까지 가려면 2~3년 누적 실패 필요

**Bear DCF 반영 시 기여**: -75% × 18% = **-13.5%p**
- Base Bear $81에서 추가로 -13.5%p 하락 = -$11 → $70

## 5. HBM/AI CAPEX 과잉투자 → 급격한 조정

**가정**:
- 하이퍼스케일러 AI CAPEX 2026~27 피크 이후 2028 -30% 급감
- HBM 과잉 공급 우려 (6~8세대 동시 투입) → 메모리 3사 신규 CAPEX 급감
- GAA Foundry 공정 수요 일시 둔화 (경기 침체 동반 시)
- Lam 매출 2028 -35% (Base 대비 -50%)

**재무/밸류에이션 충격 추정**:
- FY28 매출: $25.5B × 0.65 = $16.6B
- Op Margin: 33% → 21% (급격한 압축)
- FY28 Net Income: $3.0B, EPS $2.46
- 적용 PE: 14x (버블 붕괴 심리)
- 목표가(FY28): $34.4 → PV 2yr @ 11% = $28
- **주가 충격: -90%** (현재 $267.60 → $28)

**회사가 버티는 근거**:
- CSBG 안정 매출 (설치 베이스 기반)
- 순현금 + 현금 생성력 지속 → 자사주 매입으로 EPS 방어
- 경쟁사도 동시 하락 — 상대 포지션 유지

**취약한 근거**:
- 현재 Forward PE 49x는 AI CAPEX 지속을 가정 — 반대 시나리오 시 급격한 de-rating
- HBM 공급 과잉은 실제 가능성 (HBM 증설이 예상보다 공격적)
- 2018~19 메모리 버블 붕괴 선례 — 당시 Lam 주가 -45%

**관찰 지표**:
- 하이퍼스케일러(AWS, MS, GOOG, META) CAPEX 가이던스 분기 업데이트
- NVIDIA 데이터센터 매출 가이던스 증감
- 메모리 3사 DRAM/NAND ASP 전환점
- SK hynix HBM 매출 YoY 감속 신호

**실현가능성 (%)**: **15%**
- 근거: AI 버블 가능성 vs 구조적 성장 논쟁 중. 과잉투자 → 조정은 반도체 역사에서 반복된 패턴

**Bear DCF 반영 시 기여**: -85% × 15% = **-12.75%p**
- Base Bear $81에서 추가로 -12.75%p 하락 = -$10.3 → $71

| # | 시나리오 | 주가 충격 | 실현가능성 | Bear 기여 (%p) |

| | **단순 합산** | | | **-49.45%p** |

### 동조성 해석

시나리오 간 상관관계:
- **1(금리) ↔ 2(경기침체)**: 높음 (+0.7) — 고금리 지속 시 경기 둔화 동반
- **2(경기침체) ↔ 5(HBM/AI 조정)**: 매우 높음 (+0.8) — AI CAPEX는 매크로와 연동
- **3(중국 디커플링) ↔ 기타**: 낮음 (+0.2) — 정치적 독립 이벤트
- **4(TEL 경쟁) ↔ 기타**: 낮음 (+0.1) — 미시적·기술적 이벤트

동조성 보정:
- 독립 이벤트(3, 4)는 단순 합산 그대로 (-8.0 + -13.5 = -21.5%p)
- 상관 이벤트(1, 2, 5)는 중복 제거 — 가장 큰 기여(-12.75%p) 사용
- 보정 합계: -21.5 + -12.75 ≈ **-34.25%p**

## Bear → Stress 반영 시 비교

| 항목 | 금액 |
|------|------|
| Base 파일 **Extreme Bear 중간값** | **$37** |
| Base 파일 **Bear 중간값** | **$81** |
| Bear $81 단순 합산 적용 시 | $81 × (1 - 0.4945) = **$41** |
| Bear $81 동조성 보정 적용 시 | $81 × (1 - 0.3425) = **$53** |
| 참조: Extreme Bear $37 | |

### 시사점

- **단순 합산 시 Bear는 Extreme Bear($37)에 근접** — 모든 tail risk가 동시 현실화되면 Extreme Bear 시나리오와 수렴. 이는 Extreme Bear의 확률(15%)이 적절함을 교차 검증.
- **동조성 보정 Bear $53은 기존 Bear $81과 Extreme Bear $37 사이 중간**에 위치. 현실적 tail 압력을 반영한 "Bear+" 수준 추정치로 해석 가능.
- 가장 큰 개별 기여는 **TEL Cryogenic 경쟁(-13.5%p)** — LRCX 고유 구조적 리스크. 이는 Base 분석 6번 리스크 1과 정합성 있으며, 모니터링 우선순위 최상위.
- **주의**: 본 시뮬레이션은 **Base DCF 가중평균에 반영하지 않음**. Base 가중평균 $130은 이미 확률 가중된 값이며, Stress는 "만약 모두 반영했다면 Bear가 얼마나 더 깊어지는가" 점검용이다.
