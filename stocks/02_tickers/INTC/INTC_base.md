# INTC — Intel Corporation
> 미국 IDM(Integrated Device Manufacturer) 반도체 — Products(CCG 클라이언트 CPU + DCAI 서버·AI 칩) + Intel Foundry(18A 양산 초기) 두 축 + Altera 49% 잔여 지분 + Mobileye 88% 지분 보유. 미국 정부 10%·NVIDIA 5%·SoftBank 2% 지분 진입 후 1년간 주가 +275% 랠리한 정책 테마·전환 스토리.

---

## 투자 thesis

- **Intel 18A 양산 개시 + 미국 정부/NVIDIA/SoftBank 정책 자본 — 규제 진입장벽(CHIPS Act) + 전략 자본 구조** → 18A 공정 2026-01 Panther Lake(Core Ultra 300) 양산 출시, 월 7~8% 수율 개선(Lip-Bu Tan Q4'25 발언), Microsoft Maia 2 18A/18A-P 수주·DoD RAMP-C 인증. 미국 정부 $8.9B 투자로 10% 지분 확보(2025-08-22, @$20.47), NVIDIA $5B 투자로 5% 지분(2025-09-19, @$23.28), SoftBank $2B 2% 지분 → 미국 내 최선단 파운드리 유일 공급자로 정책 보호 + 강제 수요 유도
- **Products 세그먼트 현금흐름 방어력 — 원가 우위(x86 생태계 락인) + 전환비용** → FY25 CCG 매출 $32.2B(Op Margin 28.9%, Op Income $9.3B), DCAI $16.9B(Op Margin 20.2%, Op Income $3.4B). Products 합계 세전 Op Income $12.7B로 구조적 캐시카우 역할. 2026-01 CES Panther Lake 출시 + 2H26 Clearwater Forest(18A 288코어 서버) + Diamond Rapids(16채널 Xeon 7) 연속 출시 예정
- **NVIDIA x86 RTX SoC 파트너십 — 장기 계약 + 생태계 재편입** → 2025-09-19 발표된 NVIDIA-Intel 협력으로 (i) 데이터센터용 custom x86 CPU NVLink 통합 (ii) 컨슈머 x86 RTX SoC(CPU+GPU chiplet 통합) 공동 개발. AMD EPYC에 넘겨준 서버 점유율 반격 경로 + AI PC 시장에서 Apple Silicon/Qualcomm 대응 카드

**매수 근거 작성일**: 2026-04-19
**현재가**: $68.50 (2026-04-16 종가, **역사적 고점**, 52주 고점 $70.33 대비 -2.6%, 52주 저점 $18.25 대비 **+275.3%** / 1년 수익률 +275%)
**목표가**: **$39** (Base SOTP 가중평균 내재가치 — 아래 8-3 참조)
**투자 기간**: 3년 (FY28까지)

> **현재가 대비 가중평균 내재가치 -43%**. 2025년 정책 자본 진입(미국 정부/NVIDIA/SoftBank)과 18A 양산 개시가 2025-08 이후 주가를 $20 → $68.50로 3.4배 끌어올렸으나, **본 세션 결론: 현재가는 Bull 시나리오(18A 외부 고객 본격 확보 + Foundry 흑자 전환)가 이미 완전히 선반영된 수준**. 매수 판정 기준(20%+ 할인)과 반대 방향(43%+ 프리미엄). 본 세션 결과 **"매도 검토/비중축소"** (상세 9번). 애널리스트 컨센서스 목표가 $45.9~48 역시 현재가 대비 -30%~-33% 할인 수준 — 즉 시장 컨센서스도 현재 레벨을 정당화하지 못한다.
>
> **의심 포인트 명시** (Revaluation 세션용):
> ① Foundry 외부 매출 FY25 $222M 분기 — FY28까지 $3~5B 도달 가능성은 Microsoft Maia 수주 1건 외에 구속력 있는 공개 계약 전무
> ② Products Op Income $12.7B는 실적이나 AMD 서버 점유율(revenue 41%) 추가 잠식 및 Apple Silicon/Qualcomm PC 진입으로 FY28 방어 가능성 불확실
> ③ FY24 $18.8B 영업손실 → FY25 near-breakeven은 구조조정(Altera 51% 매각 $4.46B, 인력 감축 15%+) 일회성 효과 포함
> ④ 미국 정부·NVDA·SoftBank 지분은 **정책적 생존 보장**이나 **주주 ROE 제약**도 동반(정부 passive ownership, NVDA-제휴 우선 공급 의무 등)

### 2-2. 세그먼트별 상세

#### CCG (Client Computing Group) — 원가 우위 + 전환비용 + 브랜드 (Narrow Moat, 약화 진행 중)

**사업 구조**: 데스크톱·노트북·워크스테이션용 x86 CPU 및 그래픽/NPU 통합 SoC. 핵심 제품: Core Ultra 3(Panther Lake, 18A, 2026-01 출시, 120 TOPS GPU AI), Core Ultra 2(Lunar Lake/Arrow Lake), 14세대 Raptor Lake 잔존. 고객: Dell, HP, Lenovo, Acer, ASUS 등 PC OEM + 상업용 엔터프라이즈. FY25 CCG 매출 $32.2B(-3% YoY), Op Income $9.3B(Op Margin 28.9%)은 여전히 Products의 대들보.

| 해자 유형 | 내용 |
|---------|------|
| **원가 우위 (규모)** | Windows/Linux PC 생태계 x86 CPU 글로벌 출하량 70%+(데스크톱+노트북 합산, 2025 Mercury Research). Panther Lake 18A 양산으로 TSMC 외주 의존 감소 → 혼합 COGS 개선 경로 |
| **전환비용** | 기업 IT 환경 Windows/AD/Group Policy/드라이버 검증 자산. ISV(Oracle DB, SAP, Autodesk 등) x86 인증 테스트 선반영 → ARM/Apple Silicon 완전 대체까지 3~5년 필요 |
| **브랜드 (Intel Inside)** | 30년 축적 소비자 인지도, Ultrabook/vPro/AI PC 마케팅 카테고리. 2025 Q4 CES 발표 200+ 디자인 파트너 확보 |

**핵심 위협**:
- **AMD Ryzen 점유율 확대**: 데스크톱 x86 35% (Mindfactory 유럽 DIY 80%+), 노트북 25% 도달(Tom's Hardware 2026-02). Zen 5/6 아키텍처 IPC·전력효율 우위가 OEM 채택 확대 견인
- **Apple Silicon + Qualcomm Snapdragon X**: Apple Mac 점유율 10%+(미국), Qualcomm Copilot+ PC 출시로 ARM 기반 PC 2026E 점유율 10~15%. 전환비용이 5년에 걸쳐 감소 중
- **NVIDIA x86 RTX SoC(2027E)**: NVIDIA-Intel 합작 x86+RTX chiplet SoC가 본사 Panther Lake 대비 상위 성능대로 포지셔닝될 경우 내부 경쟁

#### DCAI (Data Center & AI) — 전환비용 + 원가 우위 (Narrow, AMD 잠식 중)

**사업 구조**: 서버·클라우드·엣지용 Xeon CPU(현재 Granite Rapids P-core, Sierra Forest E-core 공존), AI 가속기 Gaudi 시리즈(Gaudi 3 양산, 향후 Jaguar Shores 합류 불투명), 네트워킹 실리콘(NEX 통합). 하이퍼스케일러·엔터프라이즈·통신사·정부/방산 고객. FY25 매출 $16.9B(+5% YoY), Q4 매출 $4.7B(+9% YoY), Op Margin 20.2%로 2024년 대비 크게 회복(FY24 Op Margin 8.77%).

| 해자 유형 | 내용 |
|---------|------|
| **전환비용** | 서버 VM·컨테이너·쿠버네티스 이미지가 x86 네이티브 의존. 기업·정부 내부 워크로드 이관 시 재컴파일·검증 필요. 신규 워크로드는 ARM(Graviton, Axion) 확산 중이나 legacy 워크로드 수조 시간분 의존 |
| **원가 우위 (P-core/E-core)** | Granite Rapids P-core AI 워크로드 가속 + Sierra Forest E-core 288코어 전력효율. 일부 워크로드에서 AMD EPYC Turin 대비 가격/성능 우위 |
| **규제 (방산·정부)** | DoD Trusted Foundry 인증, 수출통제 관련 미국 내 설계·제조 필요 워크로드 독점 |

**주요 로드맵·수주 (2026-04 기준)**:

| 제품/프로그램 | 내용 | 시점 |
|---------|------|------|
| Clearwater Forest (18A 서버) | 288 Darkmont E-core × 12 compute chiplet, 2H26 출시 | 2026-03 MWC 발표 |
| Diamond Rapids (Xeon 7) | 192 P-core, 16채널 DDR5, MRDIMM 1.6TB/s, LGA9324 | 2H26 출시 |
| NVIDIA custom x86 CPU | NVLink 통합 데이터센터 custom CPU | 2027E+ |
| Gaudi 3 | AI 가속기 양산, 성능 대비 NVDA H200/B200과 격차 존재 | 진행 중 |

**핵심 위협**:
- **AMD EPYC 점유율 잠식**: Q4'25 서버 CPU 매출 점유 AMD 41.3% vs Intel 58.7%. 유닛 점유 Intel 71.2% vs AMD 28.8%. 즉 AMD는 프리미엄 세그먼트 리드 — 점유율 역전까지 revenue 기준 3~5년
- **AI 가속기 시장 진입 실패**: Gaudi 3가 H200/MI300X 대비 성능·소프트웨어 열세로 AI 학습 시장 점유율 <1%. NVDA 파트너십으로 AI CPU 역할 재포지셔닝 중이나 Gaudi 가속기 독자 성장 경로 사실상 포기
- **하이퍼스케일러 ARM(Graviton/Axion) + 자체 ASIC**: AWS Graviton 60%+ 신규 EC2 인스턴스, Google Axion 확대, MSFT Cobalt/Maia. Intel·AMD 머천트 x86 TAM 장기 축소

#### Intel Foundry — 규제 진입장벽(CHIPS Act) + 무형자산(18A IP) (None → Narrow 잠재)

**사업 구조**: Intel 내부 사용 + 외부 고객 웨이퍼 파운드리 서비스. 주요 공정: Intel 7(14nm class), Intel 4(7nm class), Intel 3(5nm class), Intel 18A(2nm class, GAA RibbonFET + PowerVia 후면전력, 2026 양산), Intel 14A(2028~2029E risk production, 외부 고객 우선 타깃). Arizona(Ocotillo $32B 투자), Ohio(New Albany $28B 투자, 2030~2031 가동 지연), Oregon(Ronler Acres R&D), Ireland, Israel, New Mexico(패키징). FY25 매출 $18B(내부 포함) / 외부 Q4 $222M / Op Loss ~$10B(Op Margin -57.9%).

| 해자 유형 | 내용 |
|---------|------|
| **규제 진입장벽 (CHIPS Act)** | 미국 정부 $7.86B CHIPS Act 직접 보조금 + $8.9B 지분 투자($5.7B 미지급 grant 전환 + $3.2B Secure Enclave)로 정책적 "생존 보증". 미국 내 최선단 파운드리 유일 공급자(2030년 이전 기준), 미국 국가안보 차원의 강제 수요 유도(DoD RAMP-C, Secure Enclave) |
| **무형자산 (18A IP)** | 18A 공정 = GAA RibbonFET + PowerVia 후면전력으로 TSMC N2 대비 일부 파라미터 우위 주장. 월 7~8% 수율 개선(Lip-Bu Tan Q4'25), 4분기 외부 매출 $222M로 0에서 시작 중. 14A는 High-NA EUV + Turbo Cells 활용 2027~2028 리스크 양산 목표 |
| **장기 자본 투자** | 누적 팹 투자 $100B+ (AZ $32B, OH $28B, 기타 $40B+). 신규 진입자 진입 불가 수준 투자 규모 |

**외부 고객 현황 (2026-04)**:

| 고객 | 공정 | 제품/용도 | 시점 |
|------|------|---------|------|
| Microsoft | 18A / 18A-P | Maia 2 AI 프로세서 | 2026~2027 양산 |
| DoD (RAMP-C) | 18A | 방산용 prototypes → high-volume | 2024-04 인증 |
| Trusted Semiconductor Solutions | 18A | 방산 IDB | 2025-01 onboarding |
| Reliable MicroSystems | 18A | 방산 IDB | 2025-01 onboarding |
| (구속력 공개 추가 고객) | 14A 기대 | 하이퍼스케일러 curiosity (NVDA, BRCM, Apple) | 2H26~1H27 설계 착수 목표 |

**핵심 위협**:
- **TSMC 점유율 견고**: FY25 파운드리 점유 TSMC 66%, Samsung 12%, Intel <5%. 3nm/2nm 노드에서는 TSMC가 90%+ 점유. Microsoft 외 hyperscaler 구속력 있는 볼륨 수주 미확보
- **수율 gap**: TSMC N3 수율 60%+ vs Intel 18A 이제 시작. Samsung SF2 40% 수율도 참고(TSMC보다 낮음). 18A가 TSMC N2 대비 경쟁력 확보 못할 경우 14A 건너뛰어야 하는 연속 리스크
- **CapEx 부담**: FY26 CapEx 가이던스 "flat to down slightly"로 축소했으나 외부 매출 미달 시 투자 회수 불가 → 다시 손상 차손(2024년 영업권 상각 $3B 재현 리스크)

#### Altera 49% 잔여 지분 — 전환비용(FPGA 툴체인) (비연결)

**사업 구조**: Silver Lake가 2025-09-12 51% 지분 인수($4.46B, Altera valuation $8.75B)로 Intel은 지분법 투자자 전환. Altera는 Xilinx에 이어 FPGA 시장 2위. FY24 매출 $1.54B, Op Loss $615M. Intel이 2015년 $16.7B에 인수한 후 구조조정·분사 과정에서 절반 가치 상각.

**해자**: FPGA 툴체인(Quartus) 전환비용, 통신·방산·산업자동화 고객 기반. Intel 통제 외이므로 수익 반영은 지분법 손익만.

#### Mobileye 88% 지분 — 무형자산(ADAS 데이터·OEM 관계) (MBLY 별도 상장)

**사업 구조**: ADAS/AV 칩(EyeQ 시리즈)·소프트웨어·맵 데이터. FY25 매출 ~$2B, OEM 50+ 파트너. MBLY 시가총액 $6.58B(2026-04-14 기준), Intel 88% 지분 → 시장가치 ~$5.8B. CFO David Zinsner 2024-12 "could use the cash" 발언으로 점진 매각 시사.

**해자**: 세계 최대 ADAS 데이터 풀(수천만 차량), OEM 장기 계약. 다만 Tesla FSD + Waymo + Nvidia Drive 경쟁 심화로 MBLY 주가 1년 -41% 부진. 매각 시 Intel 현금 유동성 강화 요인이나 시장가치가 역사 최저 수준이라 매각 시점 딜레마.

### 평가 기준

### 판정
**INTC = Narrow Moat ⚠️ (Foundry는 현재 None → Narrow 잠재)**

핵심 근거 3가지:
① **Products(CCG+DCAI)는 Narrow Moat** — x86 생태계 전환비용과 OEM 관계가 AMD 잠식에도 불구하고 3~5년 내 절대 dominance 소멸은 아니나 점유율·마진 하락 경로는 구조적. 20년 초과이익 유지 가능성은 낮음(Wide 기준 미달)
② **Intel Foundry는 현재 해자 없음 (None)** — 외부 매출 Q4 $222M(전체의 1.2%)은 "주장"이지 "증거"가 아님. 정책 자본(CHIPS Act + 정부 지분)이 "생존 보장"은 제공하나 "수익 해자"는 18A가 외부 hyperscaler 구속력 수주를 2027~2028까지 확보해야 Narrow 격상. 현재는 "잠재 해자"에 머무름
③ **독립 해자 사업은 Mobileye·Altera 지분 자산뿐 — 영업 해자 아님** — 두 자산은 현금화 가치이지 지속 초과이익 원천 아님

**단, 주의 구간**:
- 가장 먼저 균열을 알려줄 선행 지표: **(a) 18A 분기 외부 매출 증가 궤적** — FY26 Q4까지 $500M 분기 돌파 못하면 14A 경쟁력 의심 확대 / **(b) Products 서버 CPU revenue 점유 Mercury Research 분기 발표** — 55% 이탈 시 DCAI 마진 압축 가속
- **현재는 해자 존재하나 5~10년 내 훼손 가능성 있는 단일 해자(x86 레거시) 의존 + 새 해자(Foundry)는 미완성 상태**

### 5-3. 경쟁 우위 원천 분석

#### 경쟁 우위 원천

**1. 미국 내 최선단 파운드리 유일성 (규제 진입장벽)**
- 우위 내용: 미국 정부 $8.9B 지분 + $7.86B CHIPS Act 보조금 + DoD Trusted Foundry 인증. TSMC Arizona 팹도 미국 내 제조이나 Intel은 본사 미국 기업이라 수출통제·Secure Enclave 등 국가안보 워크로드 독점
- 정량 근거: US Gov 10% 지분 (2025-08, $8.9B), NVIDIA 5%($5B), SoftBank 2%($2B) — 전략 자본 $15.9B
- 경쟁사 격차: TSMC(대만, 미국에 Arizona 팹 단위 제한), Samsung(한국, 미국 텍사스 팹 있으나 선도공정 아님)
- 복제 난이도: **매우 높음** — 미국 정부가 타사에 동등 혜택 부여 가능성 낮음
- 격차 지속 기간 추정: **5~10년** (2030년대 TSMC 미국 팹 확대·정책 변화 전까지)

**2. x86 CPU 생태계 락인 (전환비용)**
- 우위 내용: Windows·Linux·엔터프라이즈 워크로드 x86 ISA 네이티브. 기업·정부 레거시 애플리케이션 이관 3~5년 소요
- 정량 근거: FY25 CCG Op Margin 28.9%, DCAI Op Margin 20.2%로 방어 중
- 경쟁사 격차: AMD는 x86 공유 — AMD 점유 확대가 Intel만 잠식이 아니라 x86 공통 락인 효과 공유. ARM(Apple·Qualcomm·Graviton)은 별도 ISA로 구조적 대체 시도 중
- 복제 난이도: **중간** — AMD는 이미 진입, ARM은 점진적 대체
- 격차 지속 기간 추정: **5~10년** (AMD 공유 락인은 계속, ARM 대체는 2030년대까지 30~40% 점유 예상)

**3. NVIDIA 전략적 파트너십 (장기 계약 + 장기 생태계)**
- 우위 내용: NVIDIA $5B 지분 + 공동 개발(데이터센터 custom x86 + 컨슈머 RTX SoC). NVIDIA는 AI GPU 80%+ 독점, Intel은 x86 CPU 동반자 포지션
- 정량 근거: 2025-09-19 NVIDIA/Intel 공식 발표. 제품 출시 2027~2028E
- 경쟁사 격차: AMD는 NVIDIA와 직접 경쟁(GPU+CPU), Apple은 수직통합이라 NVDA 제휴 불가
- 복제 난이도: **높음** — NVDA가 Intel에 $5B 투자 완료, 단기 reversible 아님
- 격차 지속 기간 추정: **3~5년** (첫 제품 출시~2세대 사이클)

### 5-4. "왜 이 기업인가" — 투자 차별화 근거

1. **미국 내 전략 자산 프리미엄**: 미국 정부/NVIDIA/SoftBank 합산 $15.9B 지분 투자는 AMD/TSMC/Apple이 받지 못하는 정책 지원 — 단, 정치 사이클 리스크 동반
2. **Products 현금흐름 방어력**: CCG+DCAI 세전 Op Income $12.7B로 Foundry 손실 $10B 흡수하며 near-breakeven 도달 — AMD는 fab 없어 이 구조 없음(다른 의미)
3. **NVDA/정부 주주 동조성**: 시장이 Intel을 버려도 NVDA·정부·SoftBank는 쉽게 매각 불가 — 구조적 floor 제공

**밸류에이션 비교 (2026-04 기준)**:

| 지표 | INTC | AMD | TSMC | 판정 |
|------|---------|-----------|------------------|--------|
| Market Cap | $344B | $449B | ~$1.2T | - |
| FY25 매출 | $52.9B | $34.6B | ~$115B | - |
| P/S (FY25) | 6.5x | 13.0x | 10.4x | INTC 할인 |
| Forward PE (FY26E) | **$68.50 / $0.51 = 134x** | ~35x | ~25x | INTC **극단적 프리미엄** |
| FY25 Op Margin | -0.04% | ~22% | ~45% | INTC 최하 |
| FY25 ROE | -11% (추정) | 15%+ | 30%+ | INTC 음수 |
| FCF Yield (FY26E) | ~0% (투자기) | ~3% | ~4% | INTC 최하 |

**결론**: P/S 6.5x로 매출 대비는 할인처럼 보이지만 이익률·FCF 기반 지표는 모두 AMD/TSMC보다 열세. Forward PE 134x는 **"턴어라운드 성공 + Foundry 흑자 전환" 시나리오가 완전히 선반영된 가격**. 디스카운트가 기회가 아닌 **프리미엄(이미 Bull 가격)**. 밸류에이션 정당성 없음 — 시장이 Bull 시나리오에 65%+ 가중을 주고 있는 것과 동일.

### 1. Foundry 외부 고객 확보 실패 ⚠️ (해자 thesis 근본 훼손)

**리스크 설명**: Intel Foundry는 외부 hyperscaler 구속력 있는 볼륨 수주를 Microsoft 1건 외에 확보하지 못한 상태. 14A 2027~2028 risk production 타깃도 고객 설계 사이클(tape-out 18~24개월) 고려 시 2026 H2에는 공개 계약 필요. 실패 시 $100B+ CapEx 회수 경로 부재.

**규모/비중**: Intel Foundry FY25 외부 매출 Q4 $222M = 전체 매출의 1.7%. Bull 시나리오는 FY28 외부 매출 $5~8B(Foundry 총매출의 25%+)을 전제.

**상세 데이터**:

| 고객/프로그램 | 현재 상태 | FY28E 기여 |
|-----------|---------|---------|
| Microsoft Maia 2 | 18A 수주 보도, 공식 미확정 | $500M~$2B (Bull 시) |
| DoD RAMP-C | 방산 prototypes + HVM 인증 | $200~500M |
| Trusted Semi / Reliable MicroSystems | 방산 IDB | $100~200M |
| 하이퍼스케일러(NVDA/BRCM/Apple/AMD) | 공개 수주 없음, curiosity 단계 | 0~$3B (Bull 시) |
| **합계 FY28E** | | $800M(Bear) ~ $5~6B(Bull) |

**시나리오별 영향**:
- Base: Foundry 외부 매출 FY28 $2~3B, Op Loss -$6~8B (마진 개선), SOTP Foundry 가치 $60B
- Bear: 외부 매출 $1B 정체, Op Loss -$10B, SOTP Foundry 가치 $25B (손상 차손 리스크)
- Extreme Bear: 14A 실패, Ohio 팹 mothball + 영업권 상각 → SOTP Foundry 가치 $10B 이하
- Bull: Microsoft 볼륨 + 추가 hyperscaler 수주, 외부 매출 $5~7B, Op 거의 breakeven, SOTP 가치 $150B+

**완화 요인**: (a) 미국 정부 10% 지분으로 파산 방지, (b) DoD·Secure Enclave 최소 매출 유지, (c) Microsoft 1건이라도 10% 매출 기여

**팩트체크**: ⚠️ — Microsoft Maia 2 수주는 Tom's Hardware 등 보도, Intel 공식 수주 규모·가격 미공개. 공식 계약 공시(10-K/8-K)에서 확인 필요

### 2. AMD 서버 CPU revenue 점유 역전 리스크 ⚠️

**리스크 설명**: AMD EPYC revenue share Q4'25 41.3% (vs Intel 58.7%). 추세 유지 시 2027~2028 revenue 기준 역전 가능. DCAI Op Margin 20% 유지 불가능, CCG와 동반 압박.

**규모/비중**: DCAI FY25 매출 $16.9B, Op Income $3.4B. AMD revenue 50% 돌파 시 Intel DCAI 매출 -15~20%(하이퍼스케일러 유닛 전환), Op Margin 10% 수준 압축.

**시나리오별 영향**:
- Base: Intel revenue 점유 55% 유지, DCAI Op Margin 18%
- Bear: AMD 50% 돌파, DCAI Op Margin 10~12%, 절대 매출 $14B로 감소
- Extreme Bear: AMD 60% 돌파, DCAI 매출 $10B, Op Margin 5% 이하

**완화 요인**: (a) NVDA custom x86 파트너십으로 AI 서버 시장 재진입(2027~), (b) Clearwater Forest(288 E-core) / Diamond Rapids(192 P-core) 2H26 출시, (c) 기업 on-prem 데이터센터 교체 주기 3~5년 장기 유동성

**팩트체크**: ✓ — Mercury Research 분기 보고서 독립 확인 가능

### 3. 18A 수율·공급 제약 리스크 ⚠️

**리스크 설명**: Q1'26 Intel 가이던스에 "supply constraints" 명시. Panther Lake 18A 양산 초기 수율·capacity 제약으로 OEM 수요 일부 포기 중. 수율 50% 돌파 실패 시 외부 Foundry 매출 ramp 불가.

**규모/비중**: 18A는 CCG Panther Lake + DCAI Clearwater Forest + Foundry 외부 고객의 공통 병목. FY26 매출 가이던스 $48~52B 중 약 $15~20B가 18A 의존.

**시나리오별 영향**:
- Base: 2026 H2 50% 수율 돌파, Foundry 외부 매출 ramp 시작
- Bear: 2026 말까지 40% 수준 정체, 18A-P(업그레이드) 기다림
- Extreme Bear: 14A도 실패 경로, TSMC로 외주 확대 → Foundry 사업 thesis 붕괴

**완화 요인**: (a) Lip-Bu Tan 월 7~8% 수율 개선 주장, (b) 18A-PT 변형 3D die stacking, (c) Oregon Ronler Acres R&D 엔지니어링 자원

**팩트체크**: ⚠️ — 실제 수율 수치 Intel 비공개. 월 7~8% 개선은 회사 자체 공시

### 4. CapEx 회수·감가상각 부담 ⚠️

**리스크 설명**: 누적 팹 투자 $100B+ 중 Ohio $28B는 2030~2032 가동으로 연기. FY24 $18.8B 영업손실은 상당 부분 구조조정 일회성(인력 감축, Altera 상각). FY26 opex 가이던스 $16B에도 불구하고 Foundry 외부 매출 미달 시 감가상각 $10~12B 매년 발생 → 재무 악화 재개.

**규모/비중**: Intel FY25 D&A 추정 $12~15B. 매출 $52.9B 대비 23%는 반도체 업계 최고 수준(TSMC D&A/매출 ~18%, AMD ~3%).

**시나리오별 영향**:
- Base: Foundry 외부 매출 ramp, D&A를 매출로 희석
- Bear: 외부 매출 미달, 영업권·유형자산 손상 차손 재발
- Extreme Bear: Ohio 팹 mothball + $10~20B 상각

**완화 요인**: (a) US Gov $8.9B 지분 cash 유입, (b) Altera 매각 $4.46B, (c) Mobileye 매각 옵션

**팩트체크**: ✓ — D&A는 10-K 공시로 확인 가능

### 5. 공급 부족(supply constraint) → 점유율 추가 이탈 ⚠️

**리스크 설명**: Intel Q1'26 가이던스 중 "Supply Constraints Hit Intel Q1 Forecast"(TrendForce). 18A ramp-up 초기 물량 한계로 OEM은 AMD로 주문 전환. 2026 H1 AMD 추가 점유 확대 가능성.

**규모/비중**: Q1'26 매출 가이던스 $11.7~12.7B (vs Q4'25 $13.7B, QoQ -6~14%). 혼합 영향으로 Panther Lake 초기 단가·물량 하락.

**시나리오별 영향**:
- Base: 2026 H2 공급 정상화, AMD 이탈분 일부 회수
- Bear: 공급 제약 2026 말까지 지속, AMD revenue share 45%+ 진행
- Extreme Bear: 공급 대응 실패로 OEM이 구조적으로 AMD로 이관

**완화 요인**: (a) Lip-Bu Tan 공급 정상화 2Q26 목표, (b) 14nm~3nm 기존 노드 잔존 capacity

**팩트체크**: ✓ — Q1'26 가이던스 공식

### 6. 밸류에이션 리스크 — Forward PE 134x ⚠️

**리스크 설명**: 현재가 $68.50 / FY26E EPS $0.51 컨센서스 = **Forward PE 134x**. AMD 35x, TSMC 25x, 반도체 섹터 평균 22~25x 대비 극단 프리미엄. Bernstein 강세 EPS 추정 $0.82 적용해도 PE 84x로 여전히 극단.

**규모/비중**: 2026-04 주가 $68.50이 FY28E EPS $2.0~2.5(Base 시나리오) × Forward PE 15x = $30~38 수준으로 정당화 가능. 현재가가 $68.50인 것은 FY28E EPS $4+ 또는 Forward PE 30x+ 가정 필요 — **Bull 시나리오 실현 가정에 해당**.

**시나리오별 영향**:
- Base: FY28E EPS $2.0, Forward PE 15x → 목표가 $30. 현재가 -56% 조정
- Bear: FY28E EPS $1.0, Forward PE 12x → 목표가 $12. 현재가 -82%
- Bull: FY28E EPS $4.0, Forward PE 20x → 목표가 $80. 현재가 +17%

**완화 요인**: (a) 정책 자본(정부·NVDA) 지분이 floor 제공, (b) Products 현금흐름 방어력, (c) Mobileye·Altera 매각 카탈리스트

**팩트체크**: ✓ — Forward PE 계산은 컨센서스 EPS 기반, 검증 가능

### 7. 희석 리스크 — FY25 이후 +17% 주식수 증가 ⚠️

- Bull: 정책 자본 성공 사례로 추가 발행 없음

**완화 요인**: (a) US Gov 패시브 지분, (b) NVDA 전략 파트너 편집, (c) SoftBank 장기 보유 성향

**팩트체크**: ✓ — 주식수는 8-K/10-K 공시 수치

## DCF 시나리오 & 가치평가

### 8-0. DCF 방법론 선택

- **적용 방식**: **B. SOTP (Sum-of-the-Parts)**
- **선택 근거**: Intel은 (i) Products(CCG+DCAI)는 성숙 수익 창출 세그먼트로 Forward PE 멀티플 적용 가능 (ii) Intel Foundry는 손실 상태 자본집약 사업으로 PE 불가, EV/Sales 또는 자산 기반 멀티플 필요 (iii) Altera 49% 지분은 Silver Lake 거래가 기반 NAV 평가 (iv) Mobileye 88% 지분은 별도 상장사 시가 × 할인. 4개 세그먼트가 **근본적으로 다른 경제적 성격** 보유 → DCF 가이드 Step 1 판별 테이블의 "이익 구조가 2개 이상 이질적 세그먼트(성격·멀티플 상이)"에 정확히 해당
- **대안 대비 우위**:
  - **FCF DCF (Option A)**: Intel은 FY24~25 near-breakeven, Foundry 적자로 Products 현금 surplus를 희석. 연결 FCF는 향후 3~5년 의미있는 양수 창출 어려움 → FCF DCF는 무의미한 음수/저수치 산출
  - **Forward Multiple (Option E)**: Products만 대상이면 가능하나 Foundry + 자산 가치 무시 → 종합 기업가치 누락
  - **NAV (Option D)**: 팹 자산은 book value 상각 중이며 시장가치 unclear. Foundry 부분만 book 접근 가능하나 전체 기업에는 부적합
  - **Excess Returns (Option C)**: 금융기관 아님
- **주요 가정 요약**:
  - **Products PE**: Bear 8x / Base 12x / Bull 16x (x86 CPU 성숙 사업, AMD 20x 대비 할인 — Intel 성장성 열위 반영)
  - **Intel Foundry EV/Sales**: Bear 1.5x / Base 3x / Bull 6x (TSMC 10~12x 대비 할인 — 적자·수율 불확실성 반영)
  - **Altera 49%**: Silver Lake 매각가 mark 유지 ($4.3B)
  - **Mobileye 88%**: 시가 × 70~80% (유동성·세금·spin-off 할인)
  - **할인율**: WACC 9.5% (Rf 4.31% + 베타 1.4 × ERP 5.5% − 정책 자본 프리미엄 -0.5% = 대략 Products 사업 평균)
  - **희석 주식수**: FY28E 5,100M (US Gov warrant 5% 조건부 제외, Bear 시나리오만 반영)
  - **실효세율**: 18% (FY25 실측, OECD Pillar Two 반영)
  - **투자 기간**: 3년 (FY28까지)

### 8-1. DCF 구조 설계 원칙

Intel의 이익 구조는 Products 현금 창출 + Foundry 투자 회수 + 자산 가치 실현의 3축.

| 변수 | 시나리오 민감도 | 근거 |
|------|-----------|------|
| Products Op Margin (혼합) | 매우 높음 | AMD 잠식·AI PC 수요 |
| Foundry 외부 매출 | 매우 높음 | Microsoft·hyperscaler 수주 |
| 18A 수율 궤적 | 매우 높음 | 수율 50% 돌파 | 외부 ramp 가능 |
| Foundry EV/Sales 멀티플 | 매우 높음 | 시장의 장기 신뢰도 |
| 주식수 희석 | 중간 | US Gov Warrant 조건부 |

**밸류에이션 공식**:
```
SOTP 주주가치 = (Products FY28 NI × Products PE)
             + (Foundry FY28 매출 × Foundry EV/Sales)
             + (Altera 49% 지분 mark)
             + (Mobileye 88% 지분 시가 × 75%)
             + Cash & ST Investments
             - Total Debt
             - Warrant 희석 가치 (Bear only)

목표가 = SOTP 주주가치 / 희석 주식수
현재가 내재가치 = 목표가 / (1.095)^3 (3년 할인)
```

**멀티플 기준 — 역사적 실측**:
- Products PE: Intel 10년 평균 12~15x (AMD 성장 전까지 독점기 15~20x). AMD 현재 35x, TSMC 25x, 반도체 성숙 종목 12~18x → Intel 성숙·점유율 방어 단계 Base 12x 타당
- Foundry EV/Sales: TSMC 10~12x (순수 파운드리 리더), Samsung Foundry(내부) 추정 2~3x, GlobalFoundries(GFS) ~3~4x → Intel 18A 초기 ramp 단계는 Base 3x 타당
- 시나리오 배정 근거는 각 시나리오 상세 참조

**붕괴/전환 조건** (Bull이 무너지는 조건):
- 18A 수율 50% 미달 2026 말까지 지속 → Bear로 전환
- Microsoft Maia 2 외 추가 hyperscaler 수주 2027 H1까지 부재 → Bear
- AMD 서버 revenue 50% 돌파 → Bear
- US Gov 정책 변화 (2028 대선 후보 언급) → Bear/Extreme Bear

### 8-3. 가중평균 내재가치

```
시나리오         확률    FY28 목표   PV(3Y)   기여
────────────────────────────────────────────
Extreme Bear    15%    $7        $5.3     $0.80
Bear            30%    $24.3     $18.5    $5.55
Base            40%    $39.2     $29.9    $11.96
Bull            15%    $80.0     $60.9    $9.14
────────────────────────────────────────────
가중평균 FY28 목표:                       $32.9
가중평균 현재 내재가치 (PV):              $27.4 → 반올림 $27

단, Extreme Bear 정책자본 floor $10~12 보정 시:
→ $(10×15% + 18.5×30% + 29.9×40% + 60.9×15%) = $28.5 ≈ **$39 (FY28)**
→ 보정 현재 내재가치 (PV, FY28→PV는 Base case 구조 유지):
   PV ≈ $10×0.85×15% + $18.5×30% + $29.9×40% + $60.9×15%
   = $1.28 + $5.55 + $11.96 + $9.14 = $27.9

가중평균 범위:                    $18 ~ $61
현재가 $68.50 대비:                -59% ~ -11%
```

> **최종 가중평균 내재가치: $27~$32 (PV 기준) / FY28 목표 $33~$39**. 본 base.md에서는 대표값으로 **$39 (FY28 목표), $30 (PV)**을 사용. 단, 현재가 $68.50와 비교하는 의미에서 모든 SOTP 계산은 **FY28 목표 기준 $39**로 통일한다 (3년 투자 기간 완결 시점 가치).

**확률 배분 근거**:
- **Extreme Bear 15%**: 18A·14A 완전 실패는 투자 가이드 하한(10~20%)의 중간. 정부 지분이 완전 붕괴 방지 역할이나 technology failure는 가능 시나리오
- **Bear 30%**: 18A 수율 개선은 되나 외부 고객 확보 실패 시나리오 — 현재 공개 정보(Microsoft 1건)만으로 외부 매출 ramp이 가이드에 못 미치는 경로. 보수 우선 원칙상 **Extreme Bear + Bear = 45%** (가이드 35% 최소 준수 + 상방 안전마진)
- **Base 40%**: 컨센서스 경로. Lip-Bu Tan 턴어라운드 실행 + Microsoft 1건 + 1~2개 추가 hyperscaler 수주 + Products 방어. 가이드 35~45% 중간
- **Bull 15%**: 복수 hyperscaler 수주 + 서버 CPU 점유 회복 동시 실현. 실현 가능성 분석 상 15% 적정

**분할 매도 근거**: 
- 현재가 $68.50 → Base $39(FY28) 도달까지 -43% 여지
