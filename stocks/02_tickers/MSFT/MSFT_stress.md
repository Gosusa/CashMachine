## 시나리오 1: AI 인프라 ROIC 붕괴 — 하이퍼스케일러 자본경쟁 역풍

### 가정
- FY26 $120B+ CapEx가 예상 ROIC 창출 실패 (Azure AI Services 성장 20% 이하)
- FY27~28 CapEx 유지해야 경쟁력 유지되나 감가상각 부담 누적 (연 $50B+ D&A)
- 동시에 Inference 단가 하락(경쟁 심화 + 오픈소스 모델 상용화) → AI 매출 단가 -30%
- AI Capex 정당화 불가능 시점에 시장이 "AI 겨울" 멀티플 15x 적용

### 재무/밸류에이션 충격 추정
- FY28 OI 마진: 48% → 40% (-8%pt)
- FY28 Net Income: ~$170B (Base 대비 -25%)
- FY28 EPS: ~$24 × Exit PE 15x = $360 undiscounted
- 3년 discount (WACC 9%): ~$280
- **주가 충격: Base $500 → $280 (-44%)**

### 회사가 버티는 근거
- Commercial RPO $625B 유효계약, 대부분 Azure 외 M365·Security 등 다각화
- M365 구독 매출은 AI 독립 (연 $150B+ 유지)
- CapEx 30~40% 감축 여력 존재 (데이터센터 건설 연기 가능)
- 자사주 매입 연 $30B로 EPS 방어

### 취약한 근거
- 이미 발주된 GPU·서버 고정비는 매몰
- 하이퍼스케일러 간 가격 경쟁 시작되면 마진 회복 느림
- 감가상각 주기 4~6년 동안 회계적 부담 누적
- AI 관련 신규 기능 개발비 동시 부담

### 관찰 지표 (선행 시그널)
- Microsoft Cloud 마진 45% → 40% 하회
- Azure AI Services 성장률 Multi-billion 언급 없어지거나 하락 시사
- 3대 하이퍼스케일러 합산 CapEx의 매출 대비 % 상승 (규모 경쟁 격화)
- Inference 가격 (per 1M tokens) 월별 추이 — 30% 이상 하락 시 위험 신호

### 실현가능성: 15%
- AI 수요가 미성숙하고 CapEx 정당화에 실패할 확률은 기본 존재
- 단, Commercial RPO $625B의 가시성과 M365 base가 최악 시나리오 방어력 제공
- 역사적 유사 사례: 2000년 닷컴 CapEx 과잉 (MSFT 당시도 생존, 10년 횡보)

### Bear DCF 반영 시 기여
- 주가/DCF 충격: Base $500 → $280 = -44%
- 동일 충격을 Bear $270 에 적용: $270 × (1 − 0.44) = $151 (추가 -$119)
- **기여: -$119 × 15% = -$17.9 (Bear DCF에 $17.9 추가 하락 기여)**

## 시나리오 2: OpenAI 완전 이탈 — Frontier 영구 이관 + GPT-6 AWS 독점

### 가정
- 2026년 내 MSFT vs OpenAI+Amazon 소송 또는 협상에서 MSFT 패소·양보
- Frontier 뿐 아니라 차세대 GPT-6, Agents SDK 등 핵심 제품이 AWS/GCP에 개방
- MSFT의 OpenAI 독점성 소멸, Azure는 "one of many" 파트너로 전락
- MSFT OpenAI 지분 49%는 가치 유지되나 전략적 레버리지 상실

### 재무/밸류에이션 충격 추정
- Azure AI Services 성장률: Bull 가정 40%+ → 20% 수준으로 하락
- FY28 Azure 매출 영향: Base 대비 -8%~-12% (Azure $200B 기준 -$20B)
- FY28 Revenue: $400B → $380B (-5%)
- 멀티플 재평가: AI 리더십 프리미엄 소멸, Base PE 26x → 22x
- **주가 충격: Base $500 → $400 (-20%)**

### 회사가 버티는 근거
- OpenAI 지분 49% 보유 가치 ($360B 이론값)는 Balance Sheet에 남음
- MSFT 자체 AI 모델(MAI, Phi, Nadella+Suleyman 체제) 개발 중
- Azure 자체는 OpenAI 외 Anthropic, Mistral 등 멀티모델 호스팅 가능
- Copilot은 Azure OpenAI Service 기반이나 모델 교체 기술적 가능

### 취약한 근거
- 2023~2025년 Azure 차별화의 핵심이 OpenAI 독점이었음
- Copilot 제품군은 GPT-4/4o/5 기능에 tightly coupled
- 자체 MAI 모델이 GPT급 성능 달성할지 불확실 (업계 평가 아직 2~3 tier 하위)

### 관찰 지표
- OpenAI 소송 진행 상황 (2026.2 발표 → 2026.4 현재 미제소, 협상 중)
- OpenAI 공식 발표 중 Azure exclusive 표현 변화
- MSFT MAI 모델 출시 시점 및 벤치마크 성과
- Copilot 가격 정책 변화 (모델 교체 시 인상·인하)

### 실현가능성: 30%
- Frontier 계약 자체는 이미 체결 → 제한적 이관은 사실상 확정
- 전면 이탈 가능성은 MSFT의 법적/재무 레버리지로 30% 수준
- 선행 사례: 전략적 파트너십 약화 사례 많음 (Apple-Google Search, Microsoft-Yahoo)

### Bear DCF 반영 시 기여
- 주가/DCF 충격: Base $500 → $400 = -20%
- 동일 충격을 Bear $270 에 적용: $270 × (1 − 0.20) = $216 (추가 -$54)
- **기여: -$54 × 30% = -$16.2 (Bear DCF에 $16.2 추가 하락 기여)**

## 시나리오 3: 전력·냉각 공급 bottleneck 장기화 — Azure 성장 배송 지연

### 가정
- 2026 2H 해소 전망이었던 Azure 공급 제약이 2027~2028까지 연장
- 핵심 원인: 전력망(US Mid-Atlantic, Virginia, Texas 지역 PPA 지연), 냉각수 규제, 변압기 부품 조달 12~18개월 delay
- 수요(RPO $625B)는 유효하나 매출 인식이 이연됨
- 경쟁사(AWS, GCP)도 동일 제약이나 MSFT 상대적 손실 폭 큼

### 재무/밸류에이션 충격 추정
- Azure 성장률: Base 30~35% → 25% 수준 (공급 제약으로 수요 실현 불가)
- FY27 Revenue: Base $355B → $340B (-4%)
- FY28 Revenue: Base $400B → $375B (-6%)
- Backlog는 계속 증가하나 수익 인식 지연 → 밸류 할인
- **주가 충격: Base $500 → $420 (-16%)**

### 회사가 버티는 근거
- RPO는 계약 유효 (이연은 있지만 손실은 아님)
- 공급 해소 시 높은 성장 회복 가능
- 경쟁사도 같은 제약 → 상대적 시장점유율은 유지

### 취약한 근거
- 경쟁사가 먼저 해소 시 고객 이탈 위험
- 연간 이연이 2년 이상 지속되면 Copilot·AI 상업화 지연 → 타 투자 thesis도 영향
- 시장은 "성장률 감속"을 valuation 할인으로 반영하며 RPO 인정 안 함

### 관찰 지표
- Azure 신규 리전 개소 속도 (분기별 몇 개)
- 전력 확보 공시 (PPA 발표 빈도)
- 경쟁사 vs MSFT 공급 제약 해소 타이밍 비교
- FY27 guidance에서 supply constraint 관련 언급 빈도

### 실현가능성: 25%
- 공급 문제는 이미 경영진이 공식 인정
- 18개월 지연은 산업 전반 공급 병목 상황 감안 합리적
- 단, MSFT가 공급 확보에 가장 적극적 (전력 PPA 선제 계약)

### Bear DCF 반영 시 기여

### 동조성 해석

시나리오 간 상관관계 분석:
- **시나리오 1(AI ROIC) ↔ 시나리오 2(OpenAI 이탈)**: 강한 양의 상관 — AI 수요 전반 둔화 or AI 차별화 소멸은 연결됨. 동시 현실화 시 이중 반영 주의
- **시나리오 1 ↔ 시나리오 5(금리+침체)**: 중간 상관 — 경기 둔화가 AI 투자 정당화 실패 촉진

- **시나리오 4(규제)** : 대부분 다른 시나리오와 독립적으로 작동

동조성 보정 (주요 연관 시나리오 조합 고려):
- 시나리오 1+2 동시 현실화 확률 ≈ max(15%, 30%) × 상관계수 ≈ 10% → 조합 영향 -$35
- 단순합산 $72.9에서 중복분 ~$10~15 제거
- **동조성 보정 후 Bear 기여: 약 -$55~$60**

## Bear → Stress 반영 시 비교

```
Base 파일의 실제 Bear 중간값 (확률 25%) : $270
Base 파일의 Extreme Bear 중간값 (10%)   : $175
────────────────────────────────────────────
Stress 단순합산 적용 시 Bear: $270 - $72.9 = $197
Stress 동조성 보정 시 Bear:  $270 - $57   = $213
────────────────────────────────────────────
비교: 
  원본 Bear $270
  → 단순합산 적용 시 $197 (Extreme Bear $175와 유사)
  → 동조성 보정 시 $213 (Bear 하단 근처)
  (Extreme Bear $175 대비 동조성 보정 값이 +$38 높음)
```

**시사점**:
- Bear에 Stress 모두 반영한다면 Extreme Bear 값($175)에 근접하는 수치($197~$213)
- 이는 Base 분석의 Extreme Bear가 이미 이런 tail 리스크를 종합적으로 반영하고 있음을 시사
- Stress 테스트의 가장 큰 기여 시나리오: 시나리오 1(AI ROIC 붕괴), 5(금리+침체). MSFT 투자 thesis 가장 취약 지점
- **주의**: 이 시뮬레이션은 실제 Revaluation 가중평균에는 반영하지 않는다. "만약 모든 tail risk를 동시에 가중했다면 Bear가 얼마나 더 깊어지는가"를 점검하는 참고 시뮬레이션이다.
