# Base 리서치 가이드 — 측정 템플릿

이 가이드를 따르면 `02_tickers/{TICKER}/{TICKER}_base.md` 파일이 생성된다.

> **이 파일 작성 시 반드시 [01_philosophy.md](01_philosophy.md)를 상시 상기한다.**
> philosophy는 "왜 측정하는가"를 고정하는 가치관·렌즈 레이어이고,
> 이 파일은 "무엇을 어떻게 측정하는가"의 측정 템플릿이다.
> 측정 **깊이와 우선순위는 philosophy 렌즈에 따라 조절**한다
> (같은 종목이라도 핵심 렌즈가 NVDA는 재투자 ROIC, KO는 영속성·가격인상이다).
>
> **해석·판정·최종 스토리는 이 파일이 아니라 `{TICKER}_verdict.md`에 쓴다.**
> base는 원재료(factual + 관측된 해석), verdict는 가치관 언어로 정제된 결론.

---

## Base 파일의 역할

- **가치관 물음 답변서**. base 각 섹션은 philosophy 투자 가치관의 **구체 물음에 답을 생성하는 조사**다.
  물음 없이 데이터만 채우면 판단에 연결되지 않는다. 조사 중 매 순간
  "이 섹션에서 나는 가치관 어느 물음에 답하고 있는가"를 유지한다.
  답이 안 나오는 물음은 그 사유를 기록한다 (예: "재투자 ROIC 측정 불가 — 세그먼트 공시 없음").
- **판단 재료의 저장소**. Claude가 이 종목을 생각할 때 끌어다 쓸 모든 증거·맥락·해석이 들어간다.
- **해석·시사점·인과 체인도 같이 기록**한다 — "이 수치가 의미하는 바", "이 해자 훼손이 현실화되면 어떤 연쇄가 벌어지는가" 같은 생각을 빼놓지 않는다. 나중에 다시 읽을 때 맥락이 증발하지 않도록 한다.
- **DCF는 3시나리오(Bear / Base / Bull) 범위로 산출** — 가중평균으로 단일 목표가를 만들지 않는다. 범위 그대로 제시한다.

---

## 작성 원칙

1. **모든 주장에는 수치 근거가 있어야 한다** — "강한 해자"가 아니라 "해지율 3%, 평균 계약 5년, 출처: 10-K p.32"
2. **구조화된 증거 + 판단 근거 병기** — 수치·테이블로 factual 기반을 먼저 잡고, 그 위에서 "이 수치가 어떤 신호인가"를 기록. 서술형 narrative만 나열하지 않는다.
3. **보수적 가정 우선** — 낙관적 해석은 Bull 시나리오에 한정. Base·Bear 전제는 관찰 가능한 궤적에 기반한다.
4. **팩트체크는 분석과 같은 섹션에** — 주장과 검증이 분리되면 연결을 놓친다.
5. **출처 표기** — 수치에는 출처(공시, 보고서명, 데이터 제공자)를 병기한다.
6. **최신 데이터를 직접 조회한다** — 모델 지식 컷오프에 의존하지 않는다. 매 분석 시작 시 아래 항목을 **WebSearch / WebFetch로 직접 조회**해서 사용한다:
   - **현재 주가 / 52주 고저 / 1년 수익률** (시세)
   - **직전 분기 + FY 실적 발표 자료** (매출·이익·가이던스·컨퍼런스 콜 코멘트)
   - **최신 10-K / 10-Q 공시** (세그먼트, 부채 디테일, 희석주식수, 자본배분 이력)
   - **최근 1~3개월 주요 뉴스** (애널리스트 목표가 변경, 규제 이슈, 키맨 변동, M&A 등)
   - **애널리스트 컨센서스 목표가 / 평균 PE / EPS 추정치**
   - 컷오프 이후 갭이 있을 경우 "확인 필요"로 비워두지 말고 **반드시 조회**한다

```
> 한 줄 요약 (업종, 핵심 세그먼트)
---
## 측정 전 컨텍스트 — 카테고리 분류
---
## 1. 사업의 본질 — "어떤 사업을 소유하는가?"
## 2. 경제적 해자 — "이익이 복리로 오를 수 있는가?"
## 3. 복리 엔진 — "번 돈을 재투자할 곳이 있는가?"
## 4. 자본배분 — "경영진이 번 돈을 제대로 쓰는가?"
## 5. 재무건전성 — "나쁜 시기를 버틸 수 있는가?"
## 6. 리스크 / Inversion — "어떻게 돈을 잃을 수 있는가?"
     (회사 특유 실패 경로 + 스트레스 시나리오 + Inversion 조건 통합)
## 7. 밸류에이션 & DCF — "숫자상 얼마인가?"
## 분기별 점검 기록
```

> **스트레스 테스트는 Section 6에 통합**되어 있다. 별도 `{TICKER}_stress.md` 파일을 만들지 않는다.

**각 섹션은 반드시 다음 블록으로 시작:**

```markdown
## {N}. {섹션명} — "{핵심 질문}"

**왜 장투에 중요한가**: {이 질문이 복리 성장에 왜 핵심인지}
```

## 섹션별 작성 규칙

### 측정 전 컨텍스트 — 카테고리 분류

philosophy [분석 대상 분류] 렌즈. 사업 성격·성장 단계 이해를 위한 **서술적 분류**.
판정(YES/조건부/NO)은 §2 증거에서 직접 도출되며, 카테고리는 게이트가 아니다.

```markdown
**카테고리**: Stalwart / Fast Grower / Cyclical / Slow Grower / Turnaround / Asset Play
**근거**: {성장률·사업 성격·시장 지위 등 수치·정성 근거}
**현재 상태 ↔ 전환 방향**: {예: Fast Grower → Stalwart / Cyclical → Stalwart 일부 성격 부상}
**카테고리별 추가 점검 포인트**: {philosophy 해당 카테고리 "추가 강조점"에서 이번 분석에 주목할 항목 1~3개}
```

> philosophy [분석 대상 분류] 참조. 모든 카테고리는 동일 프레임워크(§1~7)로 측정하며,
> 카테고리별 "추가 강조점"을 분석 깊이·우선순위에 반영한다.

### 1. 사업의 본질 — "어떤 사업을 소유하는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [이익] 이익 5경로 중 현재 어떤 경로가 가동 중인가? (비용절감·가격인상·신규시장 진출·기존시장 매출 확대·적자 사업 재편)
- [해자] 수요 규모와 지속성은 어떤가? 매일·정기적으로 구매되는 구조인가?

**왜 장투에 중요한가**: 복리 성장은 구조적으로 이익이 나는 사업 위에서만 가능하다. 경영진이 좋아도 사업 구조 자체가 저수익이면 한계가 분명하다. 무엇을 소유하는지 먼저 분해해야 이후 해자·성장·리스크 판단이 성립한다.

#### 1-1. 무엇을 파는가

- 제품/서비스 목록
- 고객 유형 (B2B / B2C, 기업 규모, 지역, 산업)
- 수익 모델 (일회성 / 반복 / 구독 / 라이선스 / 수수료 / 성과 보수)
- 판매 채널 (직판 / 채널 파트너 / 플랫폼)

#### 1-2. 매출·이익 믹스

| 세그먼트 | 매출 | 매출 비중 | 영업이익 | 영업이익 비중 | 성장률 (YoY) |
|---------|-----|---------|---------|------------|-----------|

- **지역별 믹스** (매출 5%+ 지역만)
- **반복 매출 비중** (구독/계약 vs 일회성)

#### 1-3. 단위 경제학

- 평균 판가, COGS 구조, 단위당 마진
- CAC vs LTV (B2B / 구독 사업)
- 해지율 (churn) / 재계약률 (retention) / NRR

#### 1-4. 공급망·고객 구조

- 주요 공급자 의존도 (상위 3개 비중)
- 주요 고객 집중도 (Top 10 비중, 10%+ 고객 존재 여부)
- 힘의 균형 (가격결정력이 어느 쪽에 있는가 — 정량 근거 포함)

### 2. 경제적 해자 — "이익이 복리로 오를 수 있는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [해자] 경쟁자가 동일 모델을 복제하는 데 걸리는 시간·자본·라이선스 장벽은?
- [해자] 고객을 잃지 않고 매년 가격을 올릴 수 있는가? (가격인상 이력 정량)
- [해자] 원가 우위 — 더 적은 비용으로 같은 결과를 내는 구조인가?
- [장기투자] 평생 보유 가능한가? (2-6 영속성 6축에서 판정)

**왜 장투에 중요한가**: 복리 성장은 초과이익(ROIC > WACC)이 수년간 유지될 때만 가능하다. 해자는 경쟁사 진입을 막아 초과이익을 보호하는 구조. 해자가 없는 초과이익은 경쟁에 의해 곧 소멸한다.

#### 2-1. 해자 유형별 식별

해당하는 해자만 작성. 각 해자마다 **정량 증거** 필수.

- **무형 자산**: 브랜드, 특허, 라이선스, 트랙레코드
- **전환비용**: 계약 기간, 대체 비용, 해지율
- **네트워크 효과**: 양면 시장, 사용자 증가 → 가치 증가 메커니즘
- **원가 우위**: 규모, 입지, 독점 자원
- **효율적 규모**: TAM 한정, 선점 효과
- **규제 진입장벽**: 인허가, 규정 compliance
- **대체 불가 실물 자산**: 노선·입지·설비

#### 2-2. 해자 후보 검증 — "이것이 해자인가 아닌가"

[philosophy](01_philosophy.md) §해자 선언("경쟁자가 복제하기 어려운 구조만 본다" · "가격을 올려도 고객을 잃지 않는 실증") 직접 구현.
**회사가 주장한다고 해자가 아니다 — 외부 데이터로 실증되어야 해자다.**

2-1에서 식별한 해자 유형 각각을 이 테이블로 검증한다. 검증 결과가 해자 인정 여부를 결정한다.

| 해자 유형 | 주장 | 정량 증거 (수치 + 출처) | 판정 |
|---------|-----|---------------------|------|
| | | | 해자 성립 / 미검증 / 해자 아님 |

**판정 정의**:
- **해자 성립** — 회사 외부 출처(경쟁사 공시·3자 리서치·규제 공시·산업 통계 등)로 수치 교차 검증 완료. **이 판정만 해자로 인정된다**
- **미검증 — 해자 후보** — 회사 자체 공시·IR 자료만 존재. 독립 검증이 불가능하거나 아직 이뤄지지 않음. **해자로 인정하지 않는다** — verdict에서 해자로 인용 불가
- **해자 아님** — 수치가 주장과 불일치하거나 훼손 증거가 관찰됨 (주장 자체가 반증됨)

**작성 규칙**:
- 2-1에서 식별한 해자 유형은 **모두 이 테이블에 올라와야 한다** (검증 없이 2-1 나열만으로 해자 인정 금지)
- "해자 성립"만 verdict §0 해자 높이·§2-1 지지 증거·§1-2 원인 체인의 "실증 증거"에 해자로 인용 가능
- "미검증"은 verdict §2-1 지지 증거로 쓸 수 없다. 필요 시 verdict §2-2 반대 증거의 "검증 부재" 또는 "추가 리서치 필요" 항목으로 기록
- "미검증" 상태로 남은 항목은 **어떤 외부 데이터가 있으면 독립확인으로 전환 가능한지** 기록해둔다 (다음 분기 점검 포인트)

#### 2-6. 영속성 판단 — "평생 보유 가능한가?" (15년+ 지속성 테스트)

장기투자의 이상적 결과는 **한 번 사서 평생 보유하는 것**. 그러려면 이 사업·해자·이익 구조가 15~25년 시간 축에서도 살아남을 구조인지 별도 판정한다. 2-1~2-5의 현재 해자 분석과 구분되는, **시대·세대 단위의 지속성 판단**.

> **판정 대상 범위**: 2-2에서 **"해자 성립" 받은 해자만** 영속성 판정 대상이다. "미검증" 또는 "해자 아님"인 항목은 영속성 판정 이전에 이미 해자로 인정되지 않았으므로 15년+ 지속성을 논할 필요가 없다. 이 종목에 "해자 성립" 항목이 하나도 없으면 2-6 판정은 자동으로 **NO**(영속성 논의 불가)로 도출되며, 그 자체가 verdict에서 강한 반대 증거다.

**판정 6축** — 각 축을 평가하고 근거를 수치·사례로 기록.

| # | 축 | 핵심 질문 | 판정 | 근거 |
|---|----|---------|------|-----|
| 1 | **사업 구조의 시대 독립성** | 이 사업이 20년 전에도 유사한 형태로 존재했고 20년 뒤에도 유사한 형태로 존재할 수 있는가? (음식·결제·전력·운송 같은 원초적 수요인가, 특정 기술 사이클 의존인가) | 견고 / 부분 / 취약 | |

| 3 | **규제·정책 의존도** | 정부 정책 변화 한 번으로 사업 모델이 무력화될 수 있는가 (반독점 분할, 수출통제, 세제 변경, 인허가 박탈) | 견고 / 부분 / 취약 | |
| 4 | **소비자·고객 고착성** | 고객 습관·계약·스위칭 비용이 세대 교체(25년)를 넘어도 유지될 구조인가 | 견고 / 부분 / 취약 | |
| 5 | **경영진 독립 복원력** | 현 CEO·창업자가 떠나도 구조적 강점이 유지되는가 (시스템·문화·프로세스가 개인 의존인가) | 견고 / 부분 / 취약 | |
| 6 | **자본·재무 사이클 내성** | 과거 다수 사이클(1~2회 이상 경기 침체·금리 급등)을 통과한 실측 기록이 있는가. 부채·자본배분 트랙레코드(4번·5번 참조)가 다음 15년도 견딜 구조인가 | 견고 / 부분 / 취약 | |

**평생 보유 판정 (yes/no)**

```markdown
**판정**: YES (평생 보유 가능) / 조건부 (특정 조건 유지 시) / NO (장기 보유 부적합)

**근거 요약**:
- 견고한 축: {6축 중 "견고" 받은 축 나열 + 핵심 근거}
- 취약한 축: {6축 중 "부분"/"취약" 받은 축 나열 + 핵심 근거}

**조건부 판정인 경우 유지 조건**:
- {이 조건들이 지속되는 한 평생 보유 가능 — 예: CEO 승계 성공, 반독점 해소, 기술 전환 성공}

**판정 재검토 트리거**:
- {현재 판정을 뒤집을 수 있는 신호 — 6-5 Inversion 조건과 연계}
```

> **평생 보유 판정은 2-1~2-5 현재 해자 강도와 다르다**. 현재 해자가 강해도(2-2에서 "해자 성립") 시대 독립성·기술 저항성이 약하면 평생 보유 판정은 "조건부" 또는 "NO"가 될 수 있다. 둘을 혼동하지 않는다.

### 3. 복리 엔진 — "번 돈을 재투자할 곳이 있는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [성장] 10배 성장 요소가 무엇인가? (현재 상태에서 미래 10배로 갈 수 있는 동력)
- [성장] 필요 CAGR이 현실적인가? 역산 PER 대비 현재가는 기대 수익률 15%+를 허용하는가?
- [성장] 규모 저항 — 같은 시장 내 확장 여지는? 신규 시장·인접 영역·가격 인상 중 어느 경로가 열려 있는가?
- [PER] 재투자된 자본이 실제로 이익을 만드는가? (재투자 ROIC)
- [해자] 자본 경량성 — 매출 성장 대비 capex 증가율은? (해자가 강해도 재투자가 무거우면 FCF 복리가 멈춘다)

**왜 장투에 중요한가**: 해자가 강해도 재투자 기회가 없으면 이익은 배당/자사주로 흘러가고 이익 자체의 복리 성장은 멈춘다. 재투자율과 재투자 ROIC 둘 다 확보되어야 장기 이익 성장이 성립한다 (공식은 3-3).

#### 3-1. 성장 동력

각 동력은 **정량화된 증거**로 기록. **15년+ 재투자 런웨이**가 있는지 함께 판단한다 (현재 성장 동력이 3~5년 뒤 소진되면 복리 엔진 멈춤).

| 성장 동력 | 현재 규모 | 3~5년 후 규모 추정 | **15년+ 지속 가능성** | 근거 / 출처 |
|---------|---------|-----------------|--------------------|----------|
| TAM 확장 | | | {포화 도달 예상 시점 / 추가 확장 경로} | |
| 시장 침투율 상승 | | | | |
| 가격 인상 (pricing power) | | | | |
| 신규 제품/지역 진출 | | | | |
| M&A 파이프라인 | | | | |

**15년+ 런웨이 판정**: 충분 / 부분 / 소진 임박 — {근거}

#### 3-2. ROIC 추세

| 연도 | NOPAT | 투하자본 | ROIC | WACC | 스프레드 (ROIC−WACC) |
|------|------|--------|------|------|-------------------|
| Y-5 | | | | | |
| Y-3 | | | | | |
| Y-1 | | | | | |
| LTM | | | | | |

#### 3-3. 재투자율과 내재 성장률

- 재투자율 = (Capex + R&D + M&A − 감가상각) / NOPAT
- 내재 성장률 = ROIC × 재투자율
- **factual 기록**: 재투자율이 낮다면 회사가 제시하는 이유(공시 인용), 높다면 최근 투하 자본의 ROIC 수준

#### 3-4. 확장성

- 한계비용 구조 (고정비 vs 변동비 비중)
- 자본집약도 (매출 1$ 증가당 필요 자본)
- 과거 매출 확장 시 영업이익률 변화 (operating leverage 실측)

### 4. 자본배분 — "경영진이 번 돈을 제대로 쓰는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [PER] 매년 번 돈이 (a) 재투자 (b) 배당 (c) 자사주 (d) 부채 상환 중 어디로 가는가?
- [경영진] 과거 번 돈이 실제 이익 성장으로 이어졌는가? (자본 배분 이력)
- [경영진] M&A가 이익 성장에 기여했는가, 규모만 키웠는가? 무리한 프리미엄 지불 이력이 반복되는가?
- [경영진] 분기 실적 방어에 쫓기는가, R&D·capex를 사이클과 무관하게 유지하는가? (장기 시야)

**왜 장투에 중요한가**: 장기 수익률은 자본배분에 크게 좌우된다. 같은 이익이라도 경영진이 번 돈을 **재투자 / 자사주 / M&A / 배당 / 부채상환** 중 어디에 얼마나 투입했느냐로 결과가 크게 갈린다. 발언이 아니라 **결정과 결과**를 본다.

#### 4-1. 5~10년 자본배분 이력

| 연도 | OCF | Capex | M&A | 자사주 | 배당 | 부채 상환 | 순이익 재투자율 |
|------|-----|-------|-----|-------|-----|---------|------------|

#### 4-2. 주요 자본 투입 결과

- **Capex/M&A 건별 ROI** (가능한 경우)
  - 투입 금액, 시기, 현재 매출/이익 기여, 추정 ROI
- **자사주 매입 타이밍** — 연도별 평균 매입 단가 vs 당시/후속 주가
- **배당 이력** — 지급률, 성장률, 지속 연수

#### 4-3. 경영진 결정 vs 결과 (트랙레코드)

말이 아닌 결정과 결과를 기록.

| 발언/약속 (시점) | 실제 결정 | 결과 | 트랙레코드 판정 |
|--------------|---------|------|-------------|

#### 4-4. 인센티브 구조

- 경영진 보수 체계 (ROIC / FCF / EPS 연동 vs 주가 연동)
- 내부자 보유 지분 (insider ownership %)
- 최근 1~2년 내부자 매수/매도 내역

### 5. 재무건전성 — "나쁜 시기를 버틸 수 있는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [부채] 순현금 상태인가? (현금성 자산 − 장기 부채 > 0). 음수라면 생존 여력은?
- [부채] 부채 구성 — 은행 대출 vs 장기채 비중. 은행 의존도가 높아 유동성 충격에 취약한가?
- [부채] 이자 커버리지 — 사이클 저점에서도 이자를 감당할 완충이 있는가?

**왜 장투에 중요한가**: 복리 성장은 파산으로 0이 된다. 경기 침체·금리 급등 등 외생 충격에서 생존해야 복리가 작동한다. 부채 규모 자체보다 **무엇에 썼는지 + 갚을 능력**이 중요.

#### 5-1. 부채 구조

| 부채 항목 | 규모 | 이자율 | 만기 | 용처 | 고정/변동 |
|---------|-----|-------|------|------|---------|

- **부채 용처 분류**: 운영 / capex / M&A / 자사주 / 리파이낸싱 — 용처별 ROI 추정
- **만기 분포**: 1년 / 2~5년 / 5년 초과 — 리파이낸싱 리스크
- **고정 vs 변동금리 비중** — 금리 상승 시 이자비용 민감도

#### 5-2. 상환 능력 지표

| 지표 | 수치 | 업계 평균 | 판정 |
|------|-----|---------|------|
| Net Debt / EBITDA | | | |
| 이자보상배율 (EBIT / 이자) | | | |
| Debt / Equity | | | |
| FCF / 부채 | | | |
| 유동비율 | | | |

#### 5-3. FCF 추세·변동성

| 연도 | OCF | Capex | FCF | FCF 마진 | FCF / 순이익 |
|------|-----|-------|-----|---------|-----------|

- 지난 경기 침체 시 FCF 낙폭 (실측)
- FCF → 이익 전환율 평균

#### 5-4. 유동성 쿠션

- 현금·단기투자 잔액
- 미사용 Revolver 한도
- 커버리지 (향후 12개월 만기 부채 + capex 대비 유동성)

### 6. 리스크 / Inversion — "어떻게 돈을 잃을 수 있는가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [회피 관점 전반] 이 회사가 돈을 잃을 수 있는 경로는? (회사 특유 실패 + 외생 충격)
- [해자] 해자가 훼손될 시나리오와 현재 감지되는 징후는?
- [경영진] 같은 해자도 경영진이 허물 수 있다 — 무리한 확장·재투자 삭감·주주 가치 훼손 신호가 있는가?

**왜 장투에 중요한가**: "어떻게 이익을 벌까"만 보면 함정에 빠진다. 먼저 **"어떻게 잃을 수 있는가"**를 점검해야 이익 복리의 전제가 성립한다. 회사 고유의 실패 경로와 외생 충격(매크로·구조적)을 한 섹션에 모아 **취약성 정도**를 기록한다.

> **이 섹션의 판정은 게이팅이 아니다** — "NO면 투자 제외" 같은 하드 게이트가 아니라 **취약성 정보**를 기록한다. 스트레스 주가 충격은 DCF 계산·시나리오에 섞지 않는다.

#### 6-1. 회사 특유 실패 경로

일반 매크로 리스크는 6-3 스트레스 시나리오로. 여기는 **이 회사 고유의 실패 시나리오**만.

```markdown
### 리스크 {N}. {구체적 실패 경로명}

**실패 시나리오**: (무엇이 어떻게 무너지는가 — 인과 체인 포함)

**현실화 조건**:
- {이 조건들이 충족되면 실현된다 — 구체적 수치·이벤트}

**규모 정량화**:
| 지표 | 현재 | 시나리오 시 impact |
|------|-----|----------------|

**현재 경고 신호**:
| 지표 | 현재값 | 경고 기준 | 상태 |
|------|-------|---------|------|

**완화 요인** (있는 경우):
- ...

**팩트체크**: 핵심 수치 검증 상태 (확인 / 수정 필요 / 미확인)
```

관련성 있는 실패 경로는 모두 기록. 개수 제한 없음.

#### 6-2. 리스크 간 독립성

- 여러 리스크가 상관되어 있는가, 독립적인가
- 독립적으로 작동하는 사업부/자산이 있다면 명시 (시장이 이 구분을 반영하지 않는다면 기회의 근거)

#### 6-3. 스트레스 시나리오 (외생 충격)

매크로·구조적 충격에 대한 시나리오 테스트. **DCF 계산·시나리오에 반영하지 않는다.** 결과는 시나리오별 **취약성 등급**으로 표기.

해당 기업 관련성 높은 시나리오만 작성 (일반론 나열 지양). 후보:

- 금리 상승 (WACC +200bp 등)
- 경기 침체 / 수요 쇼크
- 규제·정책 리스크 (반독점, 수출 통제, 세제)
- 고객·매출 집중 (Top 고객 이탈, 섹터 의존)
- 공급망·CAPEX 충격 (전력·부품·인력 병목)
- FX·지정학 리스크
- 경쟁 구도 파괴 (신규 진입자, 기술 파괴)

**각 시나리오 구조:**

```markdown
### 스트레스 {N}. {시나리오명}

**가정**: {구체적 충격 조건 — 수치 포함}

**재무·밸류에이션 충격 추정**:
- 매출 / FCF / 이익 impact
- 멀티플 압축 (있는 경우)
- 주가 충격 추정 (참고용, DCF 계산엔 미반영)

**회복 근거 (강점)**:
- {이 회사가 버틸 수 있는 구조적 근거}

**취약 근거 (약점)**:
- {이 회사가 취약한 구조적 근거}

**모니터링 선행 지표**:
| 지표 | 현재값 | 경고 기준 |
|------|-------|---------|

**취약성 등급**: 강함 / 중간 / 취약
**등급 근거**: (왜 이 등급인가)
```

**등급 정의:**
- **강함** — 내재 쿠션(재무·해자·구조) 존재. 실현되어도 이익 구조 유지 가능
- **중간** — 일부 이익·마진 영향. 회복은 가능하나 기간·비용 발생
- **취약** — 실현 시 이익 구조 훼손. 복구에 구조 변화 필요

#### 6-4. 취약성 종합

| 스트레스 시나리오 | 취약성 등급 | 핵심 근거 |
|----------------|----------|--------|
| {시나리오 1} | 강함 / 중간 / 취약 | {근거} |

**종합 관찰**: 가장 취약한 축과 가장 견고한 축. (**판정·게이팅이 아니라 관찰 기록**)

#### 6-5. Inversion — "투자 판단 재검토 조건"

**현실화 시 투자 논리 재검토가 필요한 조건**. 하드 게이트가 아니라 재평가 트리거. 각 조건에 **현재 상태 + 감지 방법** 명시.

| # | 조건 | 현재 상태 | 감지 방법 (지표·공시·뉴스) |
|---|------|---------|-----------------------|

### 7. 밸류에이션 & DCF — "숫자상 얼마인가?"

**답해야 할 가치관 물음** ([philosophy](01_philosophy.md) 참조):
- [성장] 5~10년 사이클 N배 성장 가정 시, 기대 수익률(15%+)을 달성할 **최대 허용 PER**은? 현재 PER이 이를 초과하는가?
- [장기투자] 과거 데이터(부채·투자)로 만들어낼 미래 가치를 환산한 결과는? 3시나리오 범위 내에서 현재가 위치는?
- [PER] PEG sanity — PER이 성장률 대비 비정상 구간인가? (기계적 기준은 참고만, 단독 판정 금지)

**왜 장투에 중요한가**: 좋은 회사도 비싸게 사면 복리 수익률이 훼손된다. 3시나리오 범위(Bear/Base/Bull)를 산출해 어느 가격대에서 어느 수준 수익률이 나오는지 판단한다.

> **필수**: DCF 세부 방법론은 [03_dcf_guide.md](03_dcf_guide.md)를 **반드시 먼저 참조**하여 기업 유형에 맞는 방식(A. FCF DCF / B. SOTP / C. Excess Returns / D. NAV / E. Forward Multiple)을 선택한다. 획일적 FCF DCF는 자산운용사·은행·REIT 등에서 심각한 왜곡을 만든다.

#### 7-1. DCF 방법론 선택 (필수)

**이 블록이 없으면 작성 미완료로 간주한다.**

```markdown
**적용 방식**: {A. FCF DCF / B. SOTP / C. Excess Returns / D. NAV / E. Forward Multiple}
**선택 근거**: {왜 이 기업에 이 방식이 적합한가 — 사업 구조 특성}
**대안 대비 우위**: {다른 방식이 왜 부적합한가 — 최소 1개 대안 언급}
**주요 가정 요약**: {할인율, Terminal g 또는 멀티플 범위, 세율 등}
```

방식 선택 판별은 `03_dcf_guide.md`의 **Step 1. 사업 유형 판별** 테이블을 따른다.

#### 7-2. DCF 구조 설계

- **이익 변수**: 이 기업 이익을 구성하는 핵심 변수 (예: FCF, FRE+Carry, 매출×마진, NAV)
- **밸류에이션 공식**: `목표가 = (Y{N} {이익 변수}/주) × 적용 멀티플`
- **기본 가정**: 기준 이익, 희석 주식수, 주당 이익, 투자 기간
- **멀티플 근거**: 정상/스트레스 환경별 적정 멀티플 범위 + **역사적 실측 근거** (희망적 멀티플 금지)

#### 7-3. 3시나리오 DCF

**가중평균 금지. 범위 그대로 제시한다.**

각 시나리오 구조:

```markdown
### Bear — {핵심 전제}

**전제 조건**:
- {매크로/사업 환경}

**DCF 계산**:
{코드 블록 — 아래 통일 형식}

**목표가**: ${XX}

---

### Base — {핵심 전제}

**전제 조건**:
- {현재 궤도·가이던스 연장}

**DCF 계산**: ...

**목표가**: ${XX}

---

### Bull — {핵심 전제}

**전제 조건**:
- {복수 카탈리스트 동시 작동}

**전제별 실현 가능성**:
| 전제 조건 | 실현 가능성 | 근거 | 선행 사례 / 반례 |
|---------|-----------|-----|----------------|
| {전제 1} | 높음/중간/낮음 | {정량 근거} | {실제 달성 or 실패 사례} |

**실현 경로**: {인과 체인 — 어떤 순서로 무엇이 일어나야 하는가}

**전제 간 독립성**: {하나 실패 시 다른 전제가 유지되는가}

**DCF 계산**: ...

**목표가**: ${XX}

**붕괴 조건**: {이 시나리오가 무너지는 조건}
```

**계산 코드 블록 형식 (통일):**
```
{핵심 변수} CAGR: {X}%
Y{N} {변수}: {기준값} × {승수} = {결과}
Y{N} {변수}/주: {결과} / {주식수} = {주당값}
적용 멀티플: {X}~{Y}x  (근거: 역사적 {Z}~{W}x 범위, 출처)
────────────────
목표가: ${하단} ~ ${상단} (중간값 ${중간})
현재가 ${XX} 대비: {수익률}
```

#### 7-4. 3시나리오 범위 요약

```
시나리오       목표가(중간값)    현재가 대비
────────────────────────────────
Bear          ${XX}            {수익률}
Base          ${XX}            {수익률}
Bull          ${XX}            {수익률}
────────────────────────────────
범위:         ${Bear} ~ ${Bull}
현재가:       ${XX}
```

> **가중평균 계산 금지**. 확률 배분으로 단일 목표가를 만들지 않는다. 범위를 범위로 남긴다.

|------|---------|-----|---------|----------|----------|---------|

**트렌드 판단**:
```

──────────────────────────────────
```

## 섹션 간 논리 체인 (요약)

```
1. 사업의 본질 (어떤 사업인가)
        │
        ▼
2. 경제적 해자 (초과이익 지속 가능한가) ◀── 1의 단위경제학·고객구조에 기반
   └─ 2-6. 영속성 판단 (평생 보유 가능한가, 15년+ 지속성)
        │
        ▼

        │
        ▼

        ▼
```

## 체크리스트 — 작성 완료 전 확인

- [ ] **측정 전 컨텍스트(카테고리 분류) 블록**이 기재되었는가 (카테고리·근거·전환 방향·추가 점검 포인트)
- [ ] **각 섹션이 "답해야 할 가치관 물음" 목록**을 기재했는가 ([philosophy](01_philosophy.md) 참조 링크 포함)
- [ ] **물음별로 수치·근거 기반 답이 base에 남았는가** (물음이 공란이면 조사 미완)
- [ ] 답이 안 나오는 물음이 있다면 **그 사유가 기록**되었는가 (예: "재투자 ROIC 측정 불가 — 세그먼트 공시 없음")
- [ ] **7-1 DCF 방법론 선택 블록이 작성되었고, [03_dcf_guide.md](03_dcf_guide.md) Step 1 판별과 일치하는가**
- [ ] **7-7 다모다란 교차검증 블록**이 5개 항목(Terminal g ≤ rf, Sales-to-Capital, Unlevered Beta, Implied Multiple, Story↔숫자)으로 작성되었는가 ([03_dcf_guide.md](03_dcf_guide.md) Step 2 말미)
- [ ] 각 섹션 첫머리에 **"핵심 질문" + "왜 장투에 중요한가"**가 기재되었는가
- [ ] 모든 주장에 **수치 + 출처**가 있는가 (서술형 주장만 나열되지 않았는가)
- [ ] 1번 단위경제학·고객구조가 2번 해자 증거와 연결되는가
- [ ] 2번 해자 지속성 지표(ROIC, 마진, 시장점유율)가 **3년+ 추세**로 기록되었는가
- [ ] **2-2 해자 후보 검증**: 2-1에서 식별한 해자 유형이 모두 테이블에 올라왔고 각각 **해자 성립 / 미검증 / 해자 아님**으로 판정되었는가. "해자 성립"만 verdict에서 해자로 인용 가능함을 인지했는가
- [ ] "미검증" 항목에 **독립확인으로 전환할 수 있는 외부 데이터 조건**이 기록되었는가 (다음 분기 점검 포인트)
- [ ] **2-6 영속성 판단**: 2-2에서 "해자 성립" 받은 해자만 영속성 판정 대상으로 삼았는가. "해자 성립" 항목이 없는 경우 자동 NO로 처리했는가. 6축 평가와 시대 비교 증거(50년+ 생존군 / 해자 붕괴 사례)로 근거되었는가
- [ ] 3-1 성장 동력 테이블에 **15년+ 지속 가능성** 열이 채워지고 런웨이 판정이 기록되었는가
- [ ] 3번 **ROIC × 재투자율 = 내재 성장률** 계산이 있는가
- [ ] 4번 자본배분 이력에 **경영진 발언 vs 실제 결정 대조**가 있는가
- [ ] 5번 부채가 **용처별로 분류**되었는가 (부채 규모만 기록하지 않았는가)
- [ ] 6-1 리스크가 **이 회사 특유 실패 경로**인가 (일반 매크로는 6-3 스트레스 시나리오로 갔는가)
- [ ] 6-3 스트레스 시나리오에 **취약성 등급(강함/중간/취약)**과 근거가 명시되었는가
- [ ] 6-3 스트레스 주가 충격이 **DCF 계산에 반영되지 않았는가** (참고용 표기인가)
- [ ] 6-4 취약성 종합이 **판정/게이팅이 아닌 관찰 기록**으로 작성되었는가
- [ ] 6-5 Inversion 조건이 명시되었는가 (재검토 트리거 성격인가)
- [ ] 7번 DCF 3시나리오 각각에 **전제 조건**이 있는가
- [ ] 7번 멀티플이 **역사적 실측 범위**에 근거하는가 (희망적 멀티플 아닌가)
- [ ] Bull 시나리오의 전제 조건별 **실현 가능성**이 개별 평가되고, 선행 사례/반례가 제시되었는가
- [ ] **가중평균 목표가 계산이 없는가** (3시나리오 범위만 제시되었는가)
- [ ] 현재 실적이 어느 시나리오 범위에 있는지 판단되었는가
