# 1. 종목 분석 가이드

이 가이드를 따르면 `02_tickers/{TICKER}/{TICKER}_base.md` 파일이 생성된다.
이 파일은 시장 컨센서스 관점의 **Base 리서치** 결과물로, 이후 사용자 thesis와 결합해 Alpha 재평가의 입력으로 사용된다.

---

## 작성 원칙

1. **모든 주장에는 수치 근거가 있어야 한다** — "강한 해자"가 아니라 "LP 재투자율 80%+"
2. **보수적 가정 우선** — 낙관 시나리오는 확률 가중에서 조절한다
3. **팩트체크는 분석과 같은 섹션에** — 주장과 검증이 분리되면 읽는 사람이 연결을 놓친다
4. **섹션 간 논리 체인** — 해자 분석 → 해자 팩트체크 → 해자 강도 평가 / 리스크 분석 → 리스크 팩트체크 / 팩트체크 항목 → 모니터링 지표 / 리스크 시나리오 → DCF 시나리오 진입 신호
5. **출처 표기** — 수치에는 출처(공시, 보고서명, 데이터 제공자)를 병기한다
6. **최신 데이터를 직접 조회한다** — 모델 지식 컷오프에 의존하지 않는다. 매 분석 시작 시 아래 항목을 **WebSearch / WebFetch로 직접 조회**해서 사용한다:
   - **현재 주가 / 52주 고저 / 1년 수익률** (시세)
   - **직전 분기 + FY 실적 발표 자료** (FRE, OE, AUM, 가이던스, 컨퍼런스 콜 코멘트)
   - **최신 10-K / 10-Q 공시** (Realized Performance Income, 희석주식수, Net Debt 등 디테일)
   - **최근 1~3개월 주요 뉴스** (애널리스트 목표가 변경, 규제 이슈, 키맨 변동, M&A 등)
   - **애널리스트 컨센서스 목표가 / 평균 PE / EPS 추정치**
   - 컷오프 이후 갭이 있을 경우 "❓ 확인 필요" 로 비워두지 말고 **반드시 조회**한다. 본 가이드 분석 결과물은 작성일 당시의 최신 데이터를 반영해야 한다.

## 섹션별 작성 규칙

### 1. 투자 thesis

**목적**: 이 종목을 왜 사는지 3줄 이내로 요약. 나중에 "가설이 유효한가"를 점검하는 기준점.

**작성 항목:**
- 핵심 투자 논거 3가지 (bullet)
  - 각 논거는 **해자 유형**과 연결되어야 한다 (물리적 해자, 무형 자산, 전환비용 등)
  - 정량적 근거 1개 이상 포함 (예: FRE CAGR 35~37%)
- 매수 근거 작성일
- 매수가 / 목표가 (Base DCF 기준) / 투자 기간

**형식:**
```markdown
## 투자 thesis

- {논거 1} → {해자 유형} + {수치 근거}
- {논거 2} → {해자 유형} + {수치 근거}
- {논거 3} → {해자 유형} + {수치 근거}

**매수 근거 작성일**: YYYY-MM-DD
**매수가**: $XX
**목표가**: $XX (Base DCF 기준)
**투자 기간**: X년
```

### 2. 사업 구조 및 경제적 해자

**목적**: 기업의 이익 구조를 세그먼트별로 분해하고, 각 세그먼트가 보유한 경제적 해자를 식별한다.

**작성 순서:**

#### 2-1. 세그먼트 구조 요약 (테이블)

전체 세그먼트를 한눈에 볼 수 있는 요약 테이블.

| 세그먼트 | 수익원 | 규모 지표 | 해자 유형 | 해자 강도 |
|---------|------|---------|---------|---------|
| {세그먼트 1} | {어떻게 돈을 버는가} | {AUM, 매출, 시장점유율 등} | {해자 유형 나열} | Narrow / Wide |

- **해자 유형** 후보: 무형 자산(브랜드·트랙레코드·특허), 전환비용, 네트워크 효과, 효율적 규모, 원가 우위, 규제 진입장벽, 대체 불가 실물 자산, Float 우위
- **해자 강도**: Morningstar 기준 Narrow(10년 초과이익) / Wide(20년 초과이익) / None

#### 2-2. 세그먼트별 상세 (### 소주제)

각 세그먼트마다 `### {세그먼트명} — {핵심 해자 유형}` 형식으로 작성.

**각 세그먼트에 포함할 내용:**
- **사업 구조**: 1~2줄로 무엇을 하는 사업인지 설명
- **해자 테이블**: 해자 유형 | 내용 (구체적 수치 포함)
- 필요 시 **자산 현황 테이블** 추가 (보유 자산 목록, 규모, 시기)

**세그먼트 수 기준:**
- 단일 사업 기업: 1개 세그먼트 + 가치사슬 단계별 해자 분석
- 다각화 기업: 주요 세그먼트별 (보통 2~5개)
- 세그먼트가 6개 이상이면 상위 4~5개만 분석하고 나머지는 요약

---

### 3. 해자 팩트체크

**목적**: 2번에서 식별한 해자가 **실제로 대체 불가능한지** 수치로 검증한다. 주장이 아니라 증거.

**작성 규칙:**
- 세그먼트별로 `### {세그먼트} 해자 검증` 소주제 작성
- 검증 테이블 형식:

| 검증 항목 | 수치 / 근거 | 판정 |
|---------|-----------|------|
| {해자 주장} | {구체적 수치 + 출처} | ✅ 확인 / ⚠️ 부분 확인 / ❌ 미확인 |

- 판정 기준:
  - ✅ — 독립적 출처로 수치 확인 가능
  - ⚠️ — 회사 자체 공시만 존재하거나 독립 검증 어려움
  - ❌ — 수치가 주장과 불일치하거나 해자 약화 증거

- 각 세그먼트 검증 후 **해자 리스크** 기술 (bullet, 2~3개):
  - 이 해자를 약화시킬 수 있는 구조적 위협
  - 현실화 시점 추정 포함

- **물리적 자산이 핵심 해자인 경우**: 대체원가(replacement cost) 데이터를 별도 테이블로 상세 기술
  - 단가, 소요 기간, 인허가 장벽, 공급 병목 등

#### 해자 리스크 종합 (마지막)

모든 세그먼트의 해자 리스크를 하나의 테이블로 종합.

| 세그먼트 | 핵심 모트 리스크 | 현실화 시점 |
|---------|--------------|-----------|

### 4. 해자 강도 평가

**목적**: 2~3번 분석을 종합해서 **이 기업의 해자가 Wide인지 Narrow인지** 판정한다.

**작성 구조:**

```markdown
## 해자 강도 평가 — "이 정도 리스크면 충분히 높은 해자인가?"

### 평가 기준
Morningstar Wide Moat 기준: "향후 20년 이상 초과이익을 유지할 수 있는 구조적 우위"
→ 리스크의 현실화 시점이 투자 기간(보통 5~7년)보다 먼 경우 해자 유효로 판정

### 식별된 해자 리스크 vs 현실화 시점
| 리스크 | 내용 | 현실화 시점 | 해자 훼손 정도 |
|--------|------|-----------|--------------|

### 판정
**{TICKER} = Wide Moat ✅ / Narrow Moat ⚠️ / No Moat ❌**

핵심 근거 3가지:
① {근거 1 — 시간 지평 관점}
② {근거 2 — 전략적 헤지 관점}
③ {근거 3 — 계약/구조적 보호 관점}

**단, 주의 구간:** {Wide 판정이라도 가장 먼저 균열을 알려줄 선행 지표}
```

**판정 가이드라인:**
- **Wide**: 식별된 리스크 중 투자 기간 내 결정적 훼손 항목 없음 + 복수 독립 해자 존재
- **Narrow**: 해자 존재하나 단일 해자 의존 or 5~10년 내 현실화 가능한 위협 존재
- **None**: 경쟁 우위 불명확 or 3~5년 내 해자 훼손 가능 → **분석 중단, 투자 부적격**

### 5. 경쟁 구도 및 경쟁 우위

**목적**: 핵심 성장동력 관점에서 경쟁사 대비 이 기업이 **왜 더 나은 투자 대상인지** 근거를 제시한다. 해자 분석이 "이 기업이 강한가"를 다뤘다면, 이 섹션은 "경쟁사보다 강한가, 왜 이 기업인가"를 다룬다.

**작성 순서:**

#### 5-1. 경쟁사 식별 및 포지셔닝

핵심 사업 영역별로 직접 경쟁사를 식별하고 포지셔닝 맵을 작성한다.

**경쟁사 선정 기준:**
- 동일 TAM에서 경쟁하는 상장 기업 3~5개
- 비상장이라도 시장점유율 5%+ 또는 파괴적 잠재력이 있으면 포함
- 인접 시장에서 진입 가능성이 높은 기업 1~2개 (잠재 경쟁자)

| 경쟁사 | 시가총액 | 핵심 사업 영역 | 시장점유율 | 포지셔닝 |
|--------|---------|-------------|----------|---------|
| {대상 기업} | | | | |
| {경쟁사 1} | | | | |
| {경쟁사 2} | | | | |

#### 5-2. 핵심 성장동력 경쟁 비교

대상 기업의 핵심 성장동력(투자 thesis의 논거)을 기준으로 경쟁사와 직접 비교한다.

**성장동력별 비교 테이블:**

| 성장동력 | {TICKER} | 경쟁사 A | 경쟁사 B | 판정 |
|---------|---------|---------|---------|------|
| {성장동력 1} | {수치 근거} | {수치 근거} | {수치 근거} | 🥇/🥈/🥉 |
| {성장동력 2} | | | | |

- **판정 기준**: 각 성장동력에서 대상 기업이 1위가 아닌 경우 **왜 그래도 투자해야 하는지** 또는 **추월 가능한 근거**를 명시
- 반드시 정량 지표로 비교 (매출 성장률 CAGR, 마진, R&D 투자 비중, 고객 확보 비용 등)

#### 5-3. 경쟁 우위 원천 분석

경쟁사가 쉽게 복제할 수 없는 **구조적 우위**를 식별한다.

**작성 항목:**

```markdown
### 경쟁 우위 원천

**1. {우위 항목 1}**
- 우위 내용: {구체적 설명}
- 정량 근거: {수치 + 출처}
- 경쟁사 격차: {가장 가까운 경쟁사 대비 차이}
- 복제 난이도: 높음 / 중간 / 낮음 — {근거}
- 격차 지속 기간 추정: {X}년 — {근거}

**2. {우위 항목 2}**
...
```

**우위 원천 후보 체크리스트** (해당하는 것만 작성):
- 규모 우위: 비용 구조, 채널 커버리지, 데이터 자산 규모
- 기술 우위: 특허, R&D 파이프라인, 엔지니어링 인재 풀
- 생태계/플랫폼 우위: 개발자·파트너 네트워크, 전환비용
- 고객 관계 우위: 장기 계약, 임베디드 솔루션, 교차판매 역량
- 자본 배분 우위: ROIC, M&A 트랙레코드, 주주환원 규율
- 경영진 우위: 트랙레코드, 인센티브 구조, 장기 비전 정렬

#### 5-4. "왜 이 기업인가" — 투자 차별화 근거

위 분석을 종합해 **경쟁사가 아닌 이 기업에 투자해야 하는 핵심 이유**를 3가지로 요약한다.

```markdown
### 투자 차별화 근거

1. **{차별화 1}**: {1줄 요약} — 경쟁사 대비 {정량 격차}
2. **{차별화 2}**: {1줄 요약} — 경쟁사 대비 {정량 격차}
3. **{차별화 3}**: {1줄 요약} — 경쟁사 대비 {정량 격차}

**밸류에이션 비교:**
| 지표 | {TICKER} | 경쟁사 평균 | 프리미엄/디스카운트 | 정당성 |
|------|---------|-----------|------------------|--------|
| Forward PE | | | | |
| EV/EBITDA | | | | |
| PEG | | | | |
| FCF Yield | | | | |

**결론**: {밸류에이션 프리미엄이 정당한가 / 디스카운트가 기회인가 — 1~2줄}
```

### 6. 리스크 요인

**목적**: 투자 thesis를 무효화할 수 있는 리스크를 식별하고, 각 리스크에 대해 **인라인 팩트체크**를 수행한다.

**작성 규칙:**

- 리스크는 `### {번호}. {리스크명} ⚠️` 형식
- 리스크 개수: 최소 3개, 최대 8개 (핵심 리스크에 집중)
- 각 리스크에 포함할 내용:
  1. **리스크 설명** (1~2줄)
  2. **규모/비중 정량화** (전체 매출/AUM 대비 비중 등)
  3. **상세 데이터 테이블** (해당 시)
  4. **시나리오별 영향** (어떤 DCF 시나리오에서 현실화되는가)
  5. **완화 요인** (있는 경우)
  6. **팩트체크**: 핵심 수치의 검증 상태 (✓ 확인 / ⚠️ 수정 필요 / ❓ 미확인)

**리스크 분류 체크리스트** (해당하는 것만 작성):
- 사업 리스크: 핵심 사업의 구조적 위협
- 재무 리스크: 레버리지, 유동성, 신용 등급
- 성장 리스크: 성장 둔화, TAM 한계
- 밸류에이션 리스크: 멀티플 압축
- 실현 리스크: 수익 인식 지연 (Carry, 엑싯 등)
- 매크로 리스크: 금리, 경기 사이클, 규제
- ESG/평판 리스크

#### 리스크 독립성 확인

리스크 간 상관관계를 확인하고, **독립적으로 작동하는 사업/자산**이 있다면 명시.
→ 시장이 이 구분을 반영하지 않는 경우 그것 자체가 투자 기회의 근거가 될 수 있다.

#### 리스크 수치 팩트체크 종합

모든 리스크의 핵심 수치를 하나의 테이블로 정리.

| # | 항목 | 판정 | 비고 |
|---|------|------|------|
| 1 | {핵심 수치} | ✓ / ⚠️ 수정 / ❓ | {설명} |

### 7. 모니터링 지표

**목적**: 해자 팩트체크 + 리스크 팩트체크에서 **분기마다 추적할 지표**를 도출한다.
직접 만드는 것이 아니라 3번과 6번의 팩트체크 항목에서 **파생**된다.

**작성 규칙:**
- 두 개의 테이블로 분리: **해자 건전성** / **리스크**
- 각 항목에 **출처 섹션**(어느 팩트체크에서 왔는지)을 명시

#### 해자 건전성 모니터링

| 출처 | 모니터링 항목 | 기준값 | 현재 상태 |
|------|------------|-------|----------|
| {세그먼트} 해자 | {팩트체크에서 도출된 KPI} | {유지해야 할 기준} | ✓ / ⚠️ / ❌ |

- 해자 팩트체크에서 ✅ 판정된 항목 → 그 수치가 유지되는지 추적
- 해자 팩트체크에서 ⚠️ 판정된 항목 → 독립 검증 가능해지는지 추적

#### 리스크 모니터링

| 출처 | 모니터링 항목 | 경고 기준 | 현재 상태 |
|------|------------|---------|----------|
| 리스크 {N} | {팩트체크에서 도출된 경고 지표} | {이 값 돌파 시 경고} | 현재값 + 상태 |

- 각 리스크의 팩트체크에서 ⚠️ 또는 ❓인 항목 → 경고 기준 설정
- 매크로 지표 3개 이내 추가 가능 (LP Commitment, 크레딧 스프레드, 핵심 LP 이탈 등)

#### 경쟁 우위 모니터링

| 출처 | 모니터링 항목 | 경고 기준 | 현재 상태 |
|------|------------|---------|----------|
| 경쟁 비교 {성장동력} | {시장점유율, 성장률 격차 등} | {경쟁사 추월 시점 or 격차 축소 기준} | 현재값 + 상태 |

- 5번 경쟁 분석에서 식별한 경쟁 우위 원천 → 격차가 유지되는지 추적
- 경쟁사의 신규 진입·기술 추격 신호 → 경고 기준 설정

#### 즉시 재검토 트리거

모니터링 항목 중 **하나라도 충족되면 즉시 전체 분석을 재검토**하는 조건 목록.
보통 3~5개. 형식: bullet list.

### 8. DCF 시나리오 & 가치평가

**목적**: 시나리오별 DCF 계산을 수행하고, 가중평균 내재가치를 산출한 뒤, 현재 실적이 어느 시나리오에 위치하는지 판단한다.

> **⚠️ 필수**: DCF 세부 방법론은 [02_dcf_guide.md](02_dcf_guide.md)를 **반드시 먼저 참조**하여 기업 유형에 맞는 방식(A. FCF DCF / B. SOTP / C. Excess Returns / D. NAV / E. Forward Multiple)을 선택한다. 획일적 FCF DCF는 자산운용사·은행·REIT 등에서 심각한 왜곡을 만든다.

**작성 순서:**

#### 8-0. DCF 방법론 선택 (필수)

8번 섹션 **첫머리에 반드시 기재**한다. 이 블록이 없으면 작성 미완료로 간주한다.

```markdown
### 8-0. DCF 방법론 선택

- **적용 방식**: {A. FCF DCF / B. SOTP / C. Excess Returns / D. NAV / E. Forward Multiple}
- **선택 근거**: {왜 이 기업에 이 방식이 적합한가 — 사업 구조 특성 언급}
- **대안 대비 우위**: {다른 방식이 왜 부적합한가 — 최소 1개 대안 언급}
- **주요 가정 요약**: {할인율, Terminal g 또는 멀티플 범위, 세율 등}
```

방식 선택 판별은 `02_dcf_guide.md`의 **Step 1. 사업 유형 판별** 테이블을 따른다.

#### 8-1. DCF 구조 설계 원칙

기업의 이익 구조에 맞는 밸류에이션 공식을 정의한다.

**필수 기재 항목:**
- **이익 변수**: 이 기업의 이익을 구성하는 핵심 변수 (예: FRE + Carry, 매출 × 마진, EBITDA 등)
- **밸류에이션 공식**: `목표가 = (Y{N} {이익 변수}/주) × 적용 멀티플`
- **기본 가정 테이블**: 기준 이익, 희석 주식수, 주당 이익, 투자 기간
- **멀티플 기준**: 정상/스트레스/위기 환경별 적정 멀티플 범위 + 근거 (역사적 실측치)

**공식 설계 가이드:**
- 안정 이익(반복 수익)과 변동 이익(성과 보수, 일회성)을 **분리**한다
- 변동 이익은 시나리오별로 별도 가정 (0부터 정상화까지)
- 멀티플은 반드시 **역사적 실측 범위**를 근거로 한다 (희망적 멀티플 금지)

#### 8-2. 시나리오별 DCF 계산

**4개 시나리오 고정 구조:**

| 시나리오 | 확률 가이드 | 성격 |
|---------|-----------|------|
| **Extreme Bear** | 10~20% | 금융위기급, 사업 모델 자체 위협 |
| **Bear** | 20~30% | 성장 둔화, 리스크 부분 현실화 |
| **Base** | 35~45% | 현재 궤도 연장, 가이던스 달성 |
| **Bull** | 15~25% | 순풍 가속, 복수 카탈리스트 동시 작동 |

> 확률 합계 = 100%. 보수적 가정 우선: Extreme Bear + Bear ≥ 35%.

**각 시나리오에 포함할 내용:**

```markdown
### {시나리오명} — 확률 {X}%

**전제 조건:**
- {어떤 매크로/사업 환경이 전제인가} (2~4개)

**시나리오 진입 신호:**
- {모니터링 지표 중 어떤 것이 트리거인가} (2~3개)
  → 7번 모니터링 지표 또는 기존 Bull/Bear 모니터링에서 도출

**DCF 계산:**
{코드 블록으로 계산 과정 명시}
- 핵심 변수 성장률 (CAGR)
- Y{N} 이익/주 계산
- 적용 멀티플
- 목표가 = 이익/주 × 멀티플
- 현재가 대비 수익률

**실현 가능성 분석:** (Bull에만 해당)
각 전제 조건의 달성 가능성을 개별 평가한다.

| 전제 조건 | 실현 가능성 | 근거 | 선행 사례 / 반례 |
|---------|-----------|------|----------------|
| {전제 1} | 높음/중간/낮음 | {정량 근거 — 현재 궤적, 업계 데이터, 경쟁 구도} | {유사 기업/시장에서 실제 달성한 사례 or 실패 사례} |
| {전제 2} | | | |

- **실현 경로**: 전제 조건들이 동시에 충족되려면 어떤 순서로 무엇이 일어나야 하는가 (인과 체인)
- **전제 간 독립성**: 전제 조건들이 독립적인가, 하나가 실패하면 나머지도 무너지는가
- **종합 실현 확률 판단**: 개별 전제의 실현 가능성을 종합해 Bull 확률 {X}%가 적정한지 재확인. 과대/과소 시 조정 근거 명시

**붕괴/전환 조건:** (Bull에만 해당 — 이 시나리오가 무너지는 조건)
```

**계산 코드 블록 형식 (통일):**
```
{핵심 변수} CAGR: {X}%
Y{N} {변수}: {기준값} × {승수} = {결과}
Y{N} {변수}/주: {결과} / {주식수} = {주당값}
{변동 이익}/주: {가정}
Y{N} 총 이익/주: {합계}
적용 멀티플: {X}~{Y}x
────────────────
목표가: ${하단} ~ ${상단} (중간값 ${중간})
현재가 ${XX} 대비: {수익률}
```

#### 8-3. 가중평균 내재가치

```
시나리오       확률    중간값    기여
──────────────────────────────────
Extreme Bear   {X}%    ${XX}    ${XX}
Bear           {X}%    ${XX}    ${XX}
Base           {X}%    ${XX}    ${XX}
Bull           {X}%    ${XX}    ${XX}
──────────────────────────────────
가중평균 내재가치:              ${XX}
가중평균 범위:          ${XX} ~ ${XX}
현재가 ${XX} 대비:      {수익률 범위}
```

> 확률 배분 근거를 반드시 기술한다 (왜 Extreme Bear가 10%가 아니라 15%인가 등).

#### 8-4. 실적 데이터 — 현재 어디에 위치하는가

**목적**: 직전 4분기 실적을 DCF 시나리오 가정과 대조하여 **현재 어느 Case에 있는지** 판단.

**작성 항목:**
1. **직전 실적 테이블** (LTM 또는 최근 4분기):

| 지표 | 수치 | YoY | DCF Case 위치 |
|------|------|-----|-------------|
| {핵심 KPI 1} | | | {어느 시나리오 범위인가} |

2. **트렌드 판단** (코드 블록):
```
{핵심 변수} 궤적: {과거} → {현재} → {방향}
──────────────────────────────────
현재 위치: {Case X} ~ {Case Y} 경계
트렌드 방향: {가속/감속} → {어느 Case 방향}
```

3. **가이던스 반영 시 방향**:
   - 가이던스 달성 시 → 어느 Case로 이동
   - 가이던스 미달 시 → 어느 Case로 이동

4. **핵심 관찰**: 가장 중요한 변수 1개와 향후 확인 시점

#### 8-5. 가치평가 결과

DCF 계산 결과를 종합하는 요약 테이블.

| 지표 | 수치 | 평가 |
|------|------|------|
| 현재 주가 | ${XX} (52주 고점 대비 {X}%) | |
| Forward PE | ~{X}x | 역사적 평균 대비 {고/저}평가 |
| PEG | {X} | ≤1 저평가 / >2 고평가 |
| 가중평균 내재가치 | ${XX} (${XX}~${XX}) | 현재가 대비 {업사이드}% |
| 손익비 (Base vs Bear) | 업사이드 / 다운사이드 | {비율} |
| 손익비 (Base vs Extreme Bear) | 업사이드 / 다운사이드 | {비율} |
| 애널리스트 평균 목표가 | ${XX} | 참고용 |

**결론**: 1~2줄로 밸류에이션 판단 + 핵심 조건부 진술
(예: "Base 시나리오 기준 +X% 업사이드. 단, {조건} 시 Bear 진입")

### 9. 종합 판정

**목적**: 모든 분석을 종합하여 최종 투자 의견을 제시한다.

**형식 (고정):**
```
[ {TICKER} ] 평가 요약
────────────────────────────────
비즈니스 퀄리티  : ✅ / ⚠️ / ❌ + 1줄 요약
시장 환경        : ✅ / ⚠️ / ❌ + 1줄 요약
가치평가         : ✅ / ⚠️ / ❌ + 1줄 요약
리스크           : ✅ / ⚠️ / ❌ + 1줄 요약
────────────────────────────────
종합 의견        : 매수 / 분할 매수 / 보유 / 비중축소 / 매도 검토
────────────────────────────────
핵심 모니터링:
  1. {가장 중요한 변수}
  2. {두 번째}
  3. {세 번째}
```

**판정 기준:**
- **매수**: 가중평균 내재가치 대비 20%+ 할인 + Wide/Narrow Moat
- **분할 매수**: 15~20% 할인 or 리스크 ⚠️ 항목 존재
- **보유**: 내재가치 근처 + 기존 thesis 유효
- **비중축소**: 내재가치 도달 or 리스크 ❌ 항목 발생
- **매도 검토**: 즉시 재검토 트리거 충족 or 핵심 thesis 무효화

### 10. 분기별 점검 기록

**목적**: 분기 실적 발표 후 Case 위치 변화를 기록하여 투자 thesis의 유효성을 추적한다.

**형식:**

| 날짜 | 실적 요약 | Case 위치 변화 | 가설 업데이트 |
|------|----------|-------------|-------------|
| YYYY-MM-DD | {핵심 KPI 1~2개 변화} | {이전 Case → 현재 Case} | {thesis 유지/수정/무효화} |

**작성 트리거:**
- 분기 실적 발표 시
- 즉시 재검토 트리거 충족 시
- 매크로 환경 급변 시

## 섹션 간 논리 체인 (요약)

```
투자 thesis
  │
  ▼
사업 구조 & 해자 식별 ──→ 해자 팩트체크 ──→ 해자 강도 평가
                              │                    │
                              │ (팩트체크 항목)      │
                              ▼                    ▼
                        모니터링 지표 ◀── 경쟁 구도 및 경쟁 우위
                        (해자 건전성)      (성장동력별 경쟁 비교
                              │            + 투자 차별화 근거)
                              │
리스크 요인 ──────────────────┤
  │ (인라인 팩트체크)          │
  │                          ▼
  ├──→ 모니터링 지표 ──→ DCF 시나리오 진입 신호
  │   (리스크)              │
  │                        ▼
  └──→ DCF 시나리오 ──→ 가중평균 ──→ 실적 데이터 (Case 위치)
                                        │
                                        ▼
                                   가치평가 결과
                                        │
                                        ▼
                              종합 판정
                                              │
                                              ▼
                                        분기별 점검
```
